# SA24：图像参数的任务约束与自主设计分开记录

基线1887ffa。属于A收尾第一块，B方法/排序不改。开始前先保存计划/复跑代码。审计确认旧版并非机械禁止自由尺寸：LLM给出有效值并引用文档即可执行；真正缺口是提示将所有非空项当任务声明、缺独立设计来源和参数约束校验。因此不预设旧版一定失败，不把新增记录说成成功率提升。

## 实现

semantic-native-v3在原信封增加design_decisions。首版只支持image_preprocessing设计，记录文档中的部分task_constraints、每个约束的文档引用、自主选择理由和图片任务依据；实际chosen仍在plan中。执行器验证已提取约束与chosen逐项一致，并自动将各参数标为task_requirement或agent_design_choice。没有参数要求时由LLM选择并冻结，不由Python填默认尺寸。目标/指标/标签/输出不能被design_decisions覆盖；未解决的任务事实问题仍保留，不自动吞掉uncertainties。旧v1/v2缓存和直接API兼容。

要求新提案用v3，缺图像尺寸本身不要编成缺目标；确实未知/矛盾的任务要求继续查证或报告未决。程序只核引用存在与提案内部一致，不能证明模型没遗漏原文约束，必须用独立oracle验收。设计元数据及所选参数随模型/解释缓存冻结、重放。

## 对照与预算

固定两个Digits公开来源的图像开发条件：F不规定图像处理参数；P只规定宽度12与RGB，未规定高度。各90训练/30预测、类别目录定义目标、macro_f1、Row/Class原顺序输出。训练图有不同原始尺寸，不靠堆叠原图过关；任务解释、预处理和模型由Agent选择。它们是同一已见来源的设计边界条件，不算新的未见来源或质量结果。

旧1887ffa与新实现分别通过同一正式solve运行，每格一次、不注入回复/工具/方法，B目录/fit限制/seed不变；每路径2fit含refit、3Flash、360秒、¥.30估计停止阈值。4条总上限8fit/12API/¥1.20。预期机器5–10分钟。先无fit/API检查，再冻结各格运行顺序与两份源码，真实同账本17条未知按原行SHA授权，失败停批不重试。

主指标：完整交付、错误完成、参数约束满足、自主参数来源记录、scope/fit/API/时间/费用；最后新进程预测逐字节一致。自由参数不以固定大小的特征FP判错，但用独立Pillow处理按Agent冻结chosen重建训练/预测特征核对，P必须width=12/mode=RGB。新旧都成功则如实报告没有成功率增益，只验证设计记录和约束机制。旧模式不强制有新元数据，不因其缺字段算任务失败。

没有性能评价，不开预测答案；没有目标定义的案例不硬猜。每批protocol/results/completion新目录；脚本scripts/run_sa24_image_checks.py和scripts/run_sa24_image_live.py；模型/数据/账本/密钥不进Git。第一块结束后推进说明发现和常见交付兼容，不扩成全部图像算法搜索。
