# 原始包统一入口验收

初步复现使用历史训练面板。上一轮记下了 6,608 行面板和全部 8,301 行的结果。本次在已知开发成绩的条件下做工程验收，固定规则、预算和分组种子，验证一条命令能否从两个课程原包各自交付模型。没有盲测推断。

共同入口 `python -m unified_agent train TASK.zip --run-dir DIR`。只看训练成员和数据说明，复用已有共享文本连通分量与分层五折实现。对声明左右偏好、存在重复文本、各类独立组足够支撑内外五折的输入，沿用历史外层种子 41101，第一份满足类别覆盖的留出用来做选模后的独立训练内核对。其余支持的任务把全部训练行交给原生执行器。外层逻辑不引用历史行号、文件名、题目数、分数或模型名。保留源字段名，将来预测可以使用同样的原始特征列。内层统一种子为 18643，实际拟合最多 10 次，模型 API 0 次。

两包分别从空目录训练。模型冻结后各在两个新进程预测同一份指定验证特征，先记下两个预测指纹再核对答案。同时与历史逐行比较。登记所有结果，一次运行后不按验证重选数据、参数或模型。表格和标题的正式测试、H1 与 H2 保持封存。
