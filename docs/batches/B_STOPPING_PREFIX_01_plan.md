# 连续领先能否作为 Agent 提前停止的依据

复用 B1-07/08 的 16 条完整路径（优惠券、标题、Dry Bean、短信，各两个开发划分，各有固定和动态组），以及 B2-01 的 6 条完整路径（标题、短信各三组）。这些是已分析过的开发实验。此次在计算提前停止结果前固定规则。两批源码分别对应各自真实运行版本。两批数据与组别有重复，表中分别列出。

对每条路径依次重放每个真实决策状态。只有已经完成并通过行、标签、预测和载荷指纹验证的观测能进入判断。调用当时版本的晋级函数得到该时点的在位模型，并逐字段复现原动作。沿用每条路径真实拟合计数，保留一次完整重训。不启动实验 worker、不运行任何预测或语言模型，不读课程指定验证、测试或两份登记迁移任务的答案。

比较两条只依赖当时信息的假设停止规则。

1. 至少 3 个不同候选已在首轮划分完成，且当前在位模型在连续 3 个完成观测后的状态相同，此时停止（连续两次新观测未换第一名）。
2. 在规则 1 的条件上，还要求在位模型和至少一个不同对手已在同一份复核划分完成可配对观测，两者都有该次首轮划分的预测证据。

未触发时沿用原结束时点。在真实停止状态才满足条件，也算原时点。计算各规则的首次触发时点、与原赢家是否一致、若此时收尾可省下的历史监督拟合数；预计节省明确扣除最终重训。本实验不外推运行时长。记录开发集里的晚晋级和从未当过早期第一名的最终赢家，不调整规则或重复抽种子。

先保存所有候选决定，再对照既有的完整模型。只在同一批、同一任务和训练数据、同一划分、相同候选实现与参数、同一完整重训约定、相同依赖和有相同评价行的另一条路径确实交付过该模型时，引用已生成的预测成绩。否则逐项标为缺少可比的完整重训成绩。报告此类已有模型的正确数和主分，原方向相同时核验预测指纹。所有分差只描述真实交付物，反事实提早停止自身没有执行或重训。保留结论边界与未知项。
