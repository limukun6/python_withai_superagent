## 它为什么选十二层

1. 纯词法模型与六层模型在 680 对探索标题中同时错了 123 对，超过触发门槛 34 对。Agent 因此开放了十二层方法和普通等权组合。
2. 四种简单方法仍然同时错 99 对。Agent 检查剩余额度，才执行两次分组交叉拟合和一次适配器训练。对已经训练出的组件，它还评估了条件推理和全量融合。
3. 探索部分，全量适配融合答对 503 对，十二层单模型答对 502 对。另 692 对复核标题中，十二层答对 481 对，融合答对 475 对。按事先登记的总正确数选型，十二层以 **983 比 978** 胜出，Agent 用全部 6,608 行重训它并停止。探查和复核的标题组互斥，使用同一组已训练候选。

候选和规则由开发者事先定义。启动后由程序读取任务契约、计算错误重合、决定是否扩展、复核并选择最终模型。两条路径都使用本地决策。候选库的选择和调度规则一起发生了变化，因此本实验能衡量整体方案，无法单独估算两项改动的因果收益。[运行前协议](B_local_components_pair_1123_zh.md) · [实际决策记录](../../research/b_local_components_1123/component_actions.json)

在相同内部记录上只开放词法和六层两项，会选六层。开放十二层和普通组合后会选十二层；再开放适配器及其组合，最终选择仍为十二层。逐一去掉 1,004 个标题组中的任意一组，合并成绩的赢家也仍为十二层。这项复盘没有额外训练，也没有使用外层成绩。就本次运行而言，提早给 Agent 一个更好的候选、再让它保留简单路线，比强制使用复杂模型更符合实际观测。[选型复盘](../../research/b_local_components_1123/feedback_catalog_audit.json)

## 与 72.87% 的关系

72.87% 是旧研究适配器在课程指定的 940 对验证标题上的成绩。本次 72.24% 是新 Agent 在课程训练数据内部预留的 1,693 对标题上的成绩。此次配对没有打开课程指定验证、正式测试或 H。已有离线组合在同一份 1,693 行上最高答对 1,231 对，它使用历史权重。本轮实际交付哪种模型由 Agent 在看外层成绩前决定。

## 接入方式

保留原版 `superagent run --scheduler ab-v1 --portfolio ab-v1 --planner local`。在本地研究分支加上 `--preference-components` 开启实验路径。普通路径使用原 32 项目录，满足偏好契约和资源条件的实验路径评估最多 8 种单模型或组合。未满足该任务条件时沿用原入口。输出采用团队 `superagent predict` 的模型与任务格式。

运行实验路径和加载它的模型时，分别将 `SUPERAGENT_MINILM_WEIGHTS`、`SUPERAGENT_DEEP_MINILM_WEIGHTS` 指向已核验的六层和十二层编码器目录，将 `SUPERAGENT_B_COMPONENT_RUNTIME` 指向研究运行库。两个运行版本通过独立进程隔离。[已验收的运行库快照](../../research/b_local_components_1123/runtime-source.zip) 只含 Python 源码和校验清单；解压根目录即为该变量的路径。模型权重、原始训练数据和密钥未放入仓库。

无训练的交付预检先发现并修复了冻结估计器与 scikit-learn 接口的一处不兼容。正式配对只有一次，训练没有失败或重试。后续独立实验优先比较“原动态调度＋十二层单模型”与“相同目录＋组件调度”，把候选增加与调度改动的贡献拆开。
