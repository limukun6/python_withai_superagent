# 共同目录中的自适应探索宽度

在旧目录中，E5 与带训练语料词频特征的十二层从未同时出现在一次真实调度中。研发固定组合已在重复使用的 1,693 对训练内保留区答对 1,237 对；现有四次探索的正式入口最高交付 1,224 对。下一步检验匿名 Agent 是否会自主发现值得确认的组合，事先不指定某个模型或搭档。

联合目录同时提供原有十二层、六层、E5 和新特征。可选新调度先按原规则探索四个候选。若第一和第二单模型存在逐行分歧，且领先量未超过按共享标题组估计的 1.96 个标准误，并且剩余额度能覆盖一次额外探索、最多三次对照确认和两次重训，才向普通候选选择器申请第五次探索。否则直接用已有证据。最多检查五个候选的等权两两组合；组合需要在首轮超过最佳单模型至少 0.2 个百分点，才确认两成员与首轮最佳单模型。确认仍以最高单模型为基准，两折都严格增益、汇总至少增益 0.2 个百分点才选组合，否则保留首轮最好单模型。此规则读取候选能力、逐行反馈、组号和余额。

使用预先指定的新种子 40531，完整生产 CLI 运行最多 10 次实际拟合，模型 API 0 次。记录四或五次开局、按组不确定性、入围原因、是否额外确认领先者及最终选择。先冻结成员与导出，再与同训练样本的旧单模型、固定最佳组合的历史预测比较。这些历史数字只是固定参考。随后尝试复用本次相同配置和划分的检查点，另外还原同种子、同联合目录、同额度的四候选控制；缺少的证据单独标记和计数。只有真实自主路径达到 1,235/1,693 后，才考虑冻结一次课程指定验证。正式测试继续封存。
