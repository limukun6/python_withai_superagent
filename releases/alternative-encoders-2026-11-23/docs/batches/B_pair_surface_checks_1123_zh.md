# 成对模型依赖的是左右位置、文字内容还是表面形式？

完成冻结的台词迁移和首轮本地适配后登记。本批不选择模型或调整参数。复用 Task2 的 1,693 条训练内保留数据和台词实验的 450 对留出影片台词。两项均取各自已经冻结的自主模型，拟合及模型 API 预算均为 0。

1. 原始输入复用已经通过两个进程比对的文件。交换每对文本的左右位置，要求输出相应反转，记录逐行成功数。
2. 对两边做相同的文本处理，将 Unicode 统一为 NFKC、大小写折叠、标点替换为空格并合并空白。只改变大小写、标点等表面线索，保留词序。报告因此变为同一句的对数、预测改变率、改对与改错数量，以及与原版在同一行上的差值和分组区间。两种变换各用两个新进程验证。
3. 按原始文本的空白分词数，独立列出两边同长和不同长两层，报告原模型的正确数。一个始终偏向较长文本的规则，遇到同长时计半分，作为无训练参考。此分词规则仅用于诊断。

台词实验按影片连通组，标题实验按先前冻结的共享标题组重采样。先保存所有预测的 SHA-256 再接入标签。此次只计量对表示的敏感性；未将任何处理变成正式模型的默认设置。
