# 核对标题改几个字后是否跨了训练和评价两边

课程训练 CSV 只有两个标题和偏好标签，未提供文章编号。现行分组把共享完整规范化标题的行连接起来。本项事先固定一个较严格的文本相似指标，量化仍有多少训练内评价行能在该折训练中找到近乎相同的标题，并看新增答对的题是否集中在这部分。此时尚未计算近似匹配数，也未按相似度读取任何成绩。

只取前两种五折共同的 6,608 个开发行。每个标题做 Unicode NFKC、casefold，提取 Unicode 字母数字序列，再取相邻两个词组成的有序词对集合。两个标题都至少六词且至少五个不同词对时，若词对集合的 Jaccard 相似度至少 0.80，则连接两个标题所在的原组。求连通分量。每一折，若评价行任一标题与训练行标题有一条直接近似连接，记为“检测到相似标题”；另统计更严格的“扩大后的整个连通组留在本折”的行。原分组之间完全相同的符合长度条件的规范化词序也计算为匹配。登记直连和连通两种口径，覆盖率与分母分别报告。

对前后两种五折分别核对相同原始行的双模型和概率提名 Agent。先用只有匿名文本、行号和折号的输入封存匹配标志与分组指纹，随后才按已交付的逐行预测计算三个子集的答对数、改对和改错。同时给出所有行按扩大组重抽样的配对区间。两次划分分别报告，合计仍为 6,608 个不同样本。全部处理零拟合、零模型 API。相似度不能识别所有同文异题，也不能证明两行出自同一篇文章。此项只用来检验对划分的敏感性，无权改变主检验、阈值或触发外部任务。
