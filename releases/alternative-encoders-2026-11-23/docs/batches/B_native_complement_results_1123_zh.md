# 新划分上的真实自主决策

标准命令 `superagent run --scheduler ab-complement` 在匿名任务上从零训练，选择了**六层 MiniLM 加词模型**。两层选择都使用训练内反馈：先选四个单模型中的领先者，再用逐行概率寻找互补的搭档，并在另一分区复核。种子 18643 的 1,693 行开发保留区答对 **1,208 对（71.35%）**；原十二层完整重训对照答对 1,224 对（72.30%）。它改对原模型的 78 对，同时改错 94 对。差值 −0.95 个百分点，按共享标题组重采样的 95% 区间为 −2.54 至 +0.64 个百分点。[原生动作与完整成绩](../../research/b_complement_native_1123/native/)

首轮还有词模型单独 836、十二层单独 917、E5 单独 902。两个组合精确并列时原规则沿用探索顺序，Agent 选中词模型。它完成了 4 次探索、2 次复核和 2 次完整重训；原方案、数据、候选菜单和预算由开发者事先登记。之后另用 1 次拟合复核并列的十二层搭档，原选择在复核后仍成立。对同训练量的六层模型，词模型组合改对 24 对、改错 24 对；十二层组合改对 46 对、改错 46 对。单改并列顺序未能挽回原十二层基线的 16 对差距。[补测方案和逐题成对结果](../../research/b_complement_native_1123/ties/)

两种程序检查区分了真正的反馈选择和写死的方法。将四个候选改成匿名编号后，已观测下一动作按编号一一复现。人为令全部反馈相同时，调度停止并保留单模型；让一个单独较弱的候选专门纠正领先者的错误时，调度申请成对复核。破坏概率指纹或行序会被拒绝。这些人为反馈只用于机制验收。最终模型在隔离进程中独立加载，1,693 行预测与正式导出逐字节一致。[决策验收](../../research/b_complement_native_1123/decision_audit.json) · [隔离交付](../../research/b_complement_native_1123/native/portable_result.json)

按共享标题组重复抽样 5,000 次，旧 E5 开局的原组合在 41.62% 的抽样中再次被选中，旧 BGE 为 38.32%，新 E5 为 28.44%。一两次小幅领先容易随评估样本变化。本阶段实际拟合 9 次，加上前一批已记录的 23 次合计 32 次，模型 API 共 0 次。所有成绩来自训练内开发，课程指定验证与正式测试继续封存。[抽样结果](../../research/b_complement_native_1123/stability.json) · [资源完成记录](../../research/b_complement_native_1123/completion.json)
