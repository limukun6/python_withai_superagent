# 同一训练行在两次复核中出现的影响

在 E5 平均方案获得两个正向分区后，追加统计 2,711 个评估行次里实际有多少不同的行与共享标题组。同一行可能被两个不同模型各预测一次。先逐行恢复两个分区内两两平均、MiniLM 和新编码器的历史预测，核对已公布正确数；分别按原始行次和“每条原始训练行合计权重为 1”的方式估计净增益。对后者按原正式划分规则复原的共享标题组做 5,000 次配对重采样。另列只在一个分区出现的行与重复出现的行各自贡献。

这项描述用于判断少数或重复样本是否驱动升幅，不能把两个交叠训练集当成多个独立数据集。E5 的两分区和 BGE 的追加反事实分区分别报告。此项冻结已有模型，仅用原匿名训练包，新增拟合与模型 API 请求为 0。
