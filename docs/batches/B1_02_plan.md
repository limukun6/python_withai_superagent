# B1-02 匿名交接复验

首轮（44568ac）的最后赢家只有一次 primary 记录，致因是验收驱动在当时总分最高的两个候选之间调用固定选型器，丢失了更早的完整配对。原始记录保留在 research/b1_ab_handoff/pilot。

复验固定原合成数据、种子、三份内部划分、候选、机器、时限、最多 11 次训练和零请求。前 3 个成功探索中，按共同 primary 主指标形成暂时领先者，平分按候选 ID。缺少可比记录时不晋级。此后只有在至少 2 个配对划分上严格领先且所有共同划分的平均增益达到 0.002 才允许换人。新高分可以优先申请复核。若没有足够额度同时完成一次新探索、至少一次复核及最终重训，则停止不再开新路线。停止动作仍由 A 最终执行，用同一份晋级证据交付 A。
   
macro-F1 在可信本地标签可用时用同一组重采样索引重算两个候选的 macro-F1 差值，分组可用时按组采样。只做是否值得复核的筛选，晋级仍看真实不同划分。给 Flash 的回调仅含可选 ID。没有本地标签时使用 0.002 工程阈值，不估算 macro-F1 误差。

复跑一次原匿名任务及 4 个原小探针，保留两份独立结果。不改种子、估分方式或数据以追求更高分。此批验收守住旧模型、真实预算和跨进程预测，无外层质量比较。
