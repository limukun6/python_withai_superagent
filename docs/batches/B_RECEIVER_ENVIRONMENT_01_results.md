# 没带编码器权重、或换轻量环境，哪些模型还能交付

用同一个已验收接收包，固定三个真实交付物及各自完整无标签查询。9 次新进程预测中，6 次与原结果逐字节相同，3 次明确失败，三次均没有残留部分结果。

| 模型 | Python 3.11.15 原环境＋权重 | 同环境、空权重目录 | Python 3.14.7 轻环境、原权重目录 |
|---|---|---|---|
| 优惠券字段交互（1,627 行） | 完全相同 | 完全相同 | 缺少 CatBoost，未导出 |
| 非线性 MiniLM 短信（825 行） | 完全相同 | 缺少已核验的 MiniLM 权重，未导出 | 缺少 torch，未导出 |
| 字符混合组合短信（825 行） | 完全相同 | 完全相同 | 完全相同，出现 scikit-learn 序列化版本提示 |

原机为 scikit-learn 1.7.2、CatBoost 1.2.10、torch 2.13.0、transformers 4.53.3。轻环境是 scikit-learn 1.9.0，无 CatBoost、torch、transformers、tokenizers。这里的跨版本相同只覆盖已验收的 825 行。实际交付非线性 MiniLM 时，应同时提供运行库与指定权重的获取和校验方式；优惠券路径需要 CatBoost。字符组合能在已测轻环境重放，仍以已登记的包版本作为可复现环境。此项全程禁网，模型和课程 API 调用与训练为零，也没有打开标签。[九次接收端结果](../../research/b_receiver_runtime/results.json)
