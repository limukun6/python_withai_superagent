## 从训练开始就能拿到什么

沿用原来的启动命令。训练端读到可信类别并冻结类别频率后，另一个进程读取待预测输入，在第一次拟合前向指定位置写出所有行的预测和凭据。该预测使用训练集中的类别频率，适合抢救中断，分数可能很低。正常结束时，同一路径会收到经过核验的最终预测。训练端接收固定的继续信号，实验选择只使用训练数据。

```sh
python -m unified_agent solve TRAIN.zip --prediction-input FEATURES.zip --run-dir runs/job --output runs/job/predictions.csv
python -m unified_agent predict FEATURES.zip --run-dir runs/job/first_delivery --output runs/replay/first.csv
```

第一条命令产生的 `first_delivery/` 含自足的早期模型、任务定义、预测和摘要。交付凭据在输出文件旁边。查看 `prediction_manifest.json` 的 `delivery_status`、`delivery_phase` 和 `prediction_sha256` 可以核对当前拿到的文件。若新输入无法解码，`prediction_attempt.json` 会说明这次请求的结果；此前成功文件仍然可以按原摘要核验。

在本机的三分类 ROC-AUC 故障实验中，第一次在首个拟合开始前强制杀掉主程序，3.44 秒内已经观察到 57 行顺序正确、包含三个类别概率的预测。第二次在第二个模型开训时终止训练，系统导出了第一个已验证模型的 57 行预测。两份预测都在新进程逐字节重现，两个受中断的训练进程及其工作进程均已退出。破坏一份复制模型后，普通预测入口也成功恢复了早期结果。以上中断实验使用 POSIX 本机环境。程序需要可定位的待预测行和可信类别信息才能形成有效交付。

## 从题面的评分示例读懂目标

当题目给出有限的候选指标、示例标签、示例预测和官方示例分数时，Agent 能按示例显示的小数精度逐一验算。它支持准确率、平衡准确率、宏平均、微平均和加权 F1。清单可提供 `metric_evidence`，题面 Markdown 也可在 `Scoring examples` 或 `评分示例` 下给出相同内容的 JSON。示例如下。

```json
{
  "candidates": ["accuracy", "macro_f1"],
  "labels": [0, 1],
  "examples": [{"truth": [0, 0, 0, 1], "prediction": [0, 0, 0, 0], "score": "0.43"}],
  "rounding": "half_up"
}
```

这个例子中准确率是 3/4，宏平均 F1 约为 0.42857，因此可以确认后者。三份新合成题均用两个示例识别出宏平均 F1，并各完成 320 行预测。另外两份题分别故意让文字与示例冲突、让准确率与微平均 F1 无法区分，两次都记录了待核实指标、以零拟合交付 12 行部分预测。任意数学公式、自然语言描述和从未支持过的附件格式都需要各自的验收；这些结果只覆盖记录中的格式。

## 一次训练反馈怎样进入下一轮思考

`--task-analysis feedback-local` 在取得第一次训练内验证结果后生成一个可检验的问题。`--task-analysis feedback-flash` 可以向课程允许的校园 DeepSeek 发送一次题面摘要和训练结果。两种模式都可以提出单一信号或两个信号的交集，随后在另外一份无重复行的训练划分上复核。模型更换还取决于本题主指标、剩余拟合机会以及重训所需预算。运行中的想法和证据写入 `agent/task_opening.json`。

跨题实验可设置 `SUPERAGENT_LESSON_STORE` 指向本地 SQLite 文件。归档内容是通用信号、核查结论和去重指纹。新题只读取相同数据类型、相同指标且本题可计算的信号。验收和封存时用 `SUPERAGENT_LESSONS_READONLY=1`。首次学习和随后的复核只访问训练侧数据。

第一份合成题提出“数值幅度较大且属于少数类时，分类更容易出错”。第二份同生成机制、不同抽样的题读取了这条线索。该组在主划分和复核划分的错误率分别比其余样本高 61.17 和 37.06 个百分点，组内分别只有 17 和 12 行。三次实验都在每题 5 次拟合额度内结束，这条线索没有触发额外换模。三份各自 320 行的开发留出宏平均 F1 为 75.63%、76.28%、71.13%。每份任务的样本不同，这三个数不能用来估计大模型或经验迁移的因果收益。

付费组调用一次 DeepSeek-V4.1-Flash。网关返回输入 891、输出 768 个 token，其中 723 个记为推理 token。回复在 22.36 秒后触及输出上限，未形成可校验的提案。本地判断完成了任务。依项目冻结的空闲时段价格结算为 ¥0.003963，已经与 B 侧待合并账本的对应回执核对；账户实际扣款由学校平台结算。本批付费复核的成效仍待独立验证。

两份课程原包使用默认统一入口、各 10 次实际拟合，从空目录开跑。训练完成并封存两份预测后才计算指定验证成绩。三份公开开发题使用可选的本地反馈模式，从相同训练数据重新开始，并和前一天已封存的默认版预测逐行比较。
