# Task1 方法搜索总账：十一类方法全部低于现有模型

2026-11-27。用户要求"不管能不能达到，只找有没有更好的方法"。本文件汇总本轮激进搜索的全部实测结果。**全部在训练内折（707/811/823）上完成，不用 val、不碰 test，0 API。**

## 2 观察

1. **没有任何方法在三个折上同时超过现有模型。** 最好的两个（袋装 +0.16pp、外部特征 +0.29pp）都只有 1/3 折上升。
2. **"更强的模型"并不更好**：神经网络差 5–8pp，kNN 差 7–12pp，LightGBM 差 2pp。这说明**这个数据集上关键的归纳偏置是"类别共现计数"，而不是表示学习或局部距离**。
3. **多样性融合无效**：把差 2–3pp 的模型平均进来，只会把好的拉低——和之前"联合核 / 双塔融合"的结论一致。
4. **类别加权恰好印证误差分析**：加权重会牺牲多数类，净效果为负；模型在 0.5 阈值处的偏差其实已经接近最优。

## 3 为什么这些都不行（机制层解释）

| 方法 | 失败机制 |
|---|---|
| MLP | 21 列全类别、无有序结构；独热后维度高、样本少，学不出比计数更好的东西 |
| kNN | 特征空间里"距离近"不等于"行为像"，21 维独热的余弦距离被高频类别主导 |
| LightGBM / RF | 缺少 CatBoost 的类别目标统计（CTR）与有序 boosting |
| 融合 | 成员之间的误差高度相关（都错在低置信、拒绝类），平均不产生新信息 |
| 外部三列 | 模型已通过"画像+情境" token 捕捉了等价信息 |

## 4 结论

**在这一份数据上，没有找到比 recurring-context token 树更好的方法。**

已经试过的族：树集成、梯度提升、神经网络、记忆方法、预训练表格模型、外部特征、类别加权、概率融合、种子袋装、组合复杂度、阈值。**十一个族，没有一个稳定超过。**

如果再找，只剩三类，且都要更多资源：

| 未试 | 原因 | 预期 |
|---|---|---|
| XGBoost 原生类别 | 本轮下载超时 | 与 LightGBM 同族，预期仍低 |
| TabNet / FT-Transformer | 需要 GPU 训练，本机 sm_120 内核不匹配 | 与 MLP 同族，预期低 |
| 关联规则挖掘 | 实现成本高，可能与 CatBoost 的 CTR 重复 | 不确定 |

## 5 建议

**停止在方法维度继续搜索。** 现有模型的内部成绩在 75–77% 之间波动，任何新方法的期望增益都低于折间噪声。把剩余时间放在"陌生任务无人干预"的冻结演练上，那是评分里真正没拿到的分。
