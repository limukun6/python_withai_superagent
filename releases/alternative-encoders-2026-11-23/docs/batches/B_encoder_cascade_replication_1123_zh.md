# 换编码器和训练划分后复验提前判断

沿用首轮已经冻结的候选先后排序、六个概率阈值、初筛准确率门槛和新确认组的退回规则。首轮留下了哪些架构和数据限制，直接用两种同条件比较来检验。

- 标题改用 BGE-small-en-v1.5 和普通十二层 MiniLM，初筛种子 8123。恢复原生训练的两个初筛分类头及同划分确认头，旧版本未保留完整概率矩阵的记录从对应的冻结分类头还原，并逐行核对原硬预测。用已交付的两个全量分类头在同一 1,693 行开发区实测实际路由。该开发区被重复使用。
- 台词改用六层和普通十二层 MiniLM，沿用种子 27183、1,468 条训练对、另留出的 95 部影片／276 对数据。原 450 对位于该划分之外。复用已有两候选的初筛与新确认组记录；既有 1,468 行全量十二层模型直接使用，若缺少对照所需的六层完整头，补 1 次本地拟合。该次连同原新路径 10 次拟合计 11 次。该批 276 对在早先的单模型研究中已评分。
- 先冻结两个程序选择，再提交两组留出预测，最后统一评分。复核全量 BGE 组合与既有逐行输出，独立核对影片十二层的原输出。报告实际模型选择、提前判断的行数与本地 token、与全量双模型的配对差异。沿用原门槛，每组至少节省第二个编码器 10% 的行，正确率损失最多 0.5 个百分点，才支持在两组上推广。若内部确认选择全量双模型，照实记录退回。全部新增拟合最多 1 次，模型 API 0 次。
