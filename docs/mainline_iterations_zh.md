# 七次搜索的分类主线能走多远

本轮比较一套固定计算预算下，分类 agent 怎样使用最后两个试验名额。开放的能力由开发者编写，程序根据输入和前面试验的逐行预测自行选择候选，完成训练、复核和选模。各轮之间由开发者提出新假设。运行中没有人指定下一步，程序使用本地规划器和已下载的模型权重。

## 成绩怎样读

Task1 从随作业发布的训练数据中划出 6,494 行作为开发池，另外保留 1,623 行。Task2 的开发池有 6,608 行，另外保留 1,693 行。每一套五折划分中，每行只做一次外层验证。Task1 的相同输入放在同一组，Task2 中通过任一共用标题相连的样本放在同一组。换随机种子会重分同一批样本，因此跨种子的正确数不能相加当作新的独立样本。

每组先做相同的五次搜索，再使用两个额外名额。原领先候选保证入围。入围三名在三个训练内划分上复核，优胜者用该折全部拟合行重训。七次搜索、六次额外复核和一次重训合计 14 次下游分类器拟合。我们逐折检查前五次搜索的预测完全相同，在所有比较组冻结后打开外层答案。正式验证和测试成员均未打开。每次试验上限 480 秒，整组上限 1,600 秒。候选的树数、特征计算量与实际用时可以不同。

更换主线的事前门槛是合计准确率比每个对照高至少 0.2 个百分点，且五折至少赢三折。在已探索的划分达标后，还须在重新分组的训练数据上复验。所有研究分支的分数用于开发决策。课程最终报告使用的正式成绩须从同一最终提交版本重新产生。

## 哪个环节还有空间

我们把第一套五折中原策略的三名入围者都在完整拟合行上重训，额外使用 10 次拟合。即使事后知道每折答案，并能挑中该折最好的完整模型，总共只能答对 4,810 行，比原策略多 9 行。这项诊断限定了原入围名单里进一步选模的空间。所有事后看答案的数字只用来估算上限。

再把每折剩余四名也用同一批数据重训，额外使用 20 次拟合。此时完整七名候选的同口径上界为 4,812/6,494（74.10%），比实际策略多 11 行（0.17 个百分点），低于晋级所需的 13 行。这个数值恰好与另一组固定路线的实测正确数相同。两个实验的候选、逐行预测与用途各异。

换成 47111 分组，三名入围者的整模上界是 4,785 行，七名候选的上界是 4,795 行。相对实际的 4,779 行，七名的逐折可追回行数分别是 0、1、9、6、0。第三、四折最好的完整模型恰好都是当时未进入复核的 MiniLM 类别模型。这 16 行使得第二套划分有必要继续检查入围规则。

为检验这 16 行是否真能靠改名单找回来，我们在原来的三个训练内划分上把七名候选全部测完。每折总共有 15 种三人名单包含必须保留的原领先者。把每一种名单都交给原来的三折平均分选模后，第二套划分即使事后知道哪份名单最有利，上界仍是 **4,779**，与实测完全相同。第一套分组同样计算得到上界 **4,812**，比实测多 11 行。换一种可执行的名单规则，为准确率接近、又能修复其他模型共同错误的新方法留一个位置，两套分组分别答对 4,801 和 4,779 行。另将复核从三名扩大到七名，每次运行的拟合从 14 次升至 22 次，两套分组分别多答对 10 行、少答对 10 行。

三名入围者按多数票决定类别，强制使用时答对 4,764 行。改为等权平均预测概率，在两套划分上分别答对 4,771 和 4,756 行。两种方式都沿用原 14 次拟合，其中两名成员来自较小的初次拟合。另付计算量将三个成员全部重训后，第一套划分的硬投票和概率平均均答对 4,779 行。

同一个普通 CatBoost 只改变可用于拟合的分组数量，依次使用约 25%、50%、75%、100% 时答对 4,545、4,610、4,725、4,758 行。最后四分之一增加了 33 行，说明固定名单的上限和整个分类问题的上限是两个不同的问题。查重还发现，39 组完全相同的输入带有冲突标签；这些样本约束出的 6,455/6,494 上界很宽，不能用作可达到的目标。

## Task2 与自主决策

普通七次搜索答对 4,421/6,608 行（66.90%）。开放另一组候选后，程序五折都先试从零训练的小型神经网络，再试普通文本方法，最终答对 4,435 行（67.12%）。逐折相差 +8、0、0、+12、−6 行。这一变化相当于纠正 163 行并新增 149 个错误，胜利折数低于更换主线的门槛。

对 Task2 同样把七名候选全部重训，事后可选出的最优整模总共答对 4,468 行（67.62%）。这 33 行空间全部落在每折原有三名入围者内。我们还重放了一条更谨慎的换模规则。新模型须在三个训练内复核中至少赢两次，纠错净收益达到 0.2 个百分点及一个分组标准误，才取代前五次的领先者。对重复出现的行先平均，再估计不确定性。这条规则在 Task1 少答对 26 行，在 Task2 少答对 14 行。

原来的 MiniLM 能力服务于表格类别名。在这次扩展中，输入为英文为主的文本、且多种模型仍共同犯错时，程序可以试冻结的句子向量。成对偏好任务使用左右标题的向量差，单段文本使用该段自身的向量。第一种候选将它与词、字符及适用的文本统计信息结合，第二种只用句子向量。固定组尝试两者；自主组会依据第一种候选改对和改错了哪些行，决定是否继续第二种试验。运行记录单独列出训练和外层预测的编码量。[MiniLM 模型说明](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2)

在第一套标题五折上，固定和自主两组都答对 4,623/6,608 行（69.96%），比 4,435 行的旧路线多 188 行。五折分别多答对 14、77、50、33、14 行。合计纠正 657 个旧错误，同时新增 469 个错误。自主组第三折把最后的名额给了普通文字模型，其余四折试单独使用向量。两组最终都选中混合模型，逐行预测完全相同。

第二套五折中，原普通搜索答对 4,417 行，原自主路线答对 4,414 行，开放标题 MiniLM 特征的两组均答对 4,644 行（70.28%）。与同一划分上较强的普通搜索比，五折都赢，纠正 650 行并新增 423 个错误，净增 227 行（3.44 个百分点）。与原自主路线比，五折分别净增 34、23、67、55、51 行。固定和自主使用额外试验名额的两组在这套划分也逐行一致。[五折逐行比较汇总](../research/mainline_frontier_results.json)

先把三个入围者全量重训，再补齐每折其他四个候选，混合模型在五折中每折都是七者中最好的一个。就这批七个模型而言，即便事后看答案，也无法多答对一行。把句子特征在已训练分类器中的贡献减半降至 4,552 行，翻倍得到 4,607 行。让程序在内部搜索集上用对数损失和准确率决定是否改变权重，它五折都保留原权重。这项权重试验复用了冻结的向量和分类器，新增拟合与特征前向次数均为零。

第二套划分的相同权重试验中，减半答对 4,567 行，翻倍答对 4,645 行，自动选择仍为原权重的 4,644 行。在第一套分组中还配对测试了两种非线性表示。一组让同一个标题的语义维度互相作用，另一组让左右标题的语义维度交叉作用。使用相同维度、随机投影和名额，两组各五折都真正训练了新方法，最后五折都选回原混合模型。

再做一次严格的特征对照。保持训练行、词表、字符特征、文本样式、交换增强、逻辑回归和正则化强度全部相同，只改变输入的特征。十个用真实词句混合特征重训的分类器逐行复现了原预测。相同的词字符特征配真实句向量，比去掉句向量分别多答对 176 和 227 行，两个划分都是五折全赢。只用句向量也都低于混合版本。按每段文字生成可重复的随机单位向量后，增加同样的 384 个维度会退步。这组对照使用 40 次额外分类器拟合，全部复用已有向量。

| 实际用于拟合分类器的特征 | 47147 分组 | 47381 分组 |
|---|---:|---:|
| 词、字符、样式＋真实句向量 | 4,623 | 4,644 |
| 词、字符、样式 | 4,447 | 4,417 |
| 只用真实句向量 | 4,492 | 4,513 |
| 词、字符、样式＋随机单位向量 | 4,282 | 4,290 |

用组内预测概率判断分类器是否过度自信，第一套五折中只有一折出现明确的正则化方向。程序用更强正则化重训，最后仍选回原分类器。其余四折保留名额用于普通候选，合计仍答对 4,623 行。另一套七名候选全部重训后，4,644 行同样等于每折事后选择最佳完整模型的上界。

### 是否值得下载更深的编码器

程序先训练小模型，再看内部搜索集上改对和改错的行数、两条路线共同答错的行数，以及根据小模型实测耗时估算的试验时间。满足条件时，它可以请求同为 384 维的 MiniLM-L12。首次取得权重的决策从已经冻结的训练轨迹重放，五折中的四折提出请求。随后下载并核对了 133,933,166 字节的公开权重、配置和分词器。完整五折使用相同文件离线运行。11,505 个不同标题最长 45 个 token，都落在两个编码器各自的长度限制内。[下载凭据及逐折决策](../research/encoder_depth_results.json) · [L12 模型说明](https://huggingface.co/sentence-transformers/all-MiniLM-L12-v2)

第一套五折的自主策略实际四次试用 L12，其中三次最终选用它。相对小编码器的逐折净变化为 0、+5、0、−4、+17，总计答对 4,641 行，多 18 行（0.27 个百分点）。这个新增候选有过真实贡献，严格胜利的折数仍低于事前要求。

把一份实际入选的 L12 分类器、任务规范和选模记录复制到新目录，使用显式提供的公开权重，对 16 个新编的无标签样例进行预测。在两个目录得到的文件字节一致，8 对交换次序的标题全部翻转预测。原目录和新目录各首次处理 144 个输入 token，重复预测新增 0 个。该检查单列在下载及重载记录中。

| 如何分配第二个名额 | 第一套五折 | 第二套五折 |
|---|---:|---:|
| 保留小编码器主线 | 4,623 | 4,644 |
| 较强反馈才试 L12 | 4,641 | 4,639 |
| 只要可行就试 L12 | 4,649 | 4,648 |
| 改用较宽松的反馈条件，重放已实际运行的分支 | 4,649 | 4,648 |
| 事后每折从这三条实际路线中挑最好的上界 | 4,653 | 4,656 |

较强反馈规则在每套划分都试了四次深模型，各有一折早早放弃，固定对照证实这两折本可多答对 8 行和 9 行。宽松规则只要求小模型表现仍有竞争力，两套划分都选择五次深模型。重放时逐折核对两条轨迹前六次搜索的候选和逐行预测，之后只采用已经完整训练并导出的分支。第二套五折即使在这三条既有路线间事后挑选，上界也只比小模型多 12 行，低于晋级所需的 14 行。保留 `auto` 的小模型默认，并提供可运行的自主深度选择实验参数。[第二套深度试验](../research/encoder_depth_replication.json)

表格的另一条候选路线从训练数据估计单个类别、类别组合与标签的关系。为每行生成训练特征时，程序先连同该行的重复样本一起留出，只用其他组的标签计数。遇到稀有组合时，估计向两个单列的估计收缩。单元测试会改变一整组自己的标签，验证这组得到的训练特征丝毫不变。[交叉拟合原理](https://scikit-learn.org/stable/auto_examples/preprocessing/plot_target_encoder_cross_val.html)

## 复现与团队交接

统一入口在两项任务各跑五折，分别复现 4,801 和 4,623 个正确答案。共 70 次搜索的逐行预测、10 个最终模型的逐行外层预测，与相应的单独路线完全一致。六类匿名输入均能导出可重载的分类器，每类顺序输出 15 行。混合表在第六次搜索后用完了可行候选，程序按设计提前结束。单段和成对文本模型移到新目录后，冷启动分别处理 131 和 262 个 MiniLM 输入 token，再预测的模型计算量均为零，输出文件字节一致。[统一运行与重载记录](../research/unified_policy_results.json)

另将两个真实公开数据集的名称和字段名从 agent 的输入中省去。采用三折分组验证，同一 `auto` 配置在葡萄酒数值表（178 行、3 类）得到宏平均 F1 0.9774，答对 174 行。在手写数字灰度图像（1,797 张、10 类）答对 1,759 张，准确率 97.89%。共六次完整训练，84 次下游拟合，模型 API 请求为零。这是两个公开参考任务的运行记录，课程未发布任务仍待最终评估。[逐折记录](../research/open_transfer_results.json) · [Wine 数据](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_wine.html) · [Digits 数据](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_digits.html)

同一运行时的五折结果来自本地 `tools.frontier_study`，该入口只准打开原始包的训练成员。它以对照在前的顺序接受 `--arms`，用 `--seed` 固定外层分组，用 `--freeze` 在首次拟合前写入协议。协议记录原始包和源码的 SHA-256、依赖版本、完整行号、对照运行目录和预算。可以复用同一划分下已冻结的对照模型。历史版本仍可按对应 Git 提交和保存的协议重放。

本轮固定环境为 Python 3.11.15，依赖的具体版本见 `requirements-pretrained.txt` 及其引用的 `requirements-tested.txt`。本机复现实验时，保留原两份任务的预算归属和既有账本，下面以 Task2 的一套五折为例。第一次省略 `--references` 会重新拟合两个比较组。将最后的 `--freeze` 移除后执行训练。Task1 使用相同入口，将任务包替换为类别训练包、比较组改成 `paired auto`、种子改成 `46919`。

```sh
python -m tools.frontier_study --archive "/path/to/Task2.zip" --output runs/task2-stability \
  --arms representation auto --seed 47147 \
  --ledger "/path/to/existing-project-ledger.sqlite3" \
  --historical-protocol "/path/to/released_online_completion/results/protocol.json" \
  --shared-budget "/path/to/prior-project-experiments" \
  --minilm-weights "/path/to/all-MiniLM-L6-v2" \
  --weights "/path/to/Qwen3-Embedding-0.6B" --freeze
```
