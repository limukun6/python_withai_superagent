# 复验前补充核对旧分类头的输入顺序

首次复验在恢复旧初筛反馈时停止，目录只生成了协议，当时尚未选择阈值、训练六层头或计算两项外层预测。旧 worker 按输入原有左右顺序评分，交付模型按字典序输入后还原左右方向。对四个旧训练折分类头逐行核对，原顺序都重现原来的硬预测。交付顺序下 BGE 在初筛和确认折各有一行改变选择，两行的胜方概率与 0.5 分别只差约 0.000245 和 0.000115。普通十二层的两折逐行一致。

保留全部行。先用旧实现核验其硬预测和原哈希，再用交付实现恢复每行部署概率供既定策略选择。每折记录两种输入顺序的输出哈希、差异数和差异处与 0.5 的最大距离。不修改阈值、候选、确认门槛、留出、样本权重和原始回执。若旧实现不能复现任何一行历史硬预测，停止该次复验。
