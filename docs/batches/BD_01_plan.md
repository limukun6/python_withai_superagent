# BD-01 · 搬迁编码器和最终模型后的无标签预测

用已冻结的三个真实模型检查交付依赖。选 BQ-01 的标题扩展模型、B1-06 的 45101 对称文本扩展模型，以及同一划分的词法模型作为独立对照。每个模型只带正式预测入口所需的模型、任务规格和最终选型记录。重新复制三份固定版本的 MiniLM 本地文件，给每个预测进程一个新的缓存位置。

每个模型分别在三个条件下启动新的正式预测进程：正确权重位于新目录，未提供权重目录，提供的副本中一个配置字节发生改变但文件大小保持相同。九次操作只给不含标签的特征包。可用的预测须与首次冻结的整份预测 CSV 逐字节一致，且核对真实行数。依赖缺失或校验失败的编码器模型应在写出预测前说明缺少已固定的资源。单纯词法模型在三个条件下都应能交付。网络关闭，训练和额外模型 API 上限均为零。此批不重新打分。
