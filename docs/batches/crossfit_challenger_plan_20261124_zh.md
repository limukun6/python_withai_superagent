# 单挑战者与两折训练反馈对照

起点 `f11b8cf`。B 实现可选研究配置，继续保留默认统一配置和原指定验证交付。研究配置在同一 `unified_agent train/predict` 入口运行。使用统一资产目录，仅在明确的左右偏好二分类、accuracy、具备足够独立训练组且本机有合规权重时启用，其余交回通用路径。模型 API 0 次。

## 分组和提名

先用一份匿名小偏好任务完整验收。课程研发只读原始训练成员，沿用前批共享标题分组的 6,608 行及五个外层集合。已见这些行的历史汇总，所以研究结果属于开发复验。每个外层路径只交给 Agent 一个匿名 ZIP，含外层以外的开发训练行。历史 1,693 行留出不进入此次五折的训练或评估。外层仅提供无标签特征；五份模型、决定及预测全部冻结后才统一评分。

每个路径按共享文本组哈希排序，用固定前缀 `crossfit-challenger-v1/` 和九等份，1 份提名，4 份 A，4 份 B。每个组只属于一个角色。初始双模型在 A 上拟合，在提名区预测。对本机每个合格挑战表示（原 L6、BGE、MPNet、RoBERTa）取得冻结特征的左右差并做逐行单位化，不训练候选分类头。将提名组按第二个哈希 `crossfit-nomination-v1/` 交替平分，各半计算特征向量与双模型概率残差的组等权均值，两均值的内积用于排序。正分首位获得唯一训练名额，同分用候选标识排序；没有正分可停止探索。该排名使用了训练反馈，单独计一次监督筛选。这个分数只是提名依据。

## 与谁比较

在 A 拟合三个模型预测 B，在 B 拟合三个模型预测 A，得到同样的两批折外概率。旧选择器使用既有 `choose` 在 A 的折外概率上学习，在 B 上确认。新选择器根据两个基础模型的硬预测是否分歧分两类，在每类内用单一权重决定向挑战者移动多少。以双模型均值为起点，按组等权最小化平方概率误差，权重限制在 0 到 1，分母加 1 向旧模型收缩。用 A 学出的权重评 B，用 B 学出的权重评 A。两半都改善 Brier，任一半准确率损失不超过一个组标准误，合并净增至少 max(5, ceil(0.002 × 折外行数)) 且合并准确率增益高于一个组标准误，才采用两个方向权重的平均值。其他情况保留双模型。这个开关只看训练反馈。

对照报告同一批重训模型上的双模型、原选择器、新选择器、无条件使用所学权重和等权三模型。默认单路径只重训交付所需成员。研究在决策封存后为对照补齐所需的第三个重训分类头，分别记录实际自主拟合与对照补拟合。每路径至多六次内层分类器拟合、三次最终拟合。五折合计至多 45 次，小任务验收另计至多 9 次。新旧各自两次连续融合拟合，原选择器另有两次离散筛选；按研究组记账，两臂共享的基础模型只计一次。运行时间和新进程预测耗时另记。缓存仅复用固定权重对单个输入的表示，词表、风格归一化和语料熟悉度均只在当前拟合行训练。

## 验收

相同外层组上列出每折改对、改错、净增，按标题组重抽样给出配对 95% 区间。主指标为新 Agent 实际交付相对同轮双模型的准确率。五折至少四折净增、总净增至少五题且区间下限大于零，才进入预先登记的新匿名任务性能复验。即使未晋级也保存全部负结果。每折用新的进程从原始无标签标题导出新 Agent 预测，与冻结的单模型概率组合对齐。课程指定验证、正式测试和 H 不进入该批次。
