# BH-03 · 两份 H2 训练输入已按预登记行号备好

两份匿名训练包各含 2,500 张训练地区的 EuroSAT 照片。A 的正式图片读入器逐张解码，5,000 张图的像素及行序全部与两个登记名单对应的原始 JPEG 一致。六份内部训练与评估工作文件也逐行核对了像素、标签和位置，均与 BH-02 已登记的那六份分区一致。

此次只为训练地区的文件名建立读取映射。封存留出地区的 1,000 张图片未打开、未解码，地理测试区域的图片也未读取。整包校验只读取压缩文件字节。本批训练、表征提取、模型选择、预测、评分和模型 API 请求均为零。外层性能需在双方锁定唯一部署策略后评价。
