# Task2 同目录调度与提分实验

在相同的三个候选和 1,372 行逐题预测下，原调度与组件调度都选十二层 MiniLM。将两套已训练的十二层模型等权组合，在 6,608 行训练内折外预测上多答对 12 对。三项改动均未达到预先写定的保留区准入条件。本轮新增监督拟合 0 次，模型 API 请求 0 次，新增 API 费用 ¥0。

## 十二层是否需要新调度才能选中

把词法、六层、十二层三个已训练模型的预测逐行交给仓库原版调度函数，三个模型分别答对 856、961、983 对。原版依次探索三个候选，选择十二层并停止。组件规则先看到词法和六层在 680 道探查题共同错了 123 道，超过 34 道的阈值，因而开放十二层。在另外 692 道复核题上，它也保住领先。限定相同目录后，两条路径最终指向同一个已交付模型，其训练内保留区已有结果为 1,223/1,693（72.24%）。这一观察支持让十二层方法早些进入共同目录。上轮整体方案多答对的 15 对，还不能归因于调度规则本身。

原版调用真实的动作和最终选型函数；组件侧对既有规则做三项菜单投影，并核对它能复现原八项记录的赢家。行号、文本、标签、数据包均核验一致。上轮两份六层实现有 2 条内部预测不同，这次统一使用组件侧同一份预测。回放不产生新的训练、重训或导出成绩。[同目录动作与复用模型校验值](../../research/b_accuracy_frontier_1123/equal_menu.json)

## 哪些改动提高了开发准确率

两次五折的每次划分均覆盖相同的 6,608 行。按共享标题建组，每行在两种划分中都由没有训练过该组的模型预测。十个原十二层对照的逐行分类均与已封存文件完全一致。十个模型中七个是各折完整重训的十二层模型，三个沿用该折内部初筛拟合，相关配对均采用同一权重。

| 改动 | 训练内结果 | 预先约定的判断 |
|---|---|---|
| 降低罕见词和字符片段的权重 | 两套划分净少对 13、19 对。平均下降 0.24 个百分点 | 两套均退步 |
| 两套折外十二层模型等权平均 | 4,678/6,608（70.79%）。最佳单套为 4,666/6,608（70.61%）。改对 156，对原本正确的 144 对作出错误预测 | 提升 0.18 个百分点。预先要求至少 0.20 个百分点，在这个样本量上需多答对 14 对 |
| 完整标题加上改写片段的局部语义 | 两套划分分别多对 5 对、少对 9 对，平均下降 0.03 个百分点。1,095 行触发额外视图 | 两套结果方向不同 |

在 4,874 个共享标题组上做 5,000 次配对重采样，双模型相对较强单套的差值区间为 −0.32 至 +0.68 个百分点。两个原模型同时错了 1,643 对。改写片段覆盖其中 358 对，其中 13 对在两个模型上都改对，同时有 14 对从两个都对变成两个都错。用整句学到的权重直接处理片段，纠错与新引入错误大致抵消。[冻结模型方案](B_accuracy_frontier_protocol_1123_zh.md) · [两项结果](../../research/b_accuracy_frontier_1123/heads_development.json) · [改写片段方案](B_edit_context_protocol_1123_zh.md) · [改写片段结果](../../research/b_accuracy_frontier_1123/edited_development.json)
