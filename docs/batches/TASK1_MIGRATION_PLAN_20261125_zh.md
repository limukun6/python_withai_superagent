# Task1 迁移计划：把一个未参与改动的原生类别表格任务冻进去

2026-11-25。依据 `docs/NEXT_STAGE_TASK1_AND_INTEGRATION_20261125_zh.md` 第四批"若 Task1 新方法通过开发门槛，再找一份未用于该改动选择的合法类别表格任务"。**先落计划，再取数据。**

## 1 这份计划的立场

- 这不是"未见测试"。公开数据集谁都能拿到，本文只主张：**本仓库此前没有用过它，也没用它做过任何选择**。
- 不拿它回灌调参。规则、候选、划分、预算在跑之前全部冻结。
- 不擅自把下载当"未见证据"：来源、许可、SHA-256 全部记录在包内与本文。

## 2 数据资格（开跑前必须逐条满足）

| 条件 | 要求 |
|---|---|
| 原生类别 | 特征是**字符串类别**，不是数值编码；不被我们转成数值再当"类别" |
| 规模 | ≥500 行，≥3 个类别特征 |
| 目标 | 二分类或不超过 5 类的多分类 |
| 许可 | 明确可再分发的开放许可，记录名称与链接 |
| 未使用 | 本仓库 `research/`、`data/` 中无同源记录（人工核对文件名与 SHA） |
| 可复算 | 下载包 SHA-256 固定，写出每一列的来源与类型 |

## 3 候选数据集（按优先级，只用一个）

| 优先级 | 数据集 | 行/列 | 许可 | 说明 |
|---|---|---|---:|---|
| 1 | UCI Car Evaluation（id 19） | 1,728 行 / 6 类别特征 / 4 类 | CC BY 4.0 | 纯类别、无缺失、无泄漏列 |
| 2 | UCI Tic-Tac-Toe Endgame（id 101） | 958 行 / 9 类别特征 / 2 类 | CC BY 4.0 | 特征全为 x/o/b |
| 3 | UCI Balance Scale（id 12） | 625 行 / 4 类别特征 / 3 类 | CC BY 4.0 | 特征取值少，类别偏好明显 |

取优先级 1；失败才顺延，且顺延必须写原因。

## 4 包构造（manifest-v1）

`car_evaluation_categorical.zip`：

- `train.csv` / `validation.csv`：80/20 分层，`random_state=20261125`，**原始行序在各自划分内保留**；
- 列：6 个原始类别列为 `input column`，`class` 为 target；
- `manifest.json` 记录：`metric: accuracy`、`modality: tabular`、`goal_sources.primary_metric: declared_manifest`、完整 `source` 块（数据集、UCI id、URL、许可、许可链接、引用、原始包 SHA-256、行数、缺失值数、划分说明、转换说明）。

**不做任何编码转换**：类别值原样写入 CSV，由执行器的类别处理负责。

## 5 冻结的规则（跑之前写定，跑完不改）

| 项 | 值 |
|---|---|
| 候选 | 基线 `catboost_depth8_reg3.0`；挑战者 `supported_field_interactions`（即 Task1 上过线的那条） |
| 划分 | 训练内三划分，种子 707 / 811 / 823，`grouped_partition` + `exact_rows` 分组 |
| 指标 | `accuracy` |
| fit 上限 | **6**（2 候选 × 3 划分，每个候选恰好 1 次）+ **2**（两个候选各在全训练集上重训一次，用于指定验证评分） |
| API | **0** |
| 指定验证（20%） | **不用于选择**；只在两边都跑完后各评分一次，作为迁移结果报告 |

> **开跑前修正（2026-11-25）**：原稿只写了 6 次 fit，但"指定验证评分"需要各候选在全训练集上重训一次，实际是 **6 + 2 = 8** 次。修正写在跑之前，选型判定仍只用那 6 次。

## 6 判定（预登记）

迁移成立的条件，与 Task1 上一致：

1. 挑战者在三个划分上平均 **≥ +0.5pp**；
2. 至少 **2/3** 划分为正；
3. 最差退化 **≤ 0.5pp**。

三条同时满足才算"迁移成功"。任一条不满足，就如实记录"未迁移成功"，**不改种子、不加候选、不重回 Task1 调参**。

另外单独报告：两个候选在该任务上的绝对准确率，用来判断这个任务本身是否饱和（若两者都接近上限，差异没有意义）。

## 7 停止规则

- 下载失败或许可不清 → 停止，换候选或放弃，不"找别的数据凑数"；
- 任一次 fit 失败 → 停止，不重试；
- 数据资格任一条不满足 → 停止。
