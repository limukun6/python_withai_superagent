# 按每行的情境选择对应行为字段

训练包中有五列共享相同的离散取值。例如两行中相同的 “1~3” 可以分别表示对两类服务的使用频次。普通树必须在不同列分别学会“当前服务的使用频次”有什么作用。本批验证能否从训练数据学出一一对应，把对应值放进同一个特征。

只看拟合侧，枚举具有相同取值集合的画像列组，以及类别数与组宽相同的情境列。对每个情境取值，检验哪个画像列对标签有预测力。评分在按画像分开的两个半集之间交叉计算，用匈牙利算法找一一匹配。保持原情境组合树和所有原始字段，额外添加对应值、它在画像中出现次数、它和其他情境字段的组合。对照组包含原模型、学出的对应关系、将关系整体循环错开一位的安慰剂。行序、字段名、数据集名均不作为匹配输入。

只访问课程训练成员。主实验固定 112801 五折的前三折，9 次分类器拟合，CPU 约 2–5 分钟，0 API。每折逐行核对原模型预测哈希与前批相同。晋级要求相对原模型平均 ≥0.5pp，至少两折上升，最差 ≥−0.5pp，且相对错位对照累计净增为正。通过后在剩余两折只跑原模型与真正匹配方案，另外 4fit；后两折累计净增为正且五折整体提升 ≥0.5pp 才进入统一入口验收。本批不打开指定验证及正式测试。
