# 在另一批从未用于台词调度评分的影片中复查第三划分策略

原 450 对诊断了开局锚定问题，第三划分策略也在该组达到 344/450。为检验选型是否依赖这一次划分，从此前台词开发池的 1,744 对中按影片与共享原文连通组另外留出一批。原 450 对全部跳过。新评估组从未用于此前台词任务的外层模型比较；这些影片先前属于训练池，整份公开语料也做过冻结标题模型的零样本评价。

- 使用此前规范化方式，先从研究包的原始数据指纹和开发划分重建 1,744 行，再以 `film-conflict-replication-1123-v1:` 加原连通组 ID 的 SHA-256 大端整数模 5 等于 0 划为新外层保留。训练与保留禁止共享影片或规范化台词。其余样本构成新的匿名训练包。模型只在这份更小的包内训练。种子固定为 27183，每条路径最多 11 次真实拟合，模型 API 0 次。
- 新版先跑完整生产入口。逐步将新版实际运行的状态交给旧调度器重放。如果每步动作直到停止均相同，且终局配置、选择和重训预算相同，两策略对应同一模型，复用逐行预测并明确标为已验证的共同路径。如果旧版先停止或改选，另从空目录真实跑完整旧版，两个模型都冻结后统一在新保留集评分。
- 主要输出为是否触发、两条路径的内部证据、真实拟合、逐行配对差与按影片连通组的区间。仅运行这一种新种子，不按结果寻找更有利的子集，不登录课程平台。
