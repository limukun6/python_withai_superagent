# Task2 自主交付与融合对照

从发布的 Task2 原包启动，普通入口在 8,301 个训练样本上完成建模。人提供任务和一个通用模型目录。Agent 根据任务契约和本机可用工具生成候选，根据内部划分的反馈挑选最后的模型。默认配置在发布验证集答对 **700/940（74.47%）**。相对此前 689/940 的历史记录，净增加 11 题。

| 实验条件 | 首轮可选动作 | 实际训练次数（含最终重训） | Agent 最终选择 | 发布验证集 |
| --- | ---: | ---: | --- | ---: |
| 普通入口，只给模型目录，使用默认训练与时间预算 | 68 | 10 | GTE-base | **700/940（74.47%）** |

| 旧目录，给足时间，从头运行 | 63 | 20 | BGE-small 与 MiniLM-L12 词频特征模型等权融合 | 697/940（74.15%） |
| 显式启用同组复核，引入 GTE-base | 68 | 19 | GTE-base 与 GTE-small 等权融合 | 693/940（73.72%） |

## 怎么复现普通入口

使用仓库的 Python 3.11 实验环境和同一批安装好的公开编码器。将每个可用模型放在通用目录下，保留发布方的文件和目录名。入口会核对文件并识别支持的模型。这次实验的完整可用资源和无提示启动证据见[实验登记](../research/paired_encoder_search_1127/resource_root_protocol.json)与[启动记录](../research/paired_encoder_search_1127/default_launch.json)。

~~~sh
python -m unified_agent solve <任务包> --weights-dir <通用模型目录> --run-dir <新运行目录> --prediction-input <无标签特征包> --output <预测CSV>
~~~

默认组尝试了 9 个方法，第 2 次尝试的 GTE-base 在主训练划分答对 1,228/1,693，第 8 次尝试的 GTE-small 答对 1,225。Agent 把剩余一次训练用于全量重训，最后选择的单模型只有主划分证据。已保存三个可迁移本地预测包，各自在新目录、新进程中离线重放出完全一致的 940 行。仓库保存源码、文件校验值和汇总，不附课程数据或权重。见[默认组重放凭据](../research/paired_encoder_search_1127/default_portable.json)、[大预算组重放凭据](../research/paired_encoder_search_1127/auto_portable.json)和[旧目录重放凭据](../research/paired_encoder_search_1127/legacy_portable.json)。

## 为什么有时融合，有时保留单模型

大预算组用三个训练划分比较相同入围者。GTE-base 单模型合计 71.82%，与 GTE-small 融合为 72.98%。三份划分里融合都更高，Agent 因此选择融合，在发布验证集上比普通单模型少答对 7 题。普通单模型相对上个 GTE-small 默认组改对 50 题，同时原本做对的 37 题改错。后续研发保留这两条完整轨迹，用新任务或封存划分验证这个差异。发布验证集已在项目研发中复用，不能据此认定不同任务的最优训练额度。[五组决策与评分记录](../research/paired_encoder_search_1127/delivery_results.json)

自动学习融合权重也做了对照。只用各次真实运行已经入围的模型，在探索划分上拟合权重，再拿两份独立的训练确认划分比较。28 次上限组的加权方案在两份划分合计少答对 17 题。五组均未达到预先登记的晋级条件，其中一组缺第二份确认记录。运行入口保留模型单用、等权融合和依反馈停止的能力。[权重实验](../research/paired_encoder_search_1127/within_run_weights_results.json)

相同决策流程也在一个已知的十分类图像开发任务上运行。Agent 用 16 次训练选出图像梯度特征逻辑回归、运行时生成的梯度提升与随机森林三个分类器。660 个训练留出位置上，最好的单模型答对 527 个，融合答对 550 个。用重载模型完成了另外 350 行预测，外部标签封存。此前只重命名并重排候选的检查保留相同选择，只交换两份独立确认反馈时最终选择改变。这两项分别提供跨任务运行和反馈会影响选择的证据。[图像运行](../research/paired_encoder_search_1127/auto_image_results.json) · [反馈检查](../research/paired_encoder_search_1127/feedback_audit_results.json)

这些实验保留任务类型、能力目录和预算方面的通用工程规则。操作者没有向运行入口指定获胜模型、模型顺序或融合成员。模型选择阶段只读课程 README 和训练表，训练完成后输入独立的无标签特征并封存预测，最后统一计算发布验证分。上述五组 Task2 从头运行合计 89 次实际训练，图像组另 16 次。两项均为本地计算，计费模型 API 请求 0，计费 token 0，API 费用 ¥0。课程正式测试及暂存的 H2 保持封存。[评分封存记录](../research/paired_encoder_search_1127/delivery_lock.json)
