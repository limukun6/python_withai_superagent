# 有方向的三分类文本能否按任务契约进入 Agent

选用 Marelli、Menini、Baroni、Bentivogli、Bernardi 与 Zamparelli 发布的 SICK 作为开发任务。只采用发布者标为 TRAIN 的行，特征只有原顺序的 sentence_A 和 sentence_B，目标为 entailment_AB，按作者定义区分 A 能推出 B、A 与 B 矛盾、二者中性。总体标签、反向标签、相关度、原始图注和来源标识都不作为特征。它与标题偏好、对称的同义判定分别测量。[发布者归档和校验值](https://zenodo.org/records/2787612) · [字段说明与许可](https://huggingface.co/datasets/RobZamp/sick/blob/main/README.md) · [作者论文](https://aclanthology.org/L14-1314/)

使用发布者 SICK.zip，登记其 MD5 `b03210036cc64a4cf1bc7a0525357001`，另记实际 SHA-256。如主文件将发布者的划分存于同一 TSV，仅用划分字段筛出 TRAIN 后才解码文本和目标。TRAIN 以外的样本不进入处理或评分。保留署名，在本机运行，交接仅包含代码和聚合证据。

本批先做零训练核验。用相同文本或相同来源图注将训练记录连成组，含间接连接。规范化一致使用去多余空白加 casefold。原句字段只供划分器隔开同源句子。注册种子 45101 的约五分之一外层，707、808、909 三个训练内分区。每一层核实组和来源均不相交，三类标签均存在。另外按现有统一入口默认的行分组生成同样种子的内部划分，直接统计共享句子、原图注组与重复整行各有多少，保留负结果。

制作有序关系任务的匿名训练包，核对正式解析器、指标、共同候选及其真实训练输入列。若登记的三个内部划分能用现有可信行号入口表达，保存其输入、行号与目录指纹，供随后一条自主路径。该批拟合、推理、模型 API 与评分均为零。正式课程数据与双方封存 H 均不参与。
