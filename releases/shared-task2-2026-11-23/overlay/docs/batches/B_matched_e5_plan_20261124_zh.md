# 在相同训练规模下复核历史双编码器组合

历史 Task2 高分使用 E5 和带词频的 MiniLM-L12 投票。在共同入口最新一次首轮评估上，这对组合比单模型少答对 8/1,693。单独检验该组合在之前固定的两块训练内数据上是否稳定有效。本次是研究者指定的历史方案复核。

复用已在同一批 4,971 对拟合的 MiniLM-L12 模型。只为相同训练行拟合共同目录里原有 E5 分类头，使用原登记的冻结权重、原参数和原有等权投票。与既有实验同样的 791、846 道开发题分开报告，组间和训练间均无相同标题。只读匿名训练包。两块数据均为使用过的开发区，结果只决定是否值得做新的确认。

每区按两个单模型中答对较多的一个为对照。若组合在两区都不退且合计至少多答对 8 道，才进入后续独立确认。否则结束这批固定分区上的选型。上限为一次实际分类器拟合、零次模型 API。两块数据的各自预测封存后统一计分，两模型的各自成绩与组合无论高低都登记。
