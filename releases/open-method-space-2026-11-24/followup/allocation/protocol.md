# 开放模型后怎样分配有限探索机会

这项已训练模型回放只回答探索机会的分配问题。开放实验在两份已发布开发基准上的对照结果已知。以下规则在本项四折评分前登记，课程指定验证、正式测试和此前用于交付的留出数据都不参与。使用数值 Wine、短信、手写数字、优惠券和标题五个任务的主训练内划分。每个任务合并开放组与固定目录组实际试过、具有同一训练与评分行指纹的配置，重复时固定取旧组预测。范围限于这些有完整观测的模型，不能推断未执行方案的表现。

将主划分按原始特征连通组摘要加前缀 `b-open-allocation-fold-20261124/` 取余 4。每个任务做四次选择，三个折提供反馈，另一个折评分，分类器本身在全部这些折之外训练。两种策略每次最多观察四个不同配置，同时至少留出一个未试配置。首项用同一证据选择器，最后从已试候选中选当前反馈指标最高者，配置摘要打破平手。

原策略使用已冻结的全目录估分。新策略不规定模型配额。把来源分为运行时生成及已有可执行两类，按来源已取得的分数及测量不足程度修正每个候选的估分。来源得分以全体已观测分数均值为一个先验观测；修正量为来源后验均值减全局均值的一半，加上原探索系数除以该来源已试数加一的平方根。两路对照看见同样的备选与反馈种类，无人工指定试验。各任务按原主指标报告拼合四折的成绩、动作与赢家变化。至少三项改善且没有一项下降超过 0.02，才支持为此单独新增真实训练。新增监督拟合和模型 API 均为零。
