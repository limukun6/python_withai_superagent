# 只在第三个模型可能改变标签时才运行它

重新分组的四条三成员路径，普通原始文本导出比双模型耗时更久。本轮不再试图从已反复使用的开发标签上寻找阈值，而检验在输出二元答案时，能否省去一部分必然不影响投票的编码。登记时尚未统计能跳过的行数、逐行差异或配对耗时。

适用条件为已交付、正类列明确的三个二元概率的等权平均。先算两个参考成员，概率和记为 s。若 s 明显大于 1.5，则第三个成员即使给 0 也无法使结果低于一半；若 s 明显小于 0.5，则给 1 也无法使结果高于一半。只对其余行计算第三个成员。边界和边界两侧 64 个 float64 机器精度都留给三个模型。子批推理可能改变浮点计算顺序，如果其中任何一个最终概率距 0.5 不超过 0.00002，就整批重算第三成员，以原批次输出确定待定行。返回完整概率时继续计算三个模型。相同文本及原投票的平分规则完整保留。

先用构造数值与假成员覆盖四种边界、平分、左右互换、概率要求、空输入、无法短路和全部可跳过。再使用第二套冷启动实际批准的四个模型包及各自原始匿名外层文本。每条路径在两个新进程中分别导出完整计算与按需计算的标签，四折按出现顺序交替先后；仅当源码、模型成员、输入及两份导出均核对后才汇总。报告每个新进程的墙钟、实际送进第三个编码器的行数和触发整批补算的次数，区分工作量和实测耗时。逐行验收要求两种输出及既有交付三者完全相同。只有四折总耗时有所下降且没有任何行差异，才作为可选择的交付优化。此项零拟合、零付费模型 API、零外层标签使用。保留原三成员完整概率接口。
