# 对尚未参与措辞检验的标题组确认“更常见措辞”方向

事先固定的“更少见措辞胜出”在四个内部划分上分别答对 554/1,332、580/1,379、568/1,295、579/1,314，作为十二层不确定时的修正合并少对 28 对。以上是探索依据。现单独冻结反向假设：保持相同分词、平滑和语料规则，预测平均信息量较低的标题获得更高偏好。

确认使用种子 8123 与 18643 各自的第二复核分区。事先去掉出现在上一轮四个评估分区中的全部共享标题组。两次第二复核均出现的组固定归入 8123，使主分析每条原始行和每个组只出现一次。每一折的词频模型仍仅使用本折训练文本，真实输赢只用于评分。先完成标签无关的组清单、顺序与预测指纹，再打开相应标签。报告两个分区及合并正确率，与 50% 的差值按共享标题组进行 5,000 次配对重采样。同时报告仅用该折训练标签确定的多数类参照，并单列等信息量平局。两部分均超过 50%，且合并区间下界大于 0 时才将“熟悉度”列为值得作为通用可学习特征的线索。

若已有完全相同第二复核划分的十二层检查点，则另报告预先固定的低置信修正，同样使用 0.05 概率距离与 0.5 纳特差值。缺少检查点即记为缺测。本批新增分类器拟合、模型 API、外层保留区和课程验证访问均为 0。本项在同一课程训练任务中验证新假设，不能当作全新任务上的效果。
