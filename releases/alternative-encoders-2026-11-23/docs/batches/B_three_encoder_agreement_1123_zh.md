# 三个已训练编码器在分歧样本上的表现

在本轮标准入口仍在训练、两条新路径的保留区预测尚未生成时，追加一个零拟合诊断。任务是检验“两个不同编码器都反对原模型时才改答案”能否减少错判。使用原生十二层 MiniLM、E5 和 BGE 的首个主分区模型，每个模型训练行完全相同，保留区统一取既有训练内 1,693 行。两条研究路径共用的 MiniLM 必须核对原逐行预测和参数。仅当三种方法都实际训练过才评估，不补训。

在三个方法均有可核验检查点的内部分区逐个比较多数票与三个单模型，列出两名新成员共同推翻 MiniLM 后的改对数、改错数。并将三份主分区模型用于同一训练内保留区，标签打开前固定各自的预测和哈希，按共享标题组给出对 MiniLM 的成对区间。单模型分数也取这三份同训练量的检查点。结果属于固定的事后研究策略，不能算标准 Agent 自主选择了投票。它没有课程指定验证资格，课程正式测试继续封存。

沿用原计划的双模型等权概率平均，同时记录每个配对的概率和硬预测是否复现原试验。合并分区按观测条数计，只统计两法都实际训练过的分区；相同标题跨分区重复时不作为独立总体。概率恰好相等的组合采用与正式偏好输出一致的字典序裁决。若两个附加编码器只在主分区相遇，三模型的跨分区证据仍然不足。本轮诊断新增实际拟合和模型 API 预算均为 0。
