# 在通用冻结句向量上学习非线性分类或偏好

两份标题训练内划分上，改变词字符方法的首个参数后，Agent 最终都保留了原来的词字符与线性 MiniLM 组合。检验另一种方法能力。给所有单篇文本分类和有方向偏好的文本对提供同一项可选方法，让 Agent 在原候选仍可用时自行选择。匿名输入仅依据任务合同、既有数据和已核验的本地编码器能力开放。两段语义等价判断仍走原有对称方法。

沿用原词、字符、风格与固定 MiniLM 向量，在原向量旁增加 512 个固定种子的高斯径向基随机傅里叶特征。核的带宽从当前优化输入中按文本散列次序最多取 128 个不同文本，取非零平方欧氏距离中位数，使该距离的核相似度为 0.5。样本全相同则采用有限的固定带宽。使用既定种子 12271。文本对始终以两侧单独映射后的差值表示，单篇文本使用自身映射。保留原有分类器、同一 C=0.3、偏好翻转增强和单次监督拟合。新增带宽采样消耗的本地编码 token 单独记录。登记后不依据成绩挑选宽度或维度。

1. **B-TEXT-KERNEL-01** 验证旧特征输出和菜单次序、两侧交换后的特征、只取优化文本、不使用标签来定带宽、未知文本可预测、冻结模型可搬迁、缺依赖与错误合同不暴露候选。合成检查区分于开发成绩。实际模型小试只使用公开通用文本样本，最多两次监督拟合。旧模型仍可在新研究代码上读取，重算预测文件须相同。
2. **B-TEXT-KERNEL-02** 对两份已登记标题划分 45101 和 45102，仅在原完整菜单末尾加入一个候选。与已核验 A29 原目录两条轨迹对照。每个新路径至多 11 次实际拟合含重训，共至多 22 次。两个模型都冻结后才读取训练内留出标签，两次独立进程导出。报告是否被 Agent 尝试或晋级、额外消耗、逐行准确率得失及未获选结果。
3. **B-TEXT-KERNEL-03** 使用此前登记的公开 SMS 单篇文本任务，无论标题是否有收益均执行一次完整的迁移对照。术语标签来自原任务合同，主指标 macro-F1。与独立登记的原策略相比较，双方同菜单基础、划分、种子及 1,200 秒总时限，新路径至多 11 次实际拟合含重训。仅在模型冻结后计分，并核验搬迁预测。零模型 API，课程正式验证、测试及 H 均封存。
