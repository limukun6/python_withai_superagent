# BC1-02 · 按 A11 正式入口重新核对 B 的两组六臂实验

仅做训练前验收，不启动正式 C1。两任务复用 BC1-01 锁定的分组顺序、候选全集、第一候选、每路径上限和 BP-02 固定的数据输入。检查 A11 合入版本是否能在相同的训练数据与分区下接受 L0、L1、R0、R1、E0、E1 各自的命令组合，输出每个任务逐组的准备情况。固定使用 `ab-fixed`，动态使用 `ab-v1`；保留每个预算和暂未接通组合的实际拒绝原因。读取训练输入及行清单，外层特征仅核对字节摘要，不读取外层标签。

同一任务下的六组必须获得相同目录和第一候选，两个输入必须与此前登记的 23 项和 5 项目录逐项相符。用正式分区写入函数生成三份 worker 输入，以实际训练行序、评估行序、标签及工作文件身份核对 BP-02 同环境的结果。此轮新增训练、模型调用和外层评分上限均为零。提交改变时保存新回执，不能把旧开发路径记成最终六组实跑。
