# 十二层候选接入标准调度

在原 `superagent run --scheduler ab-v1 --portfolio ab-v1` 上增加 `--preference-catalog deep`，即可向调度提供十二层 MiniLM 的词法与语义分类器。使用 `--preference-catalog deep-edit` 时同时提供一个学习改写片段权重的候选。每次探索、复核或重训任一新增候选均计一次实际监督拟合。设定本地编码器目录 `SUPERAGENT_DEEP_MINILM_WEIGHTS`；程序按文件大小和 SHA-256 验证三份资产。两个新增方法只在契约允许交换后标签翻转的二分类文本对上出现。固定、动态和 Flash 调度共用目录生成器。本轮实测使用本地动态调度。

在当前匿名任务和资产配置下，普通目录有 32 项，开放十二层后有 33 项，进一步开放改写头后有 34 项。两项新增候选均支持原生模型包和 `superagent predict`，交付只依赖已声明的十二层本地权重。使用历史已拟合的线性头及其词表和缩放器，把旧权重迁入新接口。两个候选通过独立进程分别复现了旧模型在 1,372 道内部题上的每一条分类结果，概率最大绝对差为 3.59 × 10⁻⁷。改写头的额外系数在这项交付测试中设为零。在另外 8 对触发和 8 对回退输入上，交换左右标题均使特征翻转，所有回退输入的新增特征均为零。[目录与新进程验收](../../research/b_accuracy_frontier_1123/native_delivery.json)

使用历史种子 707 的原生六层模型观测和经实际预测核对的十二层观测，额外回放全目录动作。32 项原版完整复现了 9 次搜索或复核和最后的停止及选择。33 项版本在请求一个没有匹配档案的字符候选时结束回放。34 项版本第四个动作就要求实际训练改写头；该回放在这步结束。新种子下的正式运行另按配对协议计数和评分。[完整目录回放](../../research/b_accuracy_frontier_1123/full_catalog_replay.json) · [新配对协议](B_shared_preference_pair_protocol_1123_zh.md)

进一步核对了 6,608 对开发标题中的全部观测。按原始文本精确匹配，共出现 11,505 条不同标题，6,608 个标题对均互不重复；按标签所指的赢家连接标题，也没有有向环。已见错误无法通过“同一对标题有相反标签”或“已知胜负互相矛盾”来解释。这项检查仅描述已观察标签之间的一致性；对新标题的可达准确率仍需用未参加拟合的样本估计。[开发标签一致性记录](../../research/b_accuracy_frontier_1123/title_consistency.json)
