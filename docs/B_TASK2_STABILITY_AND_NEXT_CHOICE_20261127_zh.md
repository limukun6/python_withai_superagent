# 三模型融合的稳定性，以及下一次该试哪个编码器

### 把同一批训练题重新分组

冻结三个由 Agent 实际选出的模型组合，在 8,301 条课程训练题上做两次独立随机分组，每次五折。共享标题的题始终在同一组。每道题每次只由没有见过该组的模型预测，一共实际拟合 30 次。

| 已冻结的组合 | 第一次答对 | 第二次答对 |
| --- | ---: | ---: |
| BGE-small、GTE-base 等权 | 6,081 | 6,058 |
| GTE-base 加相似案例投票 | 6,056 | 6,042 |
| BGE-small、GTE-base 加相似案例投票 | **6,104** | **6,069** |

第三种在十折中有七折超过双编码器，两次总增益分别为 0.28 和 0.13 个百分点。按标题组重采样的 95% 区间分别为 −0.13 至 +0.71 和 −0.28 至 +0.56 个百分点。与 GTE-base 加案例投票相比，两次多答对 48 条和 27 条。协议要求每次对两个对照都至少提高 0.30 个百分点，这次没有达标。此前课程指定验证的 710/940 继续保留。这次没有打开课程指定验证答案、正式测试或 H2。[划分及三组配置](../research/paired_encoder_search_1127/portfolio_stability_inputs.json) · [十折结果](../research/paired_encoder_search_1127/portfolio_stability_results.json)

### 能否从两套编码器的向量差异预测下一次该试谁

在十个实际跑过的编码器上回放决策。分别取 623 条和 6,608 条训练规模，每次给两条已有实验反馈，让调度器选择下一条可尝试的方法，再用另一半训练内留出题验证。向量差异由 96 对无标签训练文本计算。每种训练规模有 90 次回放，这些回放共享数据和已训练模型。

加入向量差异后，小训练样本的下一步选择有 83/90 次变化，留出准确率平均增加 0.51 个百分点，但两半方向相反。大样本有 81/90 次变化，平均降低 0.43 个百分点，两半都下降。生产调度继续使用原有证据。这项回放新增拟合 0 次、模型 API 0 次。[实验协议](../research/paired_encoder_search_1127/representation_geometry_protocol.json) · [分规模结果](../research/paired_encoder_search_1127/representation_geometry_results.json)
