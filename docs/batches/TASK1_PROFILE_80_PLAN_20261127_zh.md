# Task1 冲击 80% 的重复画像实验

2026-11-27。用户重新开启独立性能探索。生产起点 f0f3593。队友接手的 SA26 和共享计费账本继续由队友负责。本轮只在本地运行。

## 假设与对照

历史统一入口在指定验证集为 1533/2030，80% 为 1624/2030。实际训练数组有 21 列。先期无标签巡检发现有一组反复出现的属性组合。本轮检验能否只从拟合侧的列值自动发现这样的组合，进而利用同一组合在其他情境中已有的标签。属性相同不能证明同一人的身份。算法不得使用列名、题名、画像列位置、外部数据或行号预测标签。

基线使用既有 supported_field_interactions。挑战者保留相同的字段交叉和 CatBoost 配置，增加重复属性组合的历史接受比例、样本数，以及同一组合在不同情境取值下的历史。模型只支持二分类类别表格。外层每个留出样本的历史只来自拟合侧。构造拟合样本的历史时，再按完整特征行分八折，整折排除。无匹配使用平滑先验并显式传入零支持度。

## 运行与判据

1. 只打开原包 C_train 和 y_train。先按已有 exact_rows 协议的 707、811、823 三个划分，同划分比较两种方法。完整相同的行不能跨边。另做一次按自动发现的组合整体留出的压力测试。此处允许用训练包全体无标签特征定义划分，其余每次拟合独立发现组合。记录压力测试的实际重合率。
2. 四划分各两次分类器拟合，共 8 次。历史编码使用计数，不拟合额外分类器。记录拟合尝试数、耗时、逐项配对改对和改错、历史覆盖率、索引指纹。输出不包含原始画像、标签或模型。指定验证和正式测试均封存。
3. 三个普通划分的平均增益达 1 个百分点且至少两个划分更好，再单独登记候选资格和生产入口验证。压力测试决定适用范围。平均增益不达标就不以此批打开指定验证。达到 80% 要分别给出在哪个划分、由哪个入口取得。任何正式成绩仍需冻结版本后的 test。
4. 预算为 0 API、0 元；每个模型沿用 600 轮、深度 6。预计 CPU 5–20 分钟。输出目录须全新，保留失败记录。本批是方法配对研究，后续统一入口才能证明 Agent 会自主选用。
