# A25 整合包的空仓库验收

在空的独立 Git 仓库里只接收 A25 基线和 B 交接包，检验两个提交、生产源码和工作树状态。运行一次匿名的本地动态任务，训练数据 256 行，31 行独立无标签输入。采用正式 C1 的运行参数 strict/full、707、每路径 1,200 秒、每次 300 秒，至多 11 次监督拟合含重训。真实 worker 计数与独立观测一致，调用 A 的统一入口自主探索和重训。收集实际动作种类，不按动作数或赢家调整随机种子。用 B 的正式回执验收器检查本地无模型调用及 strict 身份，同时验收原位置与搬迁后的新进程逐行预测相同。

工程夹具没有评价标签，0 次模型 API，无课程验证、正式测试或 H 评分。既有正式数据的分数不因此新增。验收后在最终交接提交上核对代码树与已运行的版本，若仅增加脱敏文档和实验回执，可直接用冻结模型再验收，无需重复训练。
