# 首轮选择对评估样本的敏感度

正式新种子出现搭档并列。在把并列规则推广前，使用已拟合模型检查同一份反馈的抽样波动。分别读取旧种子 8123 的 E5、BGE 两份四候选开局和新种子 18643 的 E5 开局，保持真实训练行、候选序及方法不变。对每种环境，在同一主分区按共享标题的连通组重采样 5,000 次，每次取与原分区相同数量的组，有放回；组内成对行一起计数。每次重新计算领跑单模型、与它组合后最强的搭档、是否超过原定 0.2 个百分点门槛。

报告各领跑者、各无序组合与放弃组合的频次，以及原始选择重复出现的比例。每组观测来自相同已拟合模型，本项衡量验证样本变化对决策的影响。三份历史的结果不合并成独立重复。新增监督拟合、模型 API 和额外外部验证均为 0。
