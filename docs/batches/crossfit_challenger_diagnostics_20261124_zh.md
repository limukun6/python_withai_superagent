# 如何区分提名、融合及最后决定的问题

在五折训练启动后、打开任何外层评分之前，登记一次描述性诊断。只使用本批已冻结的逐行概率，划分和晋级条件与主实验一致。诊断不训练新的分类头，不调整权重或筛选规则。

1. 对每一折，比较交叉反馈中的权重净收益，与同一折整批重训后强制启用该权重的外层净收益。再列实际 Agent 的外层净收益。它们能区分“融合本身有用”和“启动条件能识别它”。两次评分的数据量不同，分别报告分母。
2. 在双模型原先意见相同、意见不同两类中，分别数第三模型与基线意见相反的行。第三模型会纠正几题、带来几题新错误？在这些行中，Agent 实际改对或改错多少？计算强制使用所学权重的同口径结果。仅计有提名的折。
3. 展示每折候选在提名样本上的残差得分与排序。只有获提名者有新训练的分类头，其余候选的假设成绩没有观测。配对区间和正式晋级仍只看预先指定的 Agent 对同轮双模型结果。
