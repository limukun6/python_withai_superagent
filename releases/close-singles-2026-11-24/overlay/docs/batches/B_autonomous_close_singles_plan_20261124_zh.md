# 只有单模型的优劣仍不清楚时，Agent 是否应该继续复核

以共同提交 `449b766eb4a29af2f4020092ab6b3eab425d25be` 为对照。适用范围是统一入口已有的本地二元有向文本偏好、自适应组合调度和 accuracy。两组都能访问相同候选、此前已核验的通用编码器和训练内反馈。只在实验组显式启用新选项。

原调度要再探索，或已有一个值得复核的组合，就沿原动作继续。原调度准备停止且从未进入组合复核时，才检查同一轮的所有单模型。候选必须确实改对过领先者的错题，且低于领先者的准确率差不超过 1.96 倍配对的标题组标准误。在满足条件者中，先选改对领先者错题数最多的，平手时先看总正确数，再按候选 ID。对实际看到的预测做比较，候选名、编码器名和任务名均不决定优先级。没有符合者、没有未见标题组、或剩余额度不够两个比较加一次最终重训，就保留原动作。

在同一已登记确认区重新拟合领先者和挑战者。确认时仅计首轮从未见过的标题组。只有挑战者在这些组上净增正确题数，并且把首轮与新组各算一次后总准确率净增至少 0.2 个百分点，才替换领先者。其余情形继续交付原单模型。两组使用相同 seed 18643、`ab-adaptive-complement`、`deep-e5-familiarity`，均开启未探索编码器覆盖，每条最多 10 次实际分类器拟合，含重训，试验限 300 秒，路径限 1,200 秒，语言模型 API 为零。原有单冲突复核及推理路由均保持默认配置。

从已经封存的 8,301 行课程训练包取数据。最近三项研究中已用于计分的四块小分区及首轮 1,693 行的所有标题连通组，均不参加本轮留出。剩下的组按 `b-close-single-outer-20261124-v1/` 加组键做 SHA-256，整数对 4 的余数为 0 时纳入新的训练内留出，其余全部用于两条自主路径。只把匿名训练子包交给 Agent。两个模型和动作都封存后，在新进程预测相同的无标签留出，各做两次导出，之后再统一读取训练内答案。不读取课程 940 行验证、正式测试或 H 的成绩。这个留出只相对列出的研究分区互斥，来自同一份开发数据。

提前写下判断标准。一次完整自主对照要同时出现新动作、交付模型在留出净增至少 0.5 个百分点、按标题组配对重抽样的 95% 区间下端大于零，才启动第二任务的从头确认。若两组交付相同，报告实际多用了几次拟合。另以已封存的完整 Task2 和电影台词历史检查默认动作与新规则的适用边界，历史重放单列。预算先留给这一对正式运行，上限合计 20 次真实拟合，学校 API 0 次。
