# A 的真实 Flash 轨迹里，分歧出现后会怎样

本批固定使用 A29 已发布的两任务、六组共 12 条完整运行。四个 Flash 组的原提案已经发生，只回放实际选择。逐步核对登记的候选与参数、动作、首轮和复核分区的行序/标签/载荷指纹、worker 成绩与真实拟合数、最终晋级依据。A 的公开紧凑记录不带 B 本机所用的完整逐行预测，因此这里只复算基于已签名观测的在位模型与停止条件，不声称独立重算每条预测或再现 Flash 的自然语言答复。保持源数据的正式验证分数和测试文件封存，本批只读训练内部的分数。

检验 B-STOPPING-PREFIX-01 原先登记的两条规则，不从 A 的结果再设阈值。分别是「至少三种候选、连续三个观测后在位模型相同」及「额外要求在位模型已与一位对手在同一确认划分比较过」。记录若提早停止会剩多少原拟合、是否错过最终赢家。在两发布任务、三种提案方式与两种分配策略下分别报告，不把共用划分和相同候选的路径当独立任务。

再逐次查找当前在位模型与一个挑战者在首轮和第一次复核各赢一次的情况。严格一胜一负即纳入，无论后来谁赢。每路径每对候选只在首次满足时登记；排除已经完成两方第二次复核的重复时点。记录下一动作、到原结束时是否完成双方第二次复核、是否换成该挑战者，以及两候选在哪些划分胜出。无观测就记缺测。对于还可完成两方复核的情况，能用的名额按原账本扣除重训计算。保留一方已有第二次观测的情形。预计节省是事后的预算模拟，不抵销真实旧账。本批新增拟合、预测、API 请求均为零。
