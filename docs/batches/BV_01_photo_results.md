# BV-01 · Agent 在五类真实照片上选用了通用视觉特征

同一批 200 张内部留出照片上，原目录的自主路径答对 85 张，可用视觉编码器的路径答对 174 张，准确率从 42.5% 提高到 87.0%。两条路径由 A 的正式入口执行。研究者控制候选资源是否可用，组内的实验顺序、复核、停止和最后的模型均由本地调度及共同选型规则决定。

| 真实运行 | 正式入口选定的模型 | 探索 / 复核 / 最终重训 | 训练次数 | 准确率 | 入口耗时 |
|---|---|---|---:|---:|---:|
| 原有像素与梯度目录 | RBF 核 SVM，C=1 | 5 / 5 / 1 | 11 | 85/200，42.5% | 26.7 秒 |
| 同目录加冻结 MobileNetV3-Small | 固定的通用图像特征 + 逻辑回归 | 9 / 0 / 1 | 10 | 174/200，87.0% | 58.1 秒 |

两个目录的前两次探索相同。第三次，扩展组选到了预先实现的视觉候选，在 160 张训练内部探索照片上答对 134 张（83.75%）。之后还尝试了 6 个其他配置。其他候选的首轮最高分为 52.5%，运行结束时保留视觉候选。这一组没有进行第二份训练内复核。两模型均在打开外层成绩前冻结，搬迁后的新进程均逐行复现 200 条预测。两组共 21 次真实监督训练，GPU 训练与模型 API 均为零，新增模型 API 费用为 0 元。计时时本机另有回归测试运行。

|---|---:|---:|---:|

逐行对照为新答对 95 张、新答错 6 张、两组都对 79 张、都错 20 张。800 张用于优化，200 张用于开发留出。全部 1,000 张有不同的原图编号、署名 Flickr 账号和解码像素。所有照片都来自 TensorFlow Flowers 官方训练来源。编码器预训练使用 ImageNet-1K，这里没有逐照片核实它的原始预训练集与 Flowers 是否重叠。这个成绩支持该候选在这一份照片开发样本上的价值。项目的封存迁移任务、课程验证及正式测试均未用于本实验。[数据来源](https://www.tensorflow.org/datasets/catalog/tf_flowers) · [权重说明](https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.mobilenet_v3_small.html)

正式运行的程序与协议在 `b17f30d`。在登记的 CPython 3.11 环境安装 `requirements-ab-vision-tested.txt` 中的依赖，将 `SUPERAGENT_MOBILENET_V3_SMALL_WEIGHTS` 指向 PyTorch 官方 `mobilenet_v3_small-047dcff4.pth`，即可让合适的图片任务在共同菜单中获得此候选。本批由开发准备过程下载权重，Agent 运行时离线决策和提取特征。最终模型文件保存线性分类器，预测需提供同一份权重。SHA-256 为 `047dcff4addef86ea5bc2eff13c9614dc11f47ab1160d0a71a25e7db994f4e1f`。[官方下载](https://download.pytorch.org/models/mobilenet_v3_small-047dcff4.pth)
