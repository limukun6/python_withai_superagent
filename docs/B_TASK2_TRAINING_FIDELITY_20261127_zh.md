# 用小样本成绩提前淘汰，可靠性有多高

取两次自主实验都实际跑过的 13 种方法，核对训练配置完全一致。较小的模型只见过 623 行，较大的见过 6,608 行。让两边都回答相同的 256 个训练内留出标题对，涉及 187 个标题组。所有这些组都没有参加任一模型的拟合。小模型也在原 145 行上重放，以核对读取的是当时那一个分类器。

| 提名依据 | 第一名 | 它训练到大样本后在同一 256 行上的答对数 | 前三名包含大样本最佳 |
| --- | --- | ---: | --- |
| 小模型在原 145 行内部验证 | E5-small，100/145 | 185/256 | 否 |
| 小模型在公用的 256 行评价 | BGE-small，171/256 | 183/256 | 否 |
| 大模型在公用的 256 行评价 | GTE-small 二次特征头，187/256 | 187/256 | 是 |

在同题同顺序下，小模型与大模型的排名相关系数为 0.196。按标题组重抽样 1,000 次，中央 95% 范围为 −0.291 至 0.677。只留小模型前三名，按两种提名方法分别会错过 2、4 道题的潜在空间。这个比较来自已经研究过的一批训练数据，且只覆盖两边都实际试过的方法。实验支持暂缓按小样本名次硬淘汰，无法给出所有新任务上的误淘汰率。

这次复用已训练模型。新增分类器拟合 0 次，模型 API 0 次。课程指定验证、正式测试与 H2 均未使用。
