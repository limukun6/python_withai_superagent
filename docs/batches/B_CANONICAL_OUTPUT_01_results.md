# 同一对标题交换顺序后的概率交付验收

在两个真实的冻结赢家上，项目原生预测入口分别导出了原目录、搬迁目录和交换方向的预测。两次开发留出的 3,358 行中，原方向的标签文件与原模型逐字节一致。交换两个不同标题后，3,358 个标签全部翻转，每一行正反两个方向的胜出概率相加都等于 1。用相同标题构成的 10 个额外输入都得到 0.5。

| 原模型与开发划分 | 行数 | 原模型最大概率互补误差 | 加适配器后 | 分批预测最大概率差 |
|---|---:|---:|---:|---:|
| MiniLM 加非线性文本特征，45101 | 1,672 | 0.00003749 | 0 | 0.00000037 以内 |
| MiniLM 加词面特征，45102 | 1,686 | 0.00012786 | 0 | 0.00000026 以内 |

每个模型各做了 3 次独立进程的原生标签导出，另在原目录和搬迁目录各启动 1 个进程检查概率，两份目录的概率指纹相同。这项变化改善了输出一致性；原方向预测完全相同，因此这两份预测的准确率变化为 0 个百分点。本批只使用无标签输入、既有预测和冻结权重，没有重新选模或读取留出标签。

供 A 评估的接口是 `python -m tools.ab_export_canonical_preference --run-dir SOURCE --output NEW`。适配器目前支持任务明确声明为二选一偏好、且原交付物是已拟合二分类 sklearn Pipeline 的模型。源模型指纹和原选择分数的归属均写进新交付记录。新目录仍可用 `python -m superagent predict FEATURES --run-dir NEW --output ROWS` 导出。本分支将适配留作可选的交付步骤，由双方决定是否接入正式流程。
