# 对 B2 的真实下一步做离线消融

在 B2-01 六条已完成路径的每个动作前，恢复该步真实输入、已签名的内层行、实际预测、方法目录及原预算，用当时的策略完整复现执行器收到的六个动作字段。原始运行须逐步完全一致，再在同一状态同时比较开启与关闭组合回调。记录实际动作类型、候选、划分是否改变。原先仅增加目录的组也做同样比较。不同选择之后不拼造下一步或声称下游分数变化。

对确实产生组合提议的历史状态，每次仅撤去一个被引用试验的逐行预测证明，保留原始分数、预算和其余证据，重新执行一次。报告剩余证据能否支持提议，是否改变下个候选或动作。使用另一个副本翻转一条被引用的预测并保留其旧指纹，要求调度器拒绝继续训练。两个改动均为只读的输入敏感性检查，另列于真实结果之外。

从两个真实组合组取每个被提议引用的唯一试验，重新加载已训练的模型及对应划分，直接在当时的训练行和搜索行重算主分，并重算原搜索行逐项预测指纹。这能查清用于选分析器与估计过拟合的信号是否来自已训练模型。只使用已经完成的训练内记录，零新拟合、零模型 API、零新外层评分。写出协议、结果和状态。
