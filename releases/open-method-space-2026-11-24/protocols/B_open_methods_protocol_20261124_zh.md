# 未知分类任务的运行时模型生成实验

课程第 2 节列出表格、文本和图像，包含二分类和多分类；指标和数据划分随任务发布。用一个入口和同一套决策代码读取匿名任务契约、训练数据画像和训练内反馈。两组均使用原有方法。开放组还在本机已安装的 sklearn 中发现可独立拟合的分类器，根据所给指标、输入表示及预算判断兼容性，再生成预处理、投影、分类器和参数的完整配置。已有路线继续参与竞争。后续探索、复核、停止和最终重训都由 Agent 决定。开发者不指派具体模型或动作次序。该范围不涵盖任意 Python 程序、所有数据格式或未来所有任务。

先在独立的匿名合成分类输入上，从原生命令行验收运行、实际拟合与跨进程预测，再开展以下三组完整本地配对。两边分别使用固定目录的证据调度与同一调度加运行时生成，均使用同一输入、种子、核数、单次 180 秒、每路径 600 秒以及最多 6 次真实分类器拟合（含最终重训）。冒烟最多 5 次。各轮最多 41 次真实拟合，全程模型 API 为零。每个方法的训练只见同一内部划分的训练行，收到的评分只来自训练内开发行。记录新配置产生在哪一步、此前是否在目录内、是否真正执行及选定。单纯高分不作为通用性的证明。

真实任务分别为本地 sklearn Wine 三类数值表的 macro-F1、UCI SMS Spam Collection 二分类单文本的 macro-F1、sklearn Digits 十类图像的准确率。为让文本实验成本与前两者同量级，SMS 先根据规范化文本组摘要取固定的八分之三。用特征组摘要加固定前缀 `b-open-space-20261124/v1/` 取余 5，余 0 留出，其余作为原生入口的训练输入。划分不使用标签或模型结果。数据集名只出现在外部准备与报告中，Agent 文件和列名匿名。三者都是开发数据，Digits 不占用正式 H2。两组在各自训练输入内重新划分和选择。所有实际模型统一封存后，每个模型对无标签包做两次独立进程导出，再一次性评分。某一路失败保留实际已发生的用量及失败阶段。没有同一划分对照时不宣称进步。报告所有结果，不按留出成绩挑版本。
