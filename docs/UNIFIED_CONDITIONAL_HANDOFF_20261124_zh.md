# Task2 的第三个模型什么时候值得听

统一版继续交付 MiniLM-L12（含语料熟悉度特征）与 E5-small 的等权双模型，上次课程指定验证答对 **689/940（73.30%）**。本轮让 Agent 学习第三个已训练模型的强项，再用另一批训练反馈决定要不要采用。四种方法和一次增加反馈量的迭代，都没有达到预登记的提分标准。本轮所有成绩都来自课程训练集。[已有指定验证记录](UNIFIED_AGENT_20261124_zh.md) · [本轮逐行记录](../research/unified_handoff_1124/)

## 从那 40 道题开始

在历史训练留出的 1,693 对标题中，原两个成员答错了同样的 319 题。第三个模型能独自救回其中 40 题。站在预测当时看，能观察到的条件是“两个老成员意见一致，第三个反对”。满足条件的有 **124 题**。其中第三个模型对了 40 题，原双模型对了 84 题。要做到净提分，Agent 需要在给出答案前识别这两种情况。

首次用置信度学习逐题切换，学习区净增 7 题，换到确认区净亏 7 题，Agent 放弃了它。如果强制采用，它在历史留出中确实找回了 40 题里的 35 题，但全部改动共救回 49 题、改错 82 题，净亏 33 题。该面板只用于识别机制问题。[历史预测与配对结果](../research/unified_handoff_1124/first/result.json) · [逐行决定](../research/unified_handoff_1124/expanded/predictions.csv)

## 五折训练内对照

把另外 6,608 对标题按共享标题的 4,874 个连通组分折。每折用四组互无共享标题的数据，分别训练三个基础模型、学习谁更可靠、确认是否启用、最后计分。三种基础模型在每折看到完全相同的训练行。旧的 1,693 行在这部分实验中只进入基础模型训练。五折的评价行互不重复，基础训练集有重叠。第四种方法也在查看五折成绩前登记并封存预测。[五折协议](batches/unified_conditional_handoff_plan_20261124_zh.md) · [相似改写协议](batches/unified_local_handoff_plan_20261124_zh.md)

| 策略 | 答对 / 6,608 | 救回 | 改错 | 净变化 |
|---|---:|---:|---:|---:|
| 原双模型 | 4,722 | 0 | 0 | 0 |
| **Agent 实际选用** | **4,722** | **0** | **0** | **0** |
| 固定三个模型等权 | 4,713 | 127 | 136 | −9 |
| 按置信度逐题硬切换 | 4,709 | 60 | 73 | −13 |
| 只在经验胜率下界够高的区域切换 | 4,722 | 0 | 0 | 0 |
| 根据置信度与标题差异调节第三模型权重 | 4,717 | 92 | 97 | −5 |
| 参考训练中相似的标题改写 | 4,724 | 5 | 3 | +2 |
| 全部听第三个模型 | 4,666 | 350 | 406 | −56 |

表中各备选行记录强制采用这一条规则的结果，便于判断 Agent 的取舍。实际选择时，规则必须在学习区净增，并在另一个确认区达到预先规定的最小增益。五折全部选择原双模型，合计 **71.46%**。相似改写规则只动了 8 题，五折净变化依次为 **0、0、+2、0、0**。按标题组做 2,000 次配对重抽样，增益的 95% 区间为 **−0.046 至 +0.107 个百分点**。在五折中再次单看原两成员一致、第三个反对的 376 题，第三个对 163 题，老成员对 213 题。[五折成绩](../research/unified_handoff_1124/five_fold_results.json) · [相似改写成绩](../research/unified_handoff_1124/local_five_fold_results.json)

## 五折之后再做的迭代

怀疑门控可学习的分歧太少，于是固定同一套基础模型、确认题和评价题，只给软融合增加另一组训练外反馈。每折可学习的分歧从 **142–163 题**增至 **287–324 题**。强制采用时，小反馈答对 4,712 题，大反馈答对 4,715 题，双模型仍为 4,722 题。两种反馈量下 Agent 都在五折中保留了双模型。这次复用了原五折的评价题，属于对同一训练集的后续研发。现有置信度和文本相似度信息仍不足以稳定识别该交给第三个模型的题。[迭代协议](batches/unified_feedback_volume_plan_20261124_zh.md) · [独立成对计分](../research/unified_handoff_1124/feedback_volume/result.json)

## 在统一版运行目录使用

先用通常的统一命令训练。对已有完整训练目录，可以单独运行以下两个命令。第一条读取该次训练的候选概率和训练反馈，第二条在新进程用保存的选择导出同格式的逐行预测。

```bash
python -m scripts.unified_handoff attach --run-dir runs/my-task
python -m scripts.unified_handoff predict FEATURES.zip --run-dir runs/my-task --output delivery/predictions.csv
```

这个可选入口针对已交付两个成员的二分类偏好任务。它从本次已得分的剩余候选中，按学习区三人组合的净增、救回共同错题数及试验顺序挑挑战者。对其他任务、缺少独立确认或已用满 11 次拟合的运行，沿用已交付模型。原运行通常已训练 10 次，因此这里最多追加一种软融合规则的一次拟合。它可以调整每题的权重。训练区净增必须为正，确认区至少多答对 `max(2, ceil(0.002 × 确认行数))` 题。通过才导出可重载的三成员模型，第三成员复用开局试验保存的权重。重复接入已完成目录会读取第一次的决策。

在实际 Task2 目录里，它自行选到 MiniLM-L6 加词汇特征。去掉与学习区共享标题的 248 行后，确认区有 1,066 题，净增 1 题，门槛是 3 题。它保留了双模型。两个独立进程在 1,693 行训练内留出上的预测与原模型逐字节一致。另用合成数据检验了正反馈足够时的启用和导出。[接入与两次预测凭证](../research/unified_handoff_1124/optional_delivery.json) · [可选入口](../scripts/unified_handoff.py)
