# 两个辅助模型一致反对首选时，要不要改答案

在 8,301 条训练数据原有的五份留出预测上，对每份再按互不重叠的标题组分成选规则、确认和评价三部分，轮流让每条样本只当一次最终评价对象。所有底层模型都在该份留出以外训练。控制器从不同编码器间提名组合，学习何种信心差距值得改答案，使用独立组里的纠错与误改决定是否采纳。

| 做法 | 纠正 | 改错 | 净增 |
| --- | ---: | ---: | ---: |
| 两个入选辅助模型一致反对就改 | 193 | 251 | −58 |
| 使用从学习组挑出的成员与信心门槛 | 110 | 137 | −27 |
| 先用独立组确认规则，再允许改答案 | 0 | 0 | 0 |

每个人工预定的门槛都在试验之前写入协议。15 次轮换中，没有一条规则通过确认。原双 GTE 在 8,301 条上答对 6,053 条。两个辅助模型确实能纠错，但它们也会一起推翻正确答案。按合同保留原模型，继续把这项能力留在研究分支。保住答对数只表明这批规则的否决有根据，未证明该方法在新题上能提分。

这次复用旧训练预测。新增基模型训练 0 次，监督规则选择 15 次，模型 API 调用 0 次。未读取课程指定验证、正式测试或 H2 标签。新随机划分实验的逐行预测没有参与本轮。
