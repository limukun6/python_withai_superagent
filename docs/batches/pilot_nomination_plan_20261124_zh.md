# 提名之前让候选在同一批训练题上试做

起点 `410ab95`。此前五折的自主策略从未提名 MPNet，历史固定融合对照显示第一轮 +55、角色轮换 +19。现在用全套可用候选完成两种自主试用策略；不依据 Task2 名称、指定验证分数或某个编码器名字给挑战者排序。两条都接入相同的 `unified_agent train/predict`。对明确的二类左右偏好 accuracy 任务使用，其他契约交回公共路径。所有模型 API 均为零。

## 学习与对照

1. 沿用已封存的五份匿名训练包和无标签外层包，评价覆盖 6,608 行、4,874 个共享标题组。历史留出的 1,693 行在整批之外。每条路径重新根据当前训练数据算分组。试用的分类头全部在前批角色 A（约 4/9 的训练组）拟合。其余组按 `pilot-feedback-v1/` 加组标识的 SHA256 排序，偶数位置提名、奇数位置确认，三者互不重叠。
2. 两个原参考成员和所有合格挑战者在相同试用训练行拟合。每个挑战者三分之一权重加入双模型，比较相同提名题上的改对、改错和平均 Brier 误差改善。主策略按净改对数、Brier 改善、名称依次排序，最高净改对须为正。第二策略按“Brier 改善减去一个按标题组计算的标准误”、净改对数、名称排序，最高保守改善须为正。两种策略均先把唯一的提名写入记录，再在确认题上评价该提名；只在提名区净改对为正、确认区净改对至少 max(2, ceil(0.002 × 确认行数)) 且确认 Brier 改善为正时，自动批准第三成员。没有提名或未获批准则交付原双模型。确认题不会换提名人选。采用者与参考成员在整折训练包上重训。
3. 两种策略独立通过普通命令执行。拟合身份完全相同的本地分类头可共用，必须核对任务包、行序、方法源码及固定权重条件、原模型与拟合账本哈希。第一折主策略从头拟合所有所需成员，另四折可复用上批匹配的分类头；两种策略都重新计算反馈、提名、批准及导出。预算分别记为独立执行需用的拟合数、实际新拟合数、复用数和对照补拟合数。
4. 每路径独立最多六次试用、三次最终拟合。两种策略共享的基础模型只计一次；封存决定后如需检验“强制采用该提名”才补其重训。每个外层最多六试用、两参考重训和两个不同挑战者重训，合计最多十个不同拟合。五折新增实际分类器上限 30 次（第一折至多十，另四折各至多五），匿名工程小包另计至多十。路径无需学习额外连续融合权重。先在匿名小包做完整训练和跨进程原始文本预测，再开五折。

## 验收与后续

五折两个策略的决定、模型和新进程原始文本预测均封存后才开放本批外层评分。相对同轮双模型和前批交付给出逐折及总体改对、改错、分组配对 95% 区间。主策略须五折至少四折正增、总净增至少五题且区间下限高于零，才进一步开展新匿名真实开发任务试验。第二策略为预先登记的替代机制，单独报告。不使用课程指定验证、正式测试和团队 H。

同批再用已训练头做一次零新增拟合的诊断：在同一外层题上，把提名者在小块试用训练时与整折重训后的三等权收益并列。两次各自使用同期两个参考头作基准，分开计入参考变化、排序和最终决定。展示各试用候选的外层配对得失，避免只列被提名者。训练样本相同、五折总体也曾用于开发，以上结果只支持研究迭代。
