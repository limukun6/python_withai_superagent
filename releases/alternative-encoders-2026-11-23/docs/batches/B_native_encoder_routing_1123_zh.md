# 可选的双编码器按需推理接入验收

在 B 的独立接入副本增加 `--confidence-cascade`。从正式入口一次运行中取得真实反馈。仅当原调度已经确认两个支持概率的冻结编码器组合时，才比较先运行哪个编码器和哪些行可提前判断。初筛选择与新确认组核验沿用四组训练内研究的规则。若确认不通过或原先只选中一个模型，交付原方案。

使用之前封存的匿名 6,608 行训练包，从空目录启动一次相同种子 18643 的本地 Agent。最多 10 次真实分类器拟合（包括最终重训），模型 API 0 次。检查真实动作顺序、方法目录、每次进程拟合以及最终成员，和同种子已冻结的全量推理路径逐项核对。先冻结模型与决策，再用已经研究过的 1,693 对开发特征在两个新进程中导出并核对每一行。检查排序、左右互换、概率规范及空批量。课程 940 行、正式测试和 H 留出本批均不参与。正式接入与原始分类准确率试验分别报告。
