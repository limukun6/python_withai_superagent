# 给尚未试过的预训练编码器一次有预算的机会

种子 40531 的正式路径试了词模型、六层、普通十二层、带词频的十二层。最后一项比普通十二层多对 37/1,323，四个已试模型之间的最优组合只对 941，低于新单模型的 950。新旧调度均在第 5 次拟合重训后交付 1,232/1,693。但该证据对未试过的 E5 没有直接说明。现在检验这个具体决策缺口。

同一个联合目录、种子、10 次拟合上限、确认机制和匿名数据。在原先的四次开局之后，即使已有明确领先者，如果剩余候选含一个未试过的本地预训练骨干，且余额容得下额外一次探索、最多三次确认和两次重训，就在该组合法候选中调用现有的通用选择器。根据已试候选的编码器标识去重，同一个骨干换分类头不计作新骨干，获准的候选也不保证入围或交付。没有可用的另一种骨干、模型未验证、或预算不足时，沿用原规则。本实验不按任务名或指定模型名做决定。

处理组使用正式 CLI 独立启动，同种子的旧路径已保存。逐行复核前四次相同方法的预测、目录、划分和授予的额度；不同的实际拟合数会单列。先冻结终局，再独立导出并在 1,693 对开发保留区评分。该区已反复使用，可报告这一对照的差异。达到原定 1,235 对才规划单次课程指定验证，不根据结果更换种子。模型 API 0 次，真实训练最多新增 10 次。
