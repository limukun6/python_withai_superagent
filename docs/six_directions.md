# 六方向实现和实验边界

错误分组的词表和中位阈值仅由本次训练输入拟合；内层搜索数据用于聚合准确率，每组至少20行。组可以重叠，不代表原因、显著性或独立数据。仅反馈模式接收分组汇总，无逐条输入或标签。默认关闭。

选择性审阅使用预先固定的四个触发条件：未尝试路线、启发式提醒、上次执行失败、最后一次搜索决定。其余决策只调用Planner。触发不强制修改；失败保留原提案并将整个运行标为未完成指定架构。过去解释与下一步动作在提示中分开，启发式误报仍可能出现。500/1200字符处理沿用v0.36。与每步审阅对照时实际调用、成本、结果和失败均记录。

潜在语义候选使用训练内TF-IDF加TruncatedSVD（32维，极小数据下自动缩小），以及它与词频特征的拼接，再训练Logistic分类器；训练/预测共用保存的转换器。单文本与成对文本均支持，配对采用左右差分和交换增强。它是统计语义基线，不是Qwen Embedding。学校网关公布的Qwen3.8-27B是对话模型，不能作为嵌入接口使用。

方案组合只允许文本类型、word/char_wb、lexical/latent/hybrid、Logistic/LinearSVC、C在0.05至10、维度32或64的声明式组合。至少两个完成结果后，按历史最好、训练搜索差距和可选未见词分组选择组合；每步最多2个、全程最多4个，不增加试验次数。旧候选保留。控制器生成规则是自主系统的一部分，不是任意LLM代码生成。生成的模型、参数、来源和使用时点均可核验；非文本任务记录不适用。

资源分配是一个小型分阶段策略，不是完整Hyperband。uniform与successive从同一个盲规则候选池出发；后者先使用25%训练行，保留最好两项及一个受保护的替代路线，在50%训练行再测，最后两项进入正常全量训练内搜索、三划分确认、全训练重训。每个层级使用同一个搜索分区，训练子集按类别分层且嵌套。45%的总时间上限分配给筛选，剩余时间进入完整流程。所有筛选和复核拟合、失败、实际耗时计入；相同时间上限不代表相同实际计算量。低保真结果只用于晋级，最终选择依据完整资源的分数。当前仅本地策略、不能同时组合生成。

通用性演习在冻结源码之后读取新的公共任务，统一入口和配置按声明模态工作，不把数据集名字提供给决策者。它验证流程和有限任务表现，不等于课程未发布任务已完成，也不能证明任意任务适用。
