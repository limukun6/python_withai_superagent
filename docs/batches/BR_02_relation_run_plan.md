# 有方向三分类的一次完整自主运行

用 BR-01 已登记的 SICK TRAIN 子集、6 个文件及行序证据中的原训练包、三份来源隔离内部划分与同一无标签外层。正式入口由现有可信行号工具提供已签名分区，优化器只读 3,685 对句子的两列文本与方向性三类标签。Agent 从原有的五项共同候选自行选择，采用与 Task2 原接入版一致的本地动态调度、种子 707、最多 11 次实际监督训练含重训、1,200 秒、每次 300 秒、零模型请求。上限以内按实际动作结束。

只有完整重训并封存模型后，才在原目录和搬迁目录分别用新进程预测 754 行无标签输入。两份预测完全一致后再从作者 TRAIN 的已登记外层行号还原正确标签。主要指标为准确率。补充报告固定训练类别顺序的 macro-F1、混淆计数及由训练频数独立确定的多数类参照。保留所有低分与失败，不据本次分数改方法、换划分或决定 H。此实验仅测一个有方向的三分类开发任务，不推断所有关系任务的效果。
