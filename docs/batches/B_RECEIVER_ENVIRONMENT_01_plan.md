# 已训练模型交付后最低需要什么

在已验收的四分支包中，固定三个真正交付过的模型：优惠券的字段交互模型、短信的非线性 MiniLM、短信的字符混合组合。采用独立接收仓库、原搬迁模型和原来无标签的预测包，在三种事先确定的环境分别运行原生预测入口：原 Python 3.11 环境加已核验权重、同环境指向空权重目录、现有较轻的 Python 3.14 环境加原权重目录。轻环境另外记录实际可导入的库与版本。每次均为新进程，禁网、禁下载，不重新训练，不复制数据给第三方。成功须逐字节匹配历史预测与行数。失败须记录具体原因和是否留下部分结果。模型、运行库与编码器权重的要求分别汇报，跨版本结果不推广到未测版本。共 9 次预测调用，零真实训练与付费请求。
