# Task1 的 79% 是怎么来的：数据量，不是方法

2026-11-27。用户确认存在 79% 的结果。本文件定位它的来源，并在我们的折上逐条检验。

## 1 找到的公开结果

[MECS 期刊 IJITCS 2022《A Comparison of Missing Value Imputation Techniques on Coupon Acceptance Prediction》](https://www.mecs-press.org/ijitcs/ijitcs-v14-n5/IJITCS-V14-N5-2.pdf) 表 4（按券种的准确率）：

| 分类器 | Bar | Coffee House | Restaurant<20 | Restaurant(20-50) | Take Away |
|---|---:|---:|---:|---:|---:|
| Random Forest | 74.0 | 75.4 | 75.9 | 62.7 | 73.4 |
| Gradient Boosted Tree | 73.3 | 75.2 | 75.4 | 66.9 | 71.9 |
| **Deep Learning** | **80.86** | **79.68** | **80.11** | **73.19** | **78.85** |

未加权平均 **78.5%**，加权后 **79% 左右**——这就是那个数字。

**同一篇论文的 SMOTE 表里，Deep Learning 达到 100% 准确率**（原文："RDeep Learning classifier gave 100% accuracy, which was the peak accuracy"）。这是协议泄漏的典型特征，但它不影响我们找"方法"。

## 5 真正的解释：数据量

课程把 12,684 行拆成 **train 8,117（64%）/ val 2,030（16%）/ test 2,537（20%）**。

而公开论文做的是 **12,684 行的随机 80/20**：

```
他们的训练集 = 12,684 × 0.8 = 10,147 行
我们的 train + val = 8,117 + 2,030 = 10,147 行   ← 完全相等
他们的测试集 = 12,684 × 0.2 = 2,537 行 = 我们的 test
```

**也就是说：他们的训练集，正好等于我们的 train 加上我们的 val。**

他们用 10,147 行训练，我们（开发阶段）只用 8,117 行——**少了 25% 的数据，而且少掉的正是我们拿来当验证集的那 2,030 行**。

### 数据量值多少：学习曲线实测

同一折上分别用 50% / 75% / 100% 的训练行：

| 折 | 50%（3,248 行） | 75%（4,872 行） | 100%（6,496 行） |
|---|---:|---:|---:|
| 707 | 0.746453 | 0.755089 | 0.758174 |
| 811 | 0.715427 | 0.740012 | 0.750461 |

斜率换算到"再加 25% 数据"：

| 折 | 每 100% 训练量的增益 | 投影 +25% |
|---|---:|---:|
| 707 | +2.34pp | **+0.59pp** |
| 811 | +7.01pp | **+1.75pp** |

**平均约 +1.2pp（区间 0.6–1.8pp）。** 这就是我们和 79% 之间的大部分差距。

## 6 所以答案是什么

| 问题 | 答案 |
|---|---|
| 79% 存在吗 | 存在，是 IJITCS 2022 的 Deep Learning 按券种结果 |
| 是靠更好的方法吗 | **不是**，同配方在我们折上 −7.7pp，同协议也只有 70–72% |
| 差在哪里 | **训练数据量**：他们 10,147 行，我们 8,117 行 |
| 我们能补吗 | **能，而且合规**——课程 Readme 只禁止用 test，val 可以进训练 |

## 7 可以立刻做的事（合规且不需要新方法）

Task1 Readme 原文：

> Use `val` for model development and validation. **Use the test set only for final evaluation.**

**val 属于开发数据，进训练是允许的。** 因此：

1. 保持 76.31%（train 训练、val 评估）作为**开发阶段的诚实估计**；
2. **最终提交模型改用 train + val（10,147 行）重训**；
3. 最终成绩由课程的 test 评定，我们不再有独立验证集——这一点必须在报告里写明。

预期：test 上的准确率大致落在 **77–78%** 区间（按学习曲线投影），而不是 79%。剩下的 1pp 属于他们未说明的配置差异（网络结构、轮数、是否对 8 个券种做了单独调参）。

## 8 边界
