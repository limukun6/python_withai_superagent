# 两个已训练的方法意见不同时，让较有把握的一方决定

前一轮真实动作已封存。用同一条无参数规则做回顾性检验。在每个模型的首轮训练内评估中，保存它对各题的置信幅度 |p−0.5| 的有序列表。新题来到时，把两个模型各自的置信幅度换成在自己以往评估题中的百分位；模型意见不同时，选择百分位较高的一方。百分位平手沿用已交付策略。只依赖预测，原选择的成员和两个模型的参数全部冻结；不使用评估答案学习权重或决定阈值。

比较对象是当时 Agent 已经选来实测的两个成员。使用此次冷启动的共同版在 937 对标题上的冻结组合、全部标题续跑的两个单模型、以及已封存的电影台词记录。后两份只在确认分区中保留首轮评估从未出现的标题组。各列同时给出原交付策略、等权概率、按置信百分位逐题选模型的正确数及改对改错。等权和百分位遇到精确 0.5 时遵循现有的标题顺序规则。先封存全部预测，再评分。

这些开发数据已有已知成绩，两个标题面板也可能重叠。各面板分开报告；以 5,000 次按标题组配对重抽样给出净变化区间。至少两个面板改善、三个面板均无退步，且 937 行面板提高 0.5 个百分点并且 95% 区间下端大于零，才值得另做全新留出的自主对照。计数只作筛选，不改变共同默认。全程 0 次新分类器拟合、0 次模型 API，不开课程指定验证或正式测试。
