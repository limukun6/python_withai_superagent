# A149 短程计划片段：核心逻辑已实现，未接入调度

2026-11-24。交接把 A149 定义为"短程计划片段（每步按新证据检查失效，B 停止优先）"。本轮实现其**判定核心**与 14 项测试，**尚未接入运行入口**，因此不改变任何默认行为，也不产生 API 或 fit。

## 1 为什么先做核心而不直接接入口

接入会改变调度语义（谁来定下一步候选），属于必须可回退的结构改动。按仓库惯例，先把"一个计划什么时候失效"写成纯函数并测透，再接入口、再谈费用。

## 2 已实现

模块 `superagent/plan_fragment.py`，三个入口函数：

| 函数 | 作用 |
|---|---|
| `validate_fragment(fragment, available_ids)` | 解析提案，返回规范化片段或错误列表 |
| `fragment_status(fragment, state, scheduler_action, step_index)` | 判定这一步能不能执行，给出 `valid / superseded_by_scheduler / invalidated / consumed` |
| `next_step(...)` | 便利封装，返回可执行候选或 `None` |

### 片段形状

```json
{"steps": [
  {"candidate": "word_char_C0.05", "requires": {"best_completed_trial": 2}},
  {"candidate": "word_char_C0.1",  "requires": {"minimum_best_score": 0.6}}
]}
```

最多 **2 步**；每个候选必须在当前合法菜单内且不重复；`requires` 只能使用三种**机器可判定**条件：

| 条件 | 含义 |
|---|---|
| `reference_trial` | 该试验必须已经完成 |
| `best_completed_trial` | 当前最好试验必须仍是它 |
| `minimum_best_score` | 当前最好分数不得低于该下限 |

自由文本条件被**明确拒绝**：无法核验的条件无法让计划失效，而不会失效的计划等于偷偷预支预算。

## 3 不可违反的约束（已由测试锁定）

1. **B 优先**：调度返回 `confirm` 或 `stop` 时，片段一律 `superseded_by_scheduler`，不执行。
2. **不越过预算**：片段不新增 fit、不改 fit 上限、不触发调用。
3. **不越过菜单**：候选离开合法菜单即 `invalidated`。
4. **新证据可作废剩余步**：例如第 1 步后出现更好的试验，第 2 步声明"最好仍是第 2 次"即失效。
5. **不重复**：同片段不得重复同一候选。

## 4 测试

`tests/test_plan_fragment.py`，14 项：

- 解析：2 步合法、>2 步拒绝、自由文本条件拒绝、菜单外候选拒绝、重复候选拒绝、空条件拒绝；
- 判定：合法步给出候选、`stop` 与 `confirm` 都 superseded、新证据作废剩余步、候选离开菜单作废、耗尽后 consumed、分数下限被更好证据满足而非违反、`next_step` 在被作废时返回 `None`。

## 6 接入前的验收口径（预登记，未执行）

1. 片段只作为**建议**：调度给出 `explore` 时，若片段当前步合法且候选可用，可优先采用；否则退回原有单步提案。
2. 任何情况下不得让片段导致 `stop`/`confirm` 被跳过。
3. 接入必须可用开关关闭，默认关闭；关闭时 payload 与行为逐字节不变。
4. 零成本回放：用 A151 已保存的 21 条历史状态验证"作废发生在第几步"，不改任何运行结果。
5. 真实调用前必须保证：同一任务、同预算、片段开/关配对，且**至少重复两次**——本轮已量到同配置漂移可达 7.9pp。
