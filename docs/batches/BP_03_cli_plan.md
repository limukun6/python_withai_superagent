# BP-03 · 两套环境从相同的登记行真正训练到交付

BP-02 已核对两套环境生成的数据包和内部行完全相同。为验证这些数据能直接用于正式训练，选 B 负责的 Dry Bean 数据块，使用两套 BP-02 各自生成的输入文件。在同一合入 A11 的源码下走正式本地动态入口。实验适配器只把 A 分区函数的行号来源绑定到事先登记的清单，候选、动作、训练器、预算、停止、重训和最终导出都走正式代码。

每套环境限 2 次真实监督拟合，供一次探索和一次最终重训使用，每套最多 120 秒、单个 worker 最多 60 秒。合计 4 次，作为跨环境工程小试计账。比较真实动作、三份内部行与标签指纹、每环境本地 worker 的文件摘要、首轮训练内逐行预测、冻结后对同一份 2,174 行无标签输入的新进程导出。两边先分别封存模型，随后进行表决结果和逐行输出的比较。预测有差异则保留差异，不重训求一致。此处只需验证共同输入能训练和交付，不要求两个三方库版本必然得到相同模型或相同预测。

不使用外层真实标签、不计算或报告新的外层分数。此实验不占用最终 C1 组位。Python 3.14 环境沿用 BP-02 已登记的本机 HTTP 客户端导入补充，两套均禁止模型网络调用。真实 API 请求上限为零。
