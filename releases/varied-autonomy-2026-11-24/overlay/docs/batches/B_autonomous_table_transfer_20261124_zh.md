# 用同一套自主选择器跑匿名分类表

标题实验之外，单独检验同一选择算法能否从表格任务和训练内反馈自行试不同模型。用 6,490 行、21 列的既有优惠券训练子包，SHA-256 为 `101a2c6d59d5a109a667804f642c933cf39932f2a7e1bd9987ff319d1339633b`。重新打成通用清单，列名为 x0 至 x20，无任务名、数据集说明、建议算法或指定首选。完全相同的特征行必须同组。组摘要加前缀 `b-anonymous-table-varied-20261124/v1/` 的 SHA-256 取余 5，余 0 留出，得到 5,221 行运行输入和 1,269 行外层评估。没有用户标识，不能据此推断新用户泛化。

沿用已冻结程序 `2ce112f`、同一训练画像、选择规则、种子 51803、标准的共同表格目录、最多 11 次真实分类器拟合（含最终重训）、20 分钟总时限、单次 5 分钟和 0 次模型 API。运行期间不指定方法、次序或停止步。表格候选来自原有注册表。先对匿名合成表做目录、动作及预算的零拟合检查，然后由原生入口从头运行一条路径。外层不可用于选择，先封存最佳模型，两个独立进程各导出一次无标签预测，再评价。另用训练集多数类别作为可复算的参照数值。这是单路径迁移测试，无法从它估计新旧调度之间的效果差异，也不是课程指定验证成绩。
