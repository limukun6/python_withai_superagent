# Task2 熟悉度特征、E5 与自主调度

在同一份 **1,693 对训练内开发保留区**，本地 Agent 从匿名任务启动，最后选择六层 MiniLM 加带词频特征的十二层模型，答对 **1,224 对（72.30%）**。研发人员另行登记的 E5 加新特征组合答对 **1,237 对（73.07%）**。两项实验均在模型冻结、独立进程重复导出后才计分。该保留区在先前研发中已经使用多次。课程指定的 940 对验证、正式测试和迁移任务均未打开。

| 开发保留区上的方法 | 正确数 | 准确率 | 选择过程 |
| --- | ---: | ---: | --- |
| 原 Agent，E5 目录，六层加词模型 | 1,208 | 71.35% | 历史同种子、8 次拟合，自主决策 |
| 新 Agent，新特征目录，六层加带特征十二层 | 1,224 | 72.30% | 本次 8 次拟合，自主决策 |
| 固定普通十二层 | 1,224 | 72.30% | 历史同训练包对照 |
| 固定带特征十二层 | 1,232 | 72.77% | 预登记的单项特征对照 |
| 旧 E5 加普通十二层 | 1,234 | 72.89% | 历史固定等权组合 |
| E5 加带特征十二层 | **1,237** | **73.07%** | 新的固定等权组合，复用两个完整模型 |

**Agent 如何决策。** 两个目录共有的四份“同方法、同划分”逐行预测完全相同。新方法单独在首轮答对 915/1,295，六层为 924，两者合用上升到 929。第二划分中两者各为 927 和 935，组合为 946/1,314。调度因此选组合并重训。开发保留区上较旧调度多答对 84 对、多错 68 对，净增 16 对，按共享标题组估计的 95% 区间为 −0.48 至 +2.41 个百分点。独立交付包使用六层和十二层两套权重，在项目目录外用隔离 Python 重放，与正式导出的全部 1,693 行逐字节相同。[调度选择](../../research/b_learned_familiarity_1123/native_familiarity_01/selection_frozen.json) · [同预算结果](../../research/b_learned_familiarity_1123/native_familiarity_01/results.json) · [独立包回执](../../research/b_learned_familiarity_1123/native_familiarity_01/relocation.json)

**新特征带来了什么。** 只从当前训练折统计词和相邻词的频率，计算两侧标题措辞常见程度之差。训练标题逐个扣除自身计数，两边交换时特征变号，分类头学习权重。排除前期评估组后的 1,002 对中，仅选措辞更常见的一边答对 541 对。直接改原答案却在可核对的 558 对里净少答对 5 对。加入可学习特征后，两个新内折内分别多对 15 和 10 对，完整重训在 1,693 对中净多对 8 对，区间 −1.17 至 +2.09 个百分点。[信号复核](../../research/b_complement_native_1123/familiarity/results.json) · [单特征回执](../../research/b_learned_familiarity_1123/learned_familiarity_01/results.json)

**E5 为什么值得进一步测试。** 两个内折只新增 E5 的两个分类头。剔除确认折与首折重复的评分组以后，新组合答对 1,697/2,382，旧组合为 1,667/2,382，增加 30 对，按组区间为 +0.30 至 +2.22 个百分点。进入开发保留区后，新增益缩小到 3 对，改对 59 对、改错 56 对，区间 −1.08 至 +1.39 个百分点。现有实验证实了组合可执行，优势大小仍需新的独立比较。正式入口该次实验的目录只替换一个席位，Agent 尚未在同一场运行中自主选出 E5 加新特征。[预登记门槛](B_e5_familiarity_1123_zh.md) · [内折与开发保留区](../../research/b_learned_familiarity_1123/e5_familiarity_01/results.json)

**另一种调度尝试。** 复用八个原有检查点，按 5,000 次标题组抽样的入选票数给最多三个成员加权。两个种子相互检验时，2,069 对合计净多对 1 对；在各检查点从未训练过、选择与评分互相隔离的组上，合计净少对 2 对。未通过预设门槛，保留在回放证据里。[分组检验结果](../../research/b_learned_familiarity_1123/cross_seed_portfolio_01/results.json)

本轮新增 **15 次本地监督拟合**：新特征对照 5 次、同预算正式入口 8 次、E5 对照 2 次；调度回放和独立包预测 0 次。新模型 API 请求、输入输出 API token 和新增 API 费用均为 0。编码器在本地处理的 token 单列在训练回执中。运行 `python scripts/verify_b_familiarity_study.py` 可以核对发布回执。正式入口使用 `--portfolio ab-v1 --planner local --scheduler ab-complement --preference-catalog deep-familiarity --seed 18643 --fit-limit 8`；复跑各阶段的数据与权重准备沿用本目录 README。[新候选研究方案](B_learned_familiarity_1123_zh.md) · [正式入口方案](B_native_familiarity_1123_zh.md)
