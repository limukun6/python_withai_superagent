# 共享标题是否使一部分训练比较获得过大权重？

有些标题参加多场比较。一组相近标题反复出现在训练里，可能比只出现一次的标题多影响模型。保留原 E5 分类头作为对照。用完全相同的训练行、左右交换增强、已拟合特征、正则强度和求解器，只更改哪些训练比较得到更大权重。

- 在训练折内，两个比较共享任一规范化标题时连成组。每行权重取组内行数的负二分之一次方，再按全部训练行归一化为平均 1。左右交换得到的镜像行使用同一权重。保留区特征和标签均不参与求权重。
- 用种子 18643、40531 的既有真实 E5 首轮试验作配对。两套目录和两个种子均在读取新预测前决定。每个折只能新拟合一个逻辑回归分类头；复用该折已训练好的无监督特征与原分类头，先复核原分类头重现原始逐行预测。两折最多 2 次本地监督拟合、模型 API 0 次。训练和评估的标题组必须分离。
- 分别报告两个内折的改对、改错、准确率差与标题组区间。不同折可能评估相同行，两个独立百分比不直接相加。只有两折均未退步、至少一折净增 5 对，才进入新的训练内确认。该门槛只用于决定是否追加验证。本轮不评 1,693 行开发保留区或 940 行课程验证集。
