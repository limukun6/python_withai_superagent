# 训练语料的措辞罕见度

前三组配对中，额外枚举不含领先者的组合没有提高首轮最高分。本阶段改测一个互补信号：同一对标题中，相对不常见的措辞是否有助于区分胜者。统计量只从各分区训练部分出现的独立标题构建，不使用输赢、外部文本、预训练模型或 API。

用同一个规范化分词器处理大小写、单词、数字、标点。训练中频次至少 2 的词纳入词表，其余映射至未知词。从句首开始，对各词计算插值二元概率。单词概率采用加一平滑；二元概率取“前词到当前词的计数，加上 10 倍整体单词概率”，除以“前词的出现次数加 10”。按词平均负自然对数得到标题的信息量。事先固定“较高信息量偏好”这个方向，相同分数用字典序处理。单独报告启发式准确率，不用反馈翻转方向。

另做一种固定的轻量修正：当十二层 MiniLM 的胜者概率距 0.5 不超过 0.05，且两标题平均信息量相差至少每词 0.5 纳特时，使用上述方向，否则保留原模型预测。两种种子 8123 和 18643 各用已实测的主分区与第一次复核，共四个训练内分区。逐一报告纠正与引入错误数、覆盖率、相同语料与划分指纹。若至少三个分区获得正向净增、合并行次达到 0.2 个百分点，则具备继续研究的依据。分区有交叠，所有内容属于开发估计。本轮不访问 1,693 行开发保留区或课程验证，新增监督拟合与模型 API 均为 0。
