# 用已训练的三组模型检验训练抽样能否带来互补

训练规模对照中，两种 75% 抽样分别答对 1,137 和 1,139 对，全部训练组答对 1,141 对。与全部训练组相比，最后一档分别有 57 对和 53 对从错变对，也分别有 53 对和 51 对从对变错。现在检验平均判断能否把这种差异转成准确率收益。研究者已看到上述单组成绩，尚未计算三组投票成绩。

在相同的 A814、B777 两组上，复用原来的六个有监督分类头。每个训练子集内仍由 E5 和词频 MiniLM-L12 等权投票。全部训练组占最终概率的二分之一，两种 75% 子集各占四分之一。按原生规则处理左右方向和恰好 0.5 的平局。只试这一组权重，预测先落盘，再评分。

两组分别不退步且合计净增至少 8 对才安排独立的下一阶段；给出从错到对、从对到错及按共享标题组的配对区间。既往已研究过这批训练内数据。此次只恢复模型及其原先的词表，新增训练 0 次，模型 API 0 次。部署六个头的成本单独计算，是否进入每任务 11 次拟合的 Agent 由后续实测决定。
