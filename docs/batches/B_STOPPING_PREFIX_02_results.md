# 一次复核打平时，保留下一次复核有实际价值

将相同的停止条件用于前三类开发实验，并在原代码上复现了 284 个真实动作。下表列出每条规则会错过的原赢家数，以及扣除最终重训后预计可省的拟合次数。所有对照均找到了同版本、同训练数据和同评价行的真实交付物。不同批次共享部分输入，因此分批呈现。

| 历史路径 | 连续领先且做过配对复核 | 再检查首轮更高、还没对比过的候选 | 再等待仍可负担的新路线 |
|---|---:|---:|---:|
| B1，16 路 | 错过 1，预计省 50 次 | 错过 1，预计省 50 次 | 错过 1，预计省 44 次 |
| B2，6 路 | 错过 1，预计省 7 次 | 错过 1，预计省 7 次 | 错过 0，预计省 2 次 |
| 商品、电影、餐馆评论，原目录 3 路 | 错过 0，预计省 0 次 | 错过 0，预计省 0 次 | 错过 0，预计省 0 次 |
| 相同来源，扩展目录 3 路 | 错过 0，预计省 8 次 | 错过 0，预计省 8 次 | 错过 0，预计省 4 次 |

**仍然错过的短信模型，其实已经在眼前。** 它在首轮以 97.11% 对 95.79% 领先 MiniLM，第一次复核以 93.46% 对 93.79% 落后。到第 7 步时，两种方法各赢一次，它们所属的路线都已试过。「有一次复核、没有未检查的高分挑战者、也没有新路线」会允许立即结束。原 Agent 继续做了第二次复核，得到 96.34% 对 94.91%，才有证据把词＋字符模型升为赢家。对应开发留出的真实完整模型多答对 7/825，宏平均 F1 高 2.37 个百分点。这解释了为什么在已出现相互矛盾的测量时，一次配对不能代替复核过程。

B2 组合短信的情况不同。第 5 步还有 5 条可尝试的路线。保留探索时间后，第 8 步实际尝试了已知路线上的一个新配置，第 9 步晋级。多出的等待在这条路径上保住了赢家。新配置所属路线此前已经试过，所以不能把收益解释为某条未试路线本身更好。在公开评论中，等待更多路线使预计可省次数从 8 降至 4，六条路径的所选模型都一样。
