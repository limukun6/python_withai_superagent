# 将局部词频信号交给分类器学习

在排除前期评估组后，较常见措辞在 1,002 个训练比较中答对 541 个；用固定门槛替换原十二层答案却在有完整对照的 558 对中少对 5 个。现在新增单个训练语料特征，让监督分类头自行学习符号和大小。使用同一匿名 6,608 行训练包、全新内部分组种子 29111。开发者选择特征和对照；本阶段是能力目录中的候选对照，调度自治另计。

原十二层和“十二层加措辞分数”使用相同词法、风格、冻结向量、C=0.3 的逻辑回归、交换增强、预算与两份训练内划分。唯一增加的输入是左右文本平均信息量之差，其算法沿用已登记的平滑二元词频模型，对单独标题去重计数；训练集里出现过的标题计算自身分数时扣除该标题的词及相邻词贡献，词表仅由本次训练确定。按该折训练差值的均方根缩放。特征不使用外层标签，不指定哪个方向代表赢家。

先在第一和第二份已登记划分分别实际拟合两种头，合计 4 次。按原行序核对对照、改对与改错，计算按共享标题组的配对区间。两份划分都净增，且合并行次增益至少 0.2 个百分点，才使用第 5 次拟合完整重训新候选；旧十二层已有同 6,608 行完整模型可复用。否则保留区继续封存。每个模型由统一目录解析，再通过既有隔离分类器 worker 执行。最多新增 5 次拟合，模型 API 0 次；本批没有课程指定验证和正式测试。
