三条轨迹都在第 3 步自行尝试新候选。标题 45101 上，两条编码器路线的首轮内分为 71.14% 和 72.38%。新方法成为前三次探索中的初始领先者，全量重训后在外部留出净多答对 4 对。这次没有第二个内层分区的成对复核。标题 45102 上，原方法得到 70.01%，新方法为 69.20%，最终保留原方法，留出预测逐行相同。

SMS 上两种句向量在首轮持平。Agent 将新旧编码器都带到接下来两个复核分区，新方法依次高 0.87 和 0.44 个百分点，因此通过晋级规则并重训。原菜单单独运行最终选择的是词字符 C=3，扩展菜单最终选择非线性句向量。报告的 macro-F1 增量是两条完整自主运行之差，含探索路径变化。

三条路径共新增 30 次真实拟合，对照复用 30 次已发生的拟合。每份新模型各做两次独立进程导出，另核对六份已存对照导出。新增 512 维特征的带宽从当前优化文本中估计，每次只用最多 128 个不同文本。首次试验的额外带宽采样在两份标题上分别处理 2,655 和 2,596 个本地编码 token，SMS 为 3,216 个。SMS 原对照有一项不改变动作的计时观察，这里仅比较得分与实际决策。三个小差值来自训练内或公开开发留出，正式成绩仍需在共同冻结版本上产生。模型 API 新增费用为零。[标题逐行比较](../../research/b_text_kernel_titles/results.json) · [短信逐行比较](../../research/b_text_kernel_sms/results.json) · [登记方案](B_TEXT_KERNEL_01_03_plan.md)
