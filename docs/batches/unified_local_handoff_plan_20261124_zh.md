# 继续迭代：从相似的标题改写中学习何时接手

第一轮硬切换在原训练留出上改对 49 题、改错 82 题。软融合仍净亏 12 题，分区门控选择保留原预测。五个新外层划分尚未开答案。在五折共同评价之前登记一次结构不同的补充对照。

第四种机制查找以往模型意见不同、且改写内容及三个模型的置信度相似的训练案例。字符 n-gram 对左右文本分别哈希并求差的绝对值，以保留改动，左右对换不改变相似度。只在原两个成员的一致状态相同的案例之间估计局部胜率；平均字符余弦相似度和分数向量的相似度。近邻数按训练冲突数的平方根确定，限制为 8 至 32。用同类冲突的整体胜率作八例强度的平滑。学习区预测排除本例所在的整个共享标题组，包括整体胜率的计算。冻结可考虑的三个最低胜率为 50%、55%、60%，由学习区的留组反馈选择切换门槛，同时允许完全不接手。门槛并列选切换较少者。用去重的确认区比较加入此机制前后的实际调度结果，新机制须满足原有正增量准入且胜过原选择（增量优先，变动少优先，完全同分保留原策略）。

复用前三种规则已训练的同一批基础模型，不重训。每折单列一次记忆学习与一次基于标签的阈值选择，所以每折原先 3 次基础拟合 + 3 次规则拟合，加本轮最多 2 次，总计最多 8 次。旧训练面板在五折确认前只用于机制诊断。五折必须先把两个版本的全部无标签输出封存，再打开任何一个新外层的答案。使用同样的逐折门槛与组配对区间；单独比较新机制、Agent 实际采用、加入第四机制之前的实际策略和原双模型。模型 API 与课程指定验证、正式测试访问均为零。
