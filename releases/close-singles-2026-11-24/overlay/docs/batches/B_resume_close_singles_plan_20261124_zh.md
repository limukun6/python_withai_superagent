# 在完整标题训练包上执行已观察到的追加动作

旧版在 8,301 对标题上的五次初探和最后的停止动作已有封存记录。新策略重放到第六个状态时提出继续比较。这项实验测量那次决定会带来什么训练内证据。选用这个案例是因为已经知道两种调度在此处分歧，因此结果单列为机制验证。

通过共同 Python 入口运行。前五个动作若与原始顺序完全一致，则复用已完成的真实模型、预测和逐工人用量。核对候选配置、划分字节、模型训练实现、硬预测和概率指纹，复用和当日发生的拟合分别记账。此后由 Agent 选择比较者、吸收反馈并决定最后交付哪个模型。允许最多两次新的同分区确认和一次完整重训。另检查候选相同且证据不足时能保留旧路线，以及计量不可信或时间用尽时能停下。

加入预算有效性检查后的源码单独封存。相对于双组从头实验所用的实验版，只增强开始追加确认前的公共账本和时限校验。核对已观察动作是否一致。学校 API 为零，课程 940 行验证和正式测试继续封存。本次最终模型用训练内样本导出验证接口，不用这些样本报告准确率。
