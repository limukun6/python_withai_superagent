# A19 正式目录开关接入有序关系实验

A 的 506441c 新增正式的 baseline/full 开关。用 A19 与 B 有序关系方法的同一份程序，检验开关能否还原 BR-02/03 的旧式两版本对照。两次训练都使用已登记的 3,685 行、同一组三个来源组隔离的实际分区，以及同一 754 行无标签预测包。固定 baseline 后 full 的顺序，本地动态调度，每路径 1,200 秒、每 worker 300 秒、实际监督拟合含重训至多 11 次，两个路径共最多 22 次，0 次模型 API。只以 A 的正式开关改变目录，不注入候选或选择的动作。

先核对两组目录的内容和次序，各自完成完全自主选择、停止和重训。两个模型及哈希全部封存后再进行四次独立预测，比较原目录和搬迁目录的逐字节输出，以及 BR-02/03 已封存的同一 754 条预测。新输出如与已有预测不同，记录为未复现；不修改种子、参数、训练数据或按差异补跑。没有重新打分或新增独立留出样本。另核对 11-fit 与实际独立观测、同任务预算标识和已登记矩阵输入。课程验证、正式测试及 H 不参与。
