# 用旧六模型的完整预测检查挑战者提名

五条自主训练路径均保留原双模型。下一步单独检查提名能不能找到值得听的第三个模型。本方案登记于打开本批外层成绩和计算下面的新对照之前。复用旧六模型研究已经评估过的原始五折，称为历史回放。旧批分类头的训练行数及来源与新五折不同；两种提名在回放内共享同一份概率、行号、基础模型和学习、确认、外层三种角色。

每个候选与原两个参考模型等权融合，即第三个模型占三分之一。提名器一继续在学习区用两个独立标题组半区的残差方向内积排序，只提名最高正分。提名器二使用每个候选已经留下的学习区预测，按照净改对题数、Brier 改善、名称依次排序，净改对须大于零。两个提名器采用同一批准条件：提名者在学习区净改对大于零、在确认区净改对至少 max(2, ceil(0.002 × 确认行数)) 且确认 Brier 改善大于零。未通过保留原双模型。保存两种提名在每折强制采用及实际批准后的决策与逐行结果。

所有提名与批准冻结后，才把外层标签交给评分程序。按题计算五折配对结果和标题组 95% 区间，并核实每个候选的外层净改对数。第三个模型在真实首次训练时是否已有逐行证据，决定了能使用哪种提名。这里的旧概率来自六个已训练的分类头；回放新增分类器拟合零次、模型 API 零次，每折另外执行两次监督提名。回放成绩用于解释提名信号，不触发课程指定验证或替换交付。
