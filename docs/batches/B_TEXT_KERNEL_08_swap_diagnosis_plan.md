# 定位标题左右交换后概率未完全互补的来源

接收验收发现 97 对标题全部翻转类别，但有概率互补误差超过预定 0.00002。冻结此前 B-TEXT-KERNEL-02 的两个最终模型（45101 非线性、45102 原 MiniLM），按原查询的全部 1,672 与 1,686 行检验，不打开标签。以实测分类器权重将正序分数加反序分数分解为两倍截距、词 TF-IDF、字符 TF-IDF、风格差、原始嵌入差、可选的随机傅里叶特征差。核对各部分之和，报告超过原容差的行数和最大偏差。不更改原模型、阈值或训练代码。

另预登记一种预测时的对称化处理。按原字符串固定每对标题的内部顺序，用同一个已训练模型对该顺序打分，再按调用者的左右顺序映射回对应概率；两标题相同则给两侧 0.5。整批与全体反向各运行一次，验证概率互补和非平局标签翻转。比较与原输出的平均、最大概率变化和类别改动数，不看真实目标，不承诺分数提高。该方案每次预测每对只调用一次原模型。两种候选均按同一程序评估，实际模型文件保持冻结，零训练、零付费请求。
