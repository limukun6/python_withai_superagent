# 已批准第三成员后，能否据反馈决定哪些题仍由原双模型答

本次在已经固定的 `pilot-brier` 决策之上增加一个可撤回的逐题动作。输入是两个试用阶段的成员概率和训练标签，以及全局批准的候选。在启动实验时，两套五折的候选决策均已封存；尚未查看两条参考意见一致或不一致时该策略各自的折外收益。复用已有分类头，不改变全局提名、批准或重训。

只在第三成员已获全局批准的路径试验。将训练样本按两个参考成员各自给出的二元答案分成“一致”和“分歧”两组，平分时使用原投票的字典序约定。在每组衡量恢复双模型会改对多少题、Brier 误差会减少多少。只有至少十个二元输出会改变、净改对为正、平均概率误差改善减一个标题组标准误也为正，策略才可提名这一组。两组同时满足时用保守概率改善、净改对和固定组名排序，只提一个组。另一块复核数据上至少十个二元输出会改变、净改对至少两题且 Brier 改善为正时，才批准在这一组恢复双模型。其他行沿用全局选择。若全局没有第三成员或两个阶段没给出支持，沿用原决策。

先在第一套与重新划分的五折分别封存这一学习决定和外层逐行预测，再打开标签。对照为全局概率提名 Agent 实际交付的结果；同时报告它相对双模型在两类样本分别改对和改错多少。若自动恢复双模型，抽该路径用序列化模型和原始匿名文本检验跨进程预测；若所有路径均保留原模型，核对十份锁定交付并在构造的小例子上检验动作的正、负分支。每个已批准路径最多一次离散选择，无新增分类器拟合、连续参数拟合和模型 API。该附加学习复用全局提名和批准阶段的训练组，独立性来自外层评价。只在两种划分中都比原决策净增、并至少一次区间下限大于零时，才考虑改统一入口。
