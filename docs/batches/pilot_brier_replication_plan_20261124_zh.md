# 把概率提名策略固定下来，换一套分组从头检验

第一批五折的原主策略 `pilot-accuracy` 净增 27 题，三折正增，未晋级。预先列为辅助的 `pilot-brier` 净增 32 题，四折正增。现在提出一项新的主检验：固定后者的当前代码、权重和批准条件，重新分配外层标题组及训练数据，五条全部从空分类头缓存启动。第一批的主检验结论保留。该后续的计划先于新五折的分割、运行和评分。

取原训练包的同一批 6,608 行及 4,874 个共享标题组。对每个组标识加前缀 `pilot-replicate-outer-v2/` 计算 SHA256，按哈希排序，排名模 5 为外层折编号。只根据组标识分割。每折向统一入口传入其余四折的带标注匿名 ZIP。每条路径自己检查任务契约及本机候选，按已冻结的试用、学习、复核规则考虑所有合格编码器。使用既有固定表示缓存，分类头不跨折、跨实验复用，不重新确定阈值、权重或入围名单。每折最多六次试用、三次最终拟合，共最多 45 次本地分类器拟合，模型 API 0 次。匿名验收用已验收的 192 行小包和同身份分类头从当前入口重走决策与预测，预算零新增拟合。

只比较最终实际交付和同折重训的两个参考成员。先封存五个决策、模型及两个路径的逐行预测，再打开全部外层标签。预先要求至少四折严格净增、总净增至少五题和标题组 95% 配对区间下限大于零。统计重抽样以组为单位，沿用原项目固定的 2,000 次与随机种子。通过后，进入一次外部真实匿名偏好试验，沿用已预登记且本阶段仍未读取的 OASST1 抽样、评价、预算方案；触发依据仅为本次新的主检验。未通过时保留研究结果，不改阈值后用这批题重选。原历史留出的 1,693 行、课程指定验证、正式测试和 H 均不用于这批训练或评分。
