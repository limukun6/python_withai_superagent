# 两道发布任务的错题，有多少能由输入完全相同而答案相反解释

使用双方已经校验过的两份仅含训练行的归档。分别统计全部开发源、以及预先登记的 45101 和 45102 训练内部留出。用原行号、数据内容和旧预测文件指纹核对四份内部留出。两份划分之间有样本重合，结果逐份报告。不打开课程指定验证、测试或待冻结迁移任务。

按模型收到的全部特征对行分组。优惠券保留 21 个字段、列序、字段类型与原值；标题保留原字符串和左右方向。每组行数减去最常见标签出现次数，再对所有组求和。这是任何只看输入、每次给相同输入相同答案的分类器在这批行上至少会错的行数。记录精确重复行、其中有相反答案的组数，以及现有开发预测中有多少错误能由该约束解释。这个计数只描述现有带答案的记录，不训练、导出或使用查表预测器。

对明确「左或右标题胜出」的 Task2，再按颠倒左右后的同一对标题分组，同时反转标签。对不同标题，按多数方向消去相抵的两种结果，建立剩余有向图。枚举无向边完整的三标题组，统计其中胜负循环的数量。按标题的固定字符串顺序，贪心取互不共享边的循环；每一环在任何全局一致标题排序下至少损失其最小残余边权的行数。它能与前述相反标签导致的错题相加。仅统计对相同标题采用确定性平局规则的模型；允许根据整对标题或上下文决定偏好的模型，仅使用前一层的相同输入约束。报告了哪些比较真的闭成三角，未形成闭环的行不能当作一致性的证据。每次划分另外检查优化部分与留出部分的完全相同输入组是否相交。

与原冻结模型的现成预测并列，但不把这个宽松的有限样本上界当作可达到的泛化准确率。不优化排序、不按结果改阈值、不生成预测或新监督样本。本批新增训练、模型 API 和课程费用均为零。
