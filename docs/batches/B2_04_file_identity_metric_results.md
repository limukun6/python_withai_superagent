# 文件名没有改变动作，换主指标能改变决策

将同一份训练输入分别使用匿名文件名与暗示卫星图像的文件名，重新经项目实际数据入口解析。两个真实任务的契约、候选顺序和所有 122 次动作（61 个历史状态各两次）逐字段相同。本地 B2 调度在这项输入扰动下不依赖外层文件名。任务的内部字段、合法候选族、默认首个方法和晋级规则仍然是开发者设计好的。

把实际评价目标从标题准确率换成 macro-F1、短信从 macro-F1 换成准确率后，分别重新绑定评价载荷和分数。55 条已有 worker 观测的搜索分均由真实逐行预测与可信标签重新计算；训练侧两项指标均与原 worker 文件一致。同样的最小历史在原目标下完整复现 61 个动作。换主指标后，有一个状态改变实际动作。短信原目录第 8 步，在真实 macro-F1 目标下调度器继续探索字符逻辑回归 C=3；同一过去状态按准确率衡量时，则要在第二份确认划分上复核 MiniLM。静止于原历史终点，原目标推荐词＋字符 C=3，按准确率重评同批已有证据则推荐 MiniLM。其余 5 条历史的最终推荐相同。

分歧发生后，新动作会产生何种后续观测没有实际执行。以上只解释当前调度对命名及目标的敏感性，不能当成按新目标自主完成了六条新实验。本批新增模型预测、训练、外层评分、付费调用均为零。[分任务回放记录](../../research/b2_identity_metric/results.json)
