# 安装新分类器后的接入验收

冻结本轮程序和两个独立的教学用分类器。扩展包用标准 Python 包元数据公布一个支持多类概率的中位数原型分类器和一个只输出二类标签的单特征分类器。生产代码不含这两个类名。扩展约定为可默认构造、CPU、单次监督拟合和 sklearn 分类接口，隐式交叉验证及嵌套分类器需要单独记账。包版本和入口绑定到配置，随模型交付。

1. 用上一轮 127 行匿名数值训练包和原有完整目录运行原生本地 Agent。随机种子 60281，最多 5 次实际分类器拟合（含重训），模型 API 0 次。Agent 自选全部动作。记录是否在目录可见、是否真正选到新增方法。无论选什么都验收结果，不改名字、排序、任务或预算重跑。
2. 在同一程序里把输入契约换为数值三分类和要求类概率的二分类，检查自动排除只支持二类标签的方法。注入一个缺失的可选包入口，检查其他方法可用。重放无扩展环境的已公开 14 条路径和 50 次选择。
3. 独立的接口验收用已公布的多类概率扩展，在正式 worker 上计 1 次真实拟合，使用同一匿名训练资料。用两个新进程执行正式预测命令，对比 33 行无标签输出。再仅替换扩展的版本元数据，检查旧模型拒绝加载。此步骤显式指名分类器用于测接口，单独记录，不能计作 Agent 自主选中过该方法。
4. 只用本地工程夹具，不访问发布任务、课程验证、正式测试、H2 或模型 API。整轮至多 6 次真实监督拟合。
