# 让编码器同时阅读两个标题，再学习改动的价值

原 E5 单独编码左、右标题，分类头使用两个向量的差。新候选用同一份冻结 E5，将两个标题按 BERT 的双段输入格式同时送入，两种顺序各读一次。只增加一种上下文差分特征。下游任务、模型权重、标签、词法特征、正则强度和左右互换增强均照旧。

- 每个输入段以相同的 `query: ` 开头，最长 512 个 token。仅对属于各自段的有效 token 求末层均值并单位化，忽略特殊分隔符。先算同一输入中两段的向量差，再把两个顺序的差相减取半，得到随左右交换而反号的向量。
- 新特征是上述联合差向量减去原 E5 独立向量差。只用当前训练折的特征范数设定尺度，使其均方长度与原语义差分相当。训练零范数时使用零新增块。用原来的 E5 逻辑回归参数对原特征加新块重新拟合。
- 先对独立的合成成对文本验证交换、相同文本和超长双段截断。只预计算原 6,608 条训练对的无标签联合表示。按种子 18643、40531 复用两份原 E5 首轮回执。每折只新拟合一个分类头，合计最多 2 次本地监督拟合，模型 API 0 次；报告联合编码输入 token 与耗时。
- 两个首轮均未退步且至少一轮多答对 5 对，才去互斥的确认 A/B 组。确认两组均未退步且合计至少多答对 8 对，才与当前更强的 E5＋词频十二层组合做匹配比较。首轮与确认均只使用训练包。课程 940 行与正式测试均不参与筛选。
