# 五折之后的迭代：增加门控学习所见的分歧

首次五折评估中，双模型答对 4,722/6,608，四种门控均未在确认区获准启用。置信软融合覆盖的冲突较多，且比直接硬切换少损失。本轮固定已经登记的软融合算法、模型和启用门槛，仅比较它所见训练反馈的来源与数量。上一轮五折汇总已知，此处是同一训练集上的开发复验。

对目标折 r，取原始十个共享标题组桶中编号相当于 2r、2r+1 的两个桶评价，沿用该折原先冻结的基础模型概率；把 2r+2 桶作为独立确认。小反馈使用 2r+3 和 2r+4 桶（由 r 的三个模型生成）；大反馈再加入 2r-2 和 2r-1 桶（由相邻折的三个模型生成），编号循环。两个基础模型组都从未在本折确认和评价的共享标题上训练，每份学习预测的产生者也没见过对应学习行。四个学习桶互不重叠，每个训练例只计一次。大反馈的新增行来自另一次基础训练的训练外预测，实测的是追加这种反馈的效果。所有确认、评价只用目标折的同一组基础模型。

每折两个门控使用完全相同的软融合函数和决策门槛。从全部五折分别封存小反馈、大反馈、强制采用的影子输出和基线输出，之后按同一批行对三个问题评分：相对双模型是否提高、相对小反馈是否提高、共同错误是否被真正救回。每折仅增加两次监督门控拟合，共十次，基础模型新增拟合与模型 API 均为零。晋级仍要求相对双模型至少四折正增益、合计至少多对五行、标题组配对区间下界大于零；还要求相对小反馈的净增为正。若通过，再用新的分组训练基础模型复验，本轮不评分课程验证或正式测试。
