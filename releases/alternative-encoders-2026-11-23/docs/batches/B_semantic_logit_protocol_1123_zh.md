# 保留词法证据，替换语义分数的离线检验

E5 在首轮与第一次复核得分接近普通十二层。此时已看过 E5 两次内部分区成绩，尚未查看 BGE 成绩或本轮保留区预测。在三方多数票之外，单列一个有明确来源的探索性问题：三份冻结的线性分类头是否都由相似的词法证据主导，掩盖了语义向量的差异？

每个分类头的最后 384 个输入是左右标题的单位语义向量之差。用模型本身的系数精确分解每条预测的 logit，分别记录语义部分和其余部分（词、字符、风格、截距）。先检查两部分之和可复原原始分类器的决策。唯一新增规则保留十二层 MiniLM 的非语义部分，再加上三份语义分数的等权平均。为了比较不同编码器的量纲，各个语义分数先乘以“MiniLM 的训练内语义均方根／该编码器训练内语义均方根”。取每个实际训练分区内按标题对内容哈希排序的前 512 个不同标题对估计尺度，整个估计不使用输赢或外部留出；零尺度则登记本分区不可用。按约定的字典序处理恰好平分。

同时报告各编码器的语义分数均方根、语义部分推翻本模型非语义部分的行数，以及新规则相对普通十二层的改对、改错。比较所有具备三种真实同划分检查点的内部分区，随后使用前述主分区模型预测 1,693 行开发保留区，先冻结预测再核对标签。此项只做结构诊断，新增拟合和模型 API 请求均为 0，没有指定课程验证资格。
