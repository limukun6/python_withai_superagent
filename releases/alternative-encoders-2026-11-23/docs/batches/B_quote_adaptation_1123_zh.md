# 新任务上重新交给同一套 Agent 选方法

在读取两套标题模型的台词成绩之前登记。这个配套实验检验同一套 Agent 拿到新任务的少量标签后，能否自行找到比直接借用标题模型更合适的方法。

- 将同一影片、或含有相同规范化台词的不同影片连在一起。对每个连通组内的影片名排序，以固定盐 `quote-adaptation-1123-v1` 和组名计算 SHA-256，大端整数模 5 等于 0 的组作为外部保留集。其余组用来开发。划分不使用台词标签或前一实验的预测。记录各组和边界重复文本数量。
- 主处理为一条完整本地自主路径，从空目录启动，使用与标题相同的联合方法目录、定价为零的本地规划、已核验的离线权重、自适应开局与尝试新编码器开关。预先固定种子 18643，每条路径最多 11 次真实拟合，包含最终重训，模型 API 0 次。决策只能看到开发包中的标签和实际内部反馈。外层严格按影片分离；内部按公共入口支持的共享文本分组。
- 两个事前固定的对照为同一保留集上的标题冻结模型和固定选边。记录每一步实际选择、真实拟合数，另起两个进程交付预测。主对照是自主模型减此前标题联合模型的正确数和按外层连通组重采样的 95% 配对区间。旧版标题模型另列作参考。
- 这是有标签的新任务开发实验，不占用 H1/H2 或课程测试。此单次划分不用于反复更换种子或再选一个有利于本方案的划分。
