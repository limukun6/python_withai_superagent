# 调换提名区和评价区，复查 MPNet 线索

第一次历史回放中，双模型与 MPNet 三等权在五折均增加正确数，合计 +55。这个候选是看过四种结果后辨认出来的。第二次回放沿用已登记的原六模型第二套角色安排：每折交换学习组与外层评价组，确认组、六个分类头、候选权重、两种提名信号、批准条件完全相同。把全部四个候选与两个真正获批准的提名器都再列一次，单独报告 MPNet 的固定对照和 Agent 能否选中。

第二轮的每份提名只读该轮学习与确认反馈；先封存五份决定及预测，再计外层成绩。两轮评价使用同一个开发总体的 6,608 行和重叠训练资料，两轮不能合并成独立样本量。新增分类器拟合和模型 API 为零，另计十次监督提名。该诊断不改变原自主实验的晋级结果。
