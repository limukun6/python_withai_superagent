# BV-02 · 验证视觉模型在另一目录如何交付

仅使用 BV-01 已冻结的两个模型、同一无标签 200 行输入及冻结时导出的预测摘要。新增监督训练、外层评分和模型 API 额度均为零。每个情形使用新进程及新工作目录。复制模型的交付文件和官方权重，重新核对模型和输入身份，再验证以下四种情况。

1. 视觉模型获得搬迁目录中的同一权重，200 行输出及行序须完全复现。
2. 视觉模型没有权重时应报告缺失资源，不产生完整预测。
3. 视觉模型收到大小相同但变动一个字节的权重时，应在预测前拒绝。
4. 原有像素模型在没有视觉权重的条件下仍须逐行复现。

最终目录资格检查使用 A 的完整图像解码契约，测试缺少字段、类型不符及超界尺寸。复验 BV-01 真实训练输入，两组的候选顺序与配置摘要应与冻结时一致。工程验收不重新评价花卉任务，不使用 H1、H2 或课程验证、测试。
