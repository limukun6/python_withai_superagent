# 两代随机傅里叶模型在同一批行上的成对比较

旧 BN01 在自己的 2,174 行 Bean 开发划分上，新一轮 A94 在自己的 2,178 行划分上都已公开过各自的结果。两条旧成绩的分母不同。这次在每个划分上补齐恰好缺少的一格，以排除数据版本、训练规模和筛选方式造成的错比。

直接克隆两个已有最终 pipeline 的参数，复用各自已有的冻结赢家。BN01 的模型只用 512 个核特征、带宽取 sklearn 的 scale、随机种子 42。A94 的模型保留原线性块、拼入按训练距离中位数定带宽的 512 个核特征、固定种子 20261123。两者均全量训练一个多分类逻辑回归。A94 的 8,710 行上补一次旧头，BN01 的 8,714 行上补一次新头。各批数据的两份预测全部冻结后才计分。两套划分来自同一原始来源，有重叠；比较逐套报告。

预定相对于旧核的解释标准是两套都净增、各增加至少 3 行，才称新版本在这两份开发划分上一致更好。只做 2 次本地监督拟合，模型 API 0。各指标、数据集版本和开关都保持已注册值；本项是知晓历史分数后的研发补强。
