# A-11：同版本固定/动态预算调度开发对照（2026-11-21）

运行前登记，开发基线5ed06c6。A维护正式循环与对照接入，不改变B方法或配对晋级规则。本批先实现ab-fixed入口，软件检查通过后冻结源码，再执行六条路径。API上限0。

## 唯一对照因素

动态组ab-v1沿用B当前调度。固定组ab-fixed先探索4个不同候选，再按primary主指标取前3名，每个在confirmation_1/2均复核，最后重训：4+6+1=11实际fits。首次anchor相同；后续新方法选择复用同一个B本地选择函数，固定组仅屏蔽复核动作（传入空确认划分前缀），避免另写一个弱候选排序。两组按同一个B selection_evidence规则选型，不将固定组改成均值选型。每条最多11fits而非强求动态也用满11。

固定组只接受单次评估/重训均1fit、总额度11的当前闭合目录；目录不足4则探索全部，再复核最多3个，保留refit，实际少用如实记录。不浪费余额填充同配置重复训练。worker失败整批停止、不重试；证据不完整不得继续或选型；不足预算完成固定的全部复核则在执行前明确拒绝，不能只跑有利的一半。固定组短名单与顺序由实际primary观测确定，后续不随新复核成绩更改；平分按candidate ID。

## 共同条件

复用A07封存bean/sms/digits数据文件，逐字节哈希核验；三个已见开发任务、外层45101，内部707/808/909。两组同输入、主指标、候选全集及能力、anchor、内部真实train/search行ID、共享300秒/worker60秒、11fit上限、相同CPU线程/缓存禁用。源码和pip依赖全批冻结。

运行顺序预先轮换：bean fixed→dynamic；sms dynamic→fixed；digits fixed→dynamic。六模型全部冻结后统一评分，外层标签不进控制器。每任务每组各一条路径，上限66fits；不能复用旧A10模型作另一源码组。主训练预估3分钟，交付约35秒，全批3–6分钟；上限30分钟训练加6分钟交付。
