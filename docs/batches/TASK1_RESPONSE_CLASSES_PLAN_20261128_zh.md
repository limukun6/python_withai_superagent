# 其他画像的回答能否帮助解释某个画像的历史？

前几批直接使用每个画像的平均表现。这里检验一个不同的假设：有些画像对不同种类的券表现出相似的接受模式，其他画像可以帮助估计这个模式。预先固定 5 个潜在类别，从拟合侧的接受和拒绝记录同时学习类别、情境难度和该画像的类别概率。完整情境的估计向粗粒度情境收缩。新画像使用总体类别比例，新情境使用对应粗类概率；决策不读取评价批其他行。仅使用训练包的两个训练成员。

单一晋级候选：保留情境树的预测，在 log odds 上加入一半的“有这个画像的历史”相对“只知道总体类别比例”的差值。机制对照固定地把训练画像的类别概率循环错配，另报潜在类别模型单独预测。任何方案均不调分类阈值。

沿用 112801 的三个评价折，重跑原树并核对预测哈希。每折一次监督树拟合、一次有监督潜在类别估计（一个初始化，固定最多 60 次 EM 更新）。三折预计 30–90 秒，0 API。晋级要求平均至少 +0.5pp、至少两折为正、最差 ≥−0.5pp、累计优于错配。通过后自动跑后两折，后两折累计为正且五折汇总至少 +0.5pp 才进一步接入。仅本训练集开发证据，实际验证留到自主入口晋级后。
