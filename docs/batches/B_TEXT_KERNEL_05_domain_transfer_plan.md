# 三种评论来源的轮流留出实验

此前非线性 MiniLM 候选在一份标题划分和 SMS 各有小幅净收益。以完全独立的公开情感分类数据检验迁移。采用 Kotzias 等人的 UCI Sentiment Labelled Sentences（DOI 10.24432/C57604），含商品、电影、餐馆三类文本。每次用两种来源的句子训练，将第三种来源的全部句子留出，三种来源各轮到一次。按项目已有的标准化文本分组，凡在留出来源出现的文本组均从本轮优化输入排除。保留留出文件中的原始行及顺序，不按结果挑样本。[UCI 数据说明](https://archive.ics.uci.edu/dataset/331/sentiment%2Blabelled%2Bsentences)

三轮均用相同匿名单篇文本契约，指定 macro-F1 为主指标，另列准确率。优化包不含领域名、外部留出或另一臂的历史。每个领域分别实跑原 A29 全菜单与增加非线性特征的完整菜单，最多 11 次实拟合含重训、1,200 秒总时限、300 秒单次。顺序预先固定为商品原→新，电影新→原，餐馆原→新。两条代码树除已登记 B 方法相关文件外均相同。六条路径共至多 66 次实际拟合。全部模型冻结后，逐一在被留出的领域导出，两次独立进程输出必须逐行一致。不同领域在不同轮次担任训练或留出角色，三轮共享训练来源，分别报告。新增模型 API 为零，课程正式验证、测试和 H 均不参与。
