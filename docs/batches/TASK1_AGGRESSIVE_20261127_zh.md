# Task1 激进探索：外部数据没有余量，公开标签必须拒绝

2026-11-27。回应"没有限制，可以更激进"。本文件记录两条**先于任何训练**得到的事实，它们决定哪些激进路线根本不该走。

## 2 事实一：课程包就是完整的 UCI 原始数据，外部数据没有余量

下载 UCI 原始数据集（dataset 603，12,684 行）后逐行比对 21 个文档列：

| 集合 | 行数 | 唯一行 |
|---|---:|---:|
| 课程 train | 8,117 | 7,961 |
| 课程 val | 2,030 | 2,016 |
| 课程 test | 2,537 | 2,525 |
| **合计** | **12,684** | — |
| UCI 原始 | 12,684 | 12,316 |

**8,117 + 2,030 + 2,537 = 12,684，正好等于 UCI 全量行数。**

也就是说：课程把**整个 UCI 数据集**划成了 train/val/test，并不存在"课程只给了一部分、外部还有大量数据"的空间。逐行哈希比对后，UCI 唯一行中只有 **589 行（4.8%）**未出现在课程包里，而且这些差异更可能是列格式/重复行的对齐问题，不是真正的新样本。

**结论：外部数据增强这条激进路线基本无效。**最多加 589 行（约为训练集的 7%），期望收益在 0.1pp 量级。

## 3 事实二：94.9% 的指定测试行可以直接在公开 UCI 数据里查到标签——必须拒绝

这是更严重的一条：

| 项 | 数值 |
|---|---:|
| 指定 test 唯一行 | 2,525 |
| 其中能在 UCI 原始数据里精确匹配到 | **2,397** |
| 占比 | **94.9%** |

UCI 原始数据是**带标签的公开数据**。因此存在一条"技术上可行"的作弊路径：拿 test 特征去 UCI 里查标签，可以直接报到 90%+。

**我们不做，并且要主动防：**

1. 任何外部数据并入训练前，必须**排除所有与 val / test 特征精确匹配的行**；
2. 该排除要作为证据写进清单（`excluded_due_to_designated_split`）；
3. 报告里明确写"我们发现了这条路径并拒绝使用"。

**这不是洁癖**：课程明确要求 test 只用于最终评估；用公开标签反查等于把测试集变成了训练集，成绩再高也没有意义，而且一旦被抽查到就是诚信问题。

## 4 对 80% 目标的判断

| 参考 | 数值 |
|---|---|
| 我们的指定验证 | 76.31% |
| 公开文献最高准确率（TWD-XGBoost） | 75.60% |
| 公开文献里"78%"级数字 | 是 **F1**，不是准确率 |
| 距 80% | +3.69pp = 75 道题 |

**在合法路径下，80% 没有任何证据支持。** 我们目前的 76.31% 已高于公开最好准确率。把目标定在 80%，只可能通过两种方式"达到"：泄漏公开标签，或在一个被反复评分的验证集上过拟合。

## 5 仍然值得试的激进路线（按下注顺序）

| 路线 | 机制 | 期望 | 成本 |
|---|---|---|---|
| **A 种子袋装** | 同一 token 树训练 5 个种子，概率平均 | +0.2–0.5pp | 5×fit，约 1 分钟/折 |
| **B 更高类别组合复杂度** | `max_ctr_complexity=3/4`，让 CatBoost 组合更多 token | 未知，可能 +0.3pp | 1–2×fit |
| C 学权重的 stacking | token 树 + 字段树 + 逻辑回归的 OOF 权重 | +0.2–0.4pp | 需 OOF，成本高 |
| D 直推式伪标签 | 用 test **特征**（不用标签）做自训练 | 不确定 | 中等 |
| E TabPFN v3.5 | 需接受门控许可；v2 已 −5.7pp | 低 | 需授权 |

前两条（A/B）已在本批执行，结果见下节。

## 6 已执行：袋装与更高组合复杂度都不晋级

同一批筛选折（种子 707 / 811 / 823），对比已记录的单种子 token 树成绩：

| 折 | token 树基线 | 袋装 5 种子 | ctr=3 | ctr=4 |
|---|---:|---:|---:|---:|
| 707 | 0.775851 | 0.769278（−0.66） | 0.769278（−0.66） | 0.767428（−0.84） |
| 811 | 0.758896 | 0.756607（−0.23） | 0.753534（−0.54） | 0.758451（−0.04） |
| 823 | 0.754462 | 0.768187（**+1.37**） | 0.768187（+1.37） | 0.770037（**+1.56**） |
| **均值** | — | **+0.16pp** | **+0.06pp** | **+0.22pp** |
| 上升折数 | — | 1/3 | 1/3 | 1/3 |
| 晋级（≥+0.5pp 且两折上升） | — | ❌ | ❌ | ❌ |

**关键观察**：同一路线在三折之间可以从 −0.84pp 跳到 +1.56pp。**折间波动比均值大一个数量级**，这正是我们一直说的噪声带——任何一折的"提升"都不足以当证据。

两次 bag5 与 ctr3 在 707/823 折上数值完全相同（0.769278 / 0.768187），属同分不同路径，已记录不做因果解释。

**结论：A、B 两条路线都不晋级。**保留 76.31%。

## 7 结论与下一步

1. **外部数据无余量**（课程包 = 完整 UCI），增强路线基本关闭；
2. **公开标签可反查 94.9% 的测试行**，这是必须拒绝并主动防护的作弊路径；
3. **袋装与更高组合复杂度**在训练内折上不晋级，且波动远大于均值；
4. 80% 在合法路径下**没有证据支持**；我们的 76.31% 已高于公开准确率上限。

下一步如果有价值，只剩两类，且都要先提出**能解释共同错题的新假设**：

| 方向 | 前提 |
|---|---|
| 误差结构分析（在训练内折上做，不碰指定验证） | 先找出 24% 错题集中在哪类 coupon / 哪类画像覆盖 |
| 学权重的 stacking（OOF） | 需要额外 OOF 训练，成本明显高于前两条 |

## 8 边界

- 本文件只比较**指定验证**之外的训练内折，不重开指定验证评分；
- 正式 test 全程封存；
- 任何路线都要先过"两折都更好、均值 ≥ +0.5pp"才晋级，否则保留 76.31%。
