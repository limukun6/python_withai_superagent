# 统一版训练内比较 BGE、MPNet、RoBERTa 及自主融合

冻结 689/940 的双模型交付。研发只用训练集，与上次 6,608 行五折实验使用完全相同的训练行、确认行和评价行。原五折结果已知，此次结果属于开发复验。训练内各折基础训练、规则学习、启用确认、外层评分按共享标题组互斥。每折复用已冻结的原双模型和 MiniLM-L6 的训练外概率，分别在该折原始基础训练区拟合 BGE-small-en-v1.5、all-mpnet-base-v2、RoBERTa-base 的分类头。两种通用句向量取左右差值，RoBERTa 成对读取两种顺序，取句内分词上下文均值的左右差并对两种顺序做反对称平均。三者沿用共同词法、风格、左右互换增强、C=0.3 的逻辑回归分类头。词表、IDF 与风格尺度仅用每折基础训练行拟合。固定作者权重的逐输入向量可以跨折缓存，特征提取接受文本，不接受标签。

Agent 同时看见所有具有实测概率的成员。学习区按答对数选择单模型、任意等权双模型两个入围方案，遇到同分优先少改基线的方案。另学两种概率融合。第一种对所有模型学习一组非负、总和为一的权重。第二种根据每个模型与原双模型的置信、分歧和标题改写程度，逐题学习这样的权重。两者在学习区优化二元对数损失，向原双模型合计占八成的先验收缩。所有规则均保持左右交换时预测翻转。全局决策还可以保留原双模型。候选须在学习区净增大于零，且在单独确认区相对原双模型至少多对 max(2, ceil(0.002 × 确认行数)) 题；按确认区净增、改动少、规则简单的顺序选定。决策只读两处训练反馈，不读取外层正确答案。保存各折模型与决策，重载输出预测，全部五折封存后才计算成绩。

逐一报告三个新增模型、单模型入围、等权搭档、固定权重、逐题权重及 Agent 实际选择。报告正确题数、改对/改错、每折差值和 2,000 次共享标题组配对重抽样区间，种子 28113。晋级研发复验仍要求至少四折净增、合计至少加五题、区间下界大于零。五折每折 3 次新增真实分类器拟合、2 次融合权重拟合。另将 2 次用标签选单模型/搭档保守计入学习次数。加上 3 次已训练的参考成员，每条路径计 10 次。新增训练合计最多 15 个分类头、10 个融合权重、10 个离散方案选择。线上模型 API、课程指定验证、正式测试及 H 访问为零。权重下载只传模型文件名与版本。实际冷启动或产品验收单列，不重复计算已有模型。
