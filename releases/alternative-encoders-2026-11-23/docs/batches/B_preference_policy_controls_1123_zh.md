# 相同预算下，固定安排和动态安排各能做出怎样的选择

此前对比的是台词自主适配与直接借用标题模型。本批的主对照让两组都取得同一个任务的训练标签，使用相同生产代码、候选目录、训练包、内部分区和种子 18643，均允许最多 11 次真实拟合、模型 API 0 次。主对照衡量整套调度策略，包括怎样使用反馈和是否组合模型。

- 固定组使用原生 `ab-fixed`，先探索四个候选，按实测分数选择前三，各在两份内部分区复核，再用完整训练包重训。固定的是资源分配；选择谁进入复核仍使用了反馈。
- 动态组使用同一联合目录的 `ab-adaptive-complement --cover-untried-encoder`，可按逐行证据分配探索和确认、选择组合、提前停止。两组最终重训成本均计入实际拟合数。按各自正常入口运行，不人为指定最后的模型。
- 再提供低成本的“只采纳开局第一个建议”参照。原生 `ab-v1` 只给 2 次拟合，1 次开局与 1 次完整重训，核对只有一个候选且首个动作的历史为空。此参照衡量继续探索相对直接定方法的收益，预算不同，单列展示。
- 先做台词：复用 8 次拟合的既有 11 上限动态路径，实际新跑固定和单建议两组，最多 13 次。然后做标题：旧联合路径上限是 10，为得到严格配对，另跑 11 上限的固定与动态两组，最多 22 次。标题单建议仅当现成的同数据同方法全量模型与空历史首动作可以核对时复用，否则此次省略。两项均不调用模型 API。
- 两套主策略之间，逐行核对三个内部分区的训练与搜索文本、标签、原行号和顺序，另核对目录、预算和任务契约。动态组合策略的执行包还携带逐行概率请求标志，因此分别记录执行包指纹。先冻结双方所有逐行预测再评分。台词只评之前留出的 450 对；标题只评训练包内部留出的 1,693 对。报告净差、改对与改错、按影片组或共享标题组计算的区间，以及真实训练次数。两套保留集已有先前结果，只用于匹配对照。课程的 940 行与正式测试继续按原计划保留。
