# Task2 更换训练划分后的结果

Agent 在此前三次独立运行中分别选中了 GTE-base、GTE-base 与 GTE-small 等权融合、BGE-small 与 MiniLM-L12 等权融合。试验先锁定这三个选择，再在 8,301 条训练样本上重新划分两次。每次划成五组，同一连通组的标题始终放在一起，每条样本恰好被留出一次。

| 训练内留出结果 | GTE-base | 双 GTE | BGE 与 MiniLM | 双 GTE 对单模型 |
| --- | ---: | ---: | ---: | ---: |
| 第一轮，8,301 条 | 6,051（72.89%） | 6,104（73.53%） | 6,042（72.79%） | 多 53 道，五组均赢 |
| 第二轮，8,301 条 | 6,039（72.75%） | 6,071（73.14%） | 6,043（72.80%） | 多 32 道，五组赢四组 |

第一轮双 GTE 纠正单模型的 231 道，同时丢掉 178 道。第二轮相应为 219 道和 187 道。两轮使用同一批样本，不能把它们加成 16,602 条独立观测。历史课程指定验证结果分别是单 GTE 700/940、双 GTE 693/940，组内优势在指定验证上没有复现。

当两个 GTE 单独都答错时，另外两个模型中至少一个能做对的记录分别有 465 和 497 条。这个数字只反映互补空间，实际部署仍需要仅凭输入与训练反馈判断什么时候调用第三方预测。全程实际拟合 40 次，各方案共用相同成员的训练结果，模型 API 为 0。此次没有读课程指定验证、正式测试或 H2 的标签。
