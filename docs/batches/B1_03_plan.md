# B1-03 复核前检查候选还有几次获胜机会

从 B 交接提交 `ad981ea04e9525d20c5ee43e7637d66cfa6e4903` 独立开发。旧版晋级需要在至少两个登记划分上严格领先，且平均增益达到 0.002。在原匿名任务第九个动作前，当前挑战者已取得一平一负，尚有一个登记划分。

只调整 B 发起复核的条件。在同一候选对中，把两边已完成的配对计入胜负，用剩余合法划分给挑战者计算乐观的胜场上限。只有上限低于既有晋级要求才排除本次复核。随后按既有次序处理其他候选。每次排除都在返回动作里保留理由和当时可见的 trial 编号。最终晋级规则、方法目录、输入输出格式与 A 的入口沿用交接版本。

先从 B1-02 已冻结的输入摘要和动作重放，从第一步比较到第一个分歧为止。预期前八步保留原路线，第九步跳过原逻辑回归的复核。另一项验收是原来第一轮落后的树模型仍可在后两份真实复核中反超。重放只验证决定，消耗零训练、零请求。

随后只在原匿名数值夹具上运行一次新策略，沿用 B1-02 的合成数据、候选、行分组、随机种子和时限。整条路径最多 11 次实际分类器训练，含一次最终重训。每次向子进程收集真实 fit 记录，并用新进程重新预测原 31 行匿名输入。记录新动作、实际消耗、最终选型与两次重载是否逐行一致。训练内分数只描述这条运行轨迹。Task2、课程验证集和正式测试集均不在本批范围，付费请求额度为零。

复跑命令为 `python -m scripts.run_b1_03_pruning NEW_DIRECTORY`。若保留了 B1-02 原始状态，可追加 `--prior-states PATH_TO_INPUTS.jsonl` 逐项核对历史指纹。新目录保存 protocol、results 与 completion，已有目录直接报错。提交脱敏结果，训练数据、逐行输入和输出模型保存在本机。
