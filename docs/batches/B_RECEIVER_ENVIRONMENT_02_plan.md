# 缺少训练时依赖时能否用同一路径的已训练模型交付

以接收环境实验的三个模型和三个机器配置为固定九格。原模型的依赖可用时始终交付原模型。对有额外依赖的最终模型，另从同一次真实运行的已完成 primary 试验中，按当时已经验证的内部主分降序，取第一份仅需 CPU 和常规 scikit-learn 的模型做备用，同分按试验编号。明确排除编码器及 CatBoost，不跨路径借模型、不重训。原模型没有这些额外依赖时不用附备用。先核验真实历史、实际训练次数、候选参数、模型与数据指纹，将全部备用选择登记并封存，再接触旧开发留出标签。

在相同的干净接收包中，每格先探测是否有必需库和已校验编码器权重，然后通过原生 predict 读取选定的完整模型与任务说明。额外模型写入单独目录，记录原 trial、模型指纹、训练范围与交付原因。通用程序仅用候选声明和运行环境作决定。每个备用都是当时的内部试验权重，不能标成全量重训。对每个条件报告能否生成完整预测、与原模型的差值、两者各自独有的正确数和增加的文件体积。9 格均冻结预测后统一对历史留出评分。没有新训练和付费调用，不修改 A 的正式交付入口。
