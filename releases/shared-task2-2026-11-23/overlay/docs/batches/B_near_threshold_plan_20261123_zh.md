# 用训练数据检验一次临界停止

共同入口在 8,301 行匿名训练包的首轮内部评估上选出一个单模型。十种两模型组合中，最好的组合多答对 3/1,693，现有 0.2 个百分点门槛要求至少多 4 题。事后提出的问题是：这类只差一题的组合，是否值得用剩余额度做一次确认？

只检验已完成的调度记录在停止前排第一的组合，以及它原本会交付的单模型。选择程序沿用当前投票公式；只有组合包括单模型、内部改善为正且恰好差一题才进入。本轮预先固定初次评估的所有共享标题组都排除。其余训练组按固定盐值与组键的 SHA-256 对 8 取余，余数 0 和 1 各成为一个复核区，其余 6 个桶共同训练两个分类器。两个复核区和新训练集各自没有相同标题组。复用一对新模型在两个区独立题目上做等权投票。两个区共享训练模型，均来自历次开发使用的课程训练池。

只有组合在两个区都多答对题，且合并净收益至少达到原 0.2 个百分点门槛，才进入下一条从头跑的调度实验。其他情况保留原停止规则。使用两个真实分类器拟合、模型 API 零次，不读课程验证和正式测试。交付每区四格计数和匿名分组结果。本轮属于对一次历史停止决策的研究。
