# BC1-03 · 六组运行、续接与评分

B 子矩阵沿用 BC1-01 的标题偏好与 Dry Bean、两个任务各六组的顺序、实际训练行、共同目录、首轮候选及时间额度。每组 11 次监督拟合（含重训），Flash 组最多 3 次。同任务四个付费组共用已有课程账本及稳定任务 ID。每个任务每组的新增许可默认沿用 A12 的 0.30 元；两任务合计至多 2.40 元的本轮许可，课程累计另算。

本批只验证工具，新增训练、模型请求、正式外层评分均为零。先在正式入口上验证两任务所有选项，使用 BA12 的真实开发运行验收模型回执，再演练缺模型、已中断及同一组同时启动。旧开发路径不算入最终 C1。预期不重复训练，不重试未知请求；任一组缺少合格回执时，评分入口应在打开标签前返回。

共同版本冻结、真实账本可用时执行子矩阵。每个组先登记唯一运行意图；已成功的组复查模型并跳过，出现未完成的组保留工件且中断。12 个模型全部核验后，先对无标签文件导出所有预测，再用两份已登记的训练内留出计算主指标。批准的正式动力来自 A 的六组入口，研究工具负责顺序与交付。
