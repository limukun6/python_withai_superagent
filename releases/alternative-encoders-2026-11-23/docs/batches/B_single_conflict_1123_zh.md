# 当开局和复核支持不同单模型时，由第三份证据裁决

台词实验中，开局 E5 比普通十二层多答对 2 对，首次确认则少答对 4 对。旧版在未晋级组合时直接保留开局领先者，即使 11 次训练额度仍有余量。已知这两个模型在台词外层留出上的大小关系，因此此任务用于诊断机制。接下来在读取新的第三内折证据前固定以下规则。

1. 仅在动态目录中显式启用。已有组合达到晋级门槛，或已确认单模型均未超过开局领先者时，照已有决定执行。
2. 组合未晋级、首次确认有单模型胜过开局领先者时，选择首次确认正确数最高者挑战开局领先者。同分依次按开局分数和原探索顺序处理。两方均使用既定的第二确认划分，预算只有足够完成两项测量并保留原终局重训预留时才启动。
3. 在双方有完整第三份逐行证据后，同一原行在多个划分出现时先取它的平均正确值，再按不重复的行计分。挑战者的累计正确率至少高 0.2 个百分点，而且在第三划分中、此前两划分从未用作评价的整组样本上净多答对，才让它独立接替。任一条件未满足均保留原领先者。外部保留区标签不进入决策。
4. 用台词开发包做单条完整正式运行，种子 18643、每条最多 11 次含重训、模型 API 0 次；沿用此前旧版路径作对照。启动新实训前用预算不足、两方交换、重复评价行和第三划分缺少新群组等构造回归测试。用当前 Task2 已保存的两个种子验证已有组合及无冲突情况能保持既有决定。后续新种子和新任务可独立检查这项开关的外推能力。
