# BA11 · 核对正式调度接口与原来实际跑过的动作

以队友 A 的 `0418ae1` 和 B 合入后的共同源码为比较对象。在 B1-07/08 十六条已完成的真实路径上，将每一步当时真正可见的状态、候选和可信训练内观测交给当前正式固定／动态函数。四个任务两个开发划分，两种调度全部纳入。旧路径原源码及文件身份单独验证，保留旧版本来源。

对每个正式动作跑 A 的现有准入函数。分别比较动作类型、候选、内部划分和预计拟合数，以及六个输出字段是否逐字相同。固定组更换过调度文件，因此要分别记录解释文本或证据引用的差异。若可执行动作分歧，从首次分歧起不再把后续历史解释成新策略真实运行；记录首处差异和共同前缀长度。最后单独询问正式命令行选项检查器是否接受固定／动态的 local、raw、checked 组合，全程不连接模型。

本批新增训练、模型预测、课程评分及 API 额度均为零。它检验接口行为，正式新版主实验仍需以新版自主跑出的落盘结果为准。
