# 第三个模型应在什么时候接手

冻结双模型和 689/940 的交付。新一轮只使用训练成员及训练内留出的特征、标签。历史上发现的 40 道错题不提供给选择器。既有第三成员由统一运行的共同 primary 证据选出，身份连同已交付的两个成员在新实验开始前冻结。输入列的顺序变化应使两侧预测互换，接手决定保持相同。

第一轮只用保留的 primary 训练外概率学习一条硬切换规则。双模型与第三模型预测不同才有接手机会。分类器根据双模型置信度、第三模型置信度、两原成员分歧和一致状态估计第三模型胜出的概率。由历史首个确认划分去除与 primary 重合的共享标题组后做选择，最后一次性在旧的 1,693 行训练内留出上检验。先封存各策略输出，再连接留出答案。旧面板用于研发，不能据此晋级。本段最多 1 次监督门控拟合，禁止模型 API。

第二轮在相同口径上引入两种机制，再把三个方案放入一次共同预算的自主选择。第一种用相同训练外证据学习两种情况（原成员一致或分歧）下的置信优势阈值，要求触发区域至少有 16 个冲突样本且胜率的 Wilson 单侧下界超过一半。第二种用对数损失学习逐对融合权重，输入还包括两边文本的词汇重叠和长度差，向三成员等权的小模型权重收缩。三个方案各计一次监督学习。若拟合和独立确认都没有足够证据，Agent 可以逐题或整条路径保留原双模型。确认门槛为拟合区净增大于零、确认区净增至少 max(2, 向上取整(0.002×确认行数))；按确认区净增优先、变动少优先选一项，精确同分按登记顺序。冻结策略再评分。

第三轮将第二轮固定的三种策略原样带入五个新划分，在 6,608 个历史拟合样本中做不重叠的外层评估，每一行只做一次外层评价。用共享标题连通分量哈希分配 10 个固定桶，每折以连续两个桶做外层评估、其后两个做门控学习、再一个做门控确认，余下五个和全部 1,693 个旧留出样本只供基础分类器拟合。每折重新训练原双模型的两个分类头及自动选出的第三模型分类头，三者使用完全相同的训练行。基础模型训练、门控学习、门控确认、外层评价四者在每折互无共享标题。词汇表、标准化和语料频率只从相应训练部分学习。轮换共享训练池，五折评价样本互不重叠。

每折上限 3 次基础拟合与 3 次门控拟合，总计 30 次，模型 API 0 次。各折模型、决策和外层无标签预测全部冻结后统一开答案。同时报告固定双模型、三者等权、只听第三模型、三个候选以及 Agent 真正采用的规则。记录改对、改错、接手次数、实际挽回的共同错误、每折净增和按共享标题组 2,000 次配对重抽样的 95% 区间，种子 28113。进入下一阶段要求 Agent 真正采用的规则在五折中至少四折净增、合计净增至少五行、组配对区间下界大于零。工程或数据核验失败单列。课程指定验证、正式测试与 H 均不打开。
