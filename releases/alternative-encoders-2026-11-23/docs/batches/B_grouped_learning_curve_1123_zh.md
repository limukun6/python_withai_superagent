# Task2 训练规模与准确率

在同一批标题上，比较当前 E5＋词频 MiniLM-L12 等权组合使用一半、四分之三、全部可用训练组时的准确率。这个问题约束在当前模型与样本规模内。课程正式训练包最终重训由双方冻结后执行。

在原 6,608 行匿名训练包内复用已经登记的 5,017 行拟合池，以及 814 行和 777 行两个确认组。相同或相连的标题归到同一组，训练池与两个确认组互不相交。确认组在以往研究中已经使用，本实验作为学习曲线。始终只用拟合子集重建词表、词频、归一化和有监督的分类头。

- 对训练组 ID 独立使用 `curve-a` 和 `curve-b` 两个固定盐做 SHA-256 排序，分别取组数前 50%、75% 和全部。每个排序内严格嵌套，100% 共享，只执行一次。标签和已有成绩均不参与抽样。原数据包内的行序保留不变。
- 每个规模均用主线 E5、带措辞熟悉度的 MiniLM-L12、原正则参数、左右互换增强和原生等权概率投票。100% 规模复用已核验的 E5 分类头，其余四个子集各拟合两个头，另补一个 100% 的 L12 头。最多 9 次新增本地监督拟合，0 次模型 API。
- 全部五种模型的预测先冻结，再评分。记录两组和合计的正确数，对每个排序报告 50%→75%、75%→100%、50%→100% 的逐行增减及按共享标题组自举区间。两种排序共享评估样本，分别报告。只在两个排序中 75%→100% 的合计都上升时报告观察到最后一档收益，不据此外推新的课程成绩。
