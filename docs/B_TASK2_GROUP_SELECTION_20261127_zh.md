# 相近的融合方案该怎么选

用同样的六个模型生成 41 个候选，包括单模型、两模型等权融合和三模型等权融合。按标题间的关联分组，把同组样本放在一起，轮换三个角色，分别用于提名、复核和评价。每一行只在其所在划分的一次评价中计分。共比较 15 次选择，复用已有模型的逐行预测。

| 选择规则 | 五份训练内留出合计答对 |
| --- | ---: |
| 学习区选出的最佳单模型 | 5,931 / 8,301 |

| 在接近的方案中更看重各组平均成绩，再做双指标复核 | 5,975 / 8,301 |
