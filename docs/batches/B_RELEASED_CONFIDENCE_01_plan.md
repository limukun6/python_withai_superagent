# 冻结模型知道自己哪一题可能答错吗

只用 B-ROUTE-02、03 的代表参数组已冻结模型。优惠券与标题各两份已登记训练内留出 45101、45102，这两份在各自任务中可能重叠，分别展示。读取真实发布包的仅训练副本核对行号，不打开课程提供的验证或正式测试。逐例取模型给所选类别的概率作为信心，先按信心再按原始行号排序。五个等数量组事先固定，分别记录行数、正确／错误数、平均信心。报告最低约 20% 收集了多少全部错误，以及最高约 80% 行上的准确率与覆盖率；完整预测得分仍引用全部行。

另按固定的 0.8 与 0.9 概率报告覆盖与错误数。核验概率列与类别顺序、取最大概率得到的标签与已冻结导出的一致性。对整个二分类留出记录 Brier 分数与 10 个固定等宽箱的加权绝对校准偏差。所有分组先依赖输入行号与已有概率，不看标签生成规则。没有阈值拟合、额外分类器、重新训练、API 请求及新方法晋级。这是对错误反馈是否包含实用信号的诊断。
