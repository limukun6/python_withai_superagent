六个配对均有效，逐行预测差异均为零。新增的第 5/6 项在四组进入复核，在六组都未成为最终赢家。累计 132 次拟合、878.6 秒、0 次模型 API 调用。

开发阶段的文本 42011 出现过 +1.96 个百分点，本轮三个新种子均持平。6/2 相对 4/3 的配对耗时变化中位数约 +2.1%，两条预设晋级路线均未达标。发布配置选择 4/3。三个种子是同一任务训练数据的重新分组，结果范围以此为准。

额外的事后回放从每条 4/3 记录取搜索前两名及其三划分记录。六组都保留原赢家，新增拟合为零。加上开发阶段共十组未发生换模。这项结果支持后续单独测试 9 次拟合的 4/2 配置，实际运行耗时与晋级仍需另行测量。

## 交付冒烟与故障检查

以统一命令入口跑匿名数值表格多分类和匿名 RGB 图像多分类，主指标均为 macro-F1。表格夹具有验证集，图像夹具只提供训练集和无标签预测输入。两套均完整确认、重训，并在新的进程中重载输出 15 条预测。验收能识别行 ID 顺序错误，实际预测入口拒绝内容被更改的模型文件。合成示例用于检验执行流程。

19 项离线检查覆盖时间窗口、部分结果、账本预留和恢复、流式输出截断与缺失用量。截断案例在日志保留已知 token 用量且不产生可执行提案，缺失用量案例保留未结算请求并拒绝后续调用。校园逐轮 Flash 对照仍受历史用量待核对影响，本轮未消耗模型额度。
