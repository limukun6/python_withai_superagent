# 两次追加拟合的用途

前一批 E5 与 BGE 路径各实耗 10 次。E5 和十二层 MiniLM 的等权概率组合在主分区与第一次复核均超过两个单模型，合计 2,711 个评估行次净多答对 8 次。依据已登记的两分区、0.2 个百分点门槛，仅该组合进入后续整集检验。此前已看过开发保留区的单个主分区检查点与单独方法的诊断，因此本批保留区属于重复使用的开发数据。

1. E5 路径追加最多 1 次，使用同一份 6,608 行的完整重训载荷训练 E5 分类头。复用该路径的十二层完整重训模型，按原规则等权平均两个概率。这是由内部分区证据触发的后续实验，独立于先前标准 Agent 已完成的选型。冻结两种权重和组合后，用两个新进程通过标准预测入口输出相同的开发保留区。报告 1,693 行上两个单模型和组合的配对差异，以及按共享标题组的 5,000 次重采样区间。
2. BGE 路径追加最多 1 次，跑原调度没有执行的第一次复核。它在首轮落后，已见开发保留区主分区检查点表现较好，所以这是一项人工发起的反事实，不改变原调度结论。分别比较 BGE、MiniLM 和两者平均在主分区及第一次复核的表现，按原登记门槛判断。全程不为 BGE 做整集重训。

追加两次均由原生隔离训练 worker 执行。每路累计最多 11 次，两条路径合计最多 22 次。沿用匿名输入、源代码与随机种子，并记录每次真实拟合及零网络限制。该研究后续没有启动课程指定验证的资格，正式测试与 H 继续封存。
