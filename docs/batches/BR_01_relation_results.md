# 两列文本能正确进入三分类，按整行分组会拆开同源句子

使用 SICK 原始 TRAIN 的 4,439 对句子，把共享句子或来源图注的记录连在一起，共得到 788 个来源组。外层留出的 754 对来自 157 个组，其余 3,685 对属于 631 个训练组；两边没有共同的可见句子或来源组。本批只验输入和划分，没有运行模型。

| 训练内部划分 | 默认留出行数 | 其中与训练共享实际句子 | 其中来自训练出现过的来源组 | 预登记来源隔离后的留出行数 / 共享来源 |
|---|---:|---:|---:|---:|
| 首轮探索 | 737 | 682 | 718 | 499 / 0 |
| 第一次复核 | 737 | 677 | 710 | 557 / 0 |
| 第二次复核 | 737 | 679 | 726 | 566 / 0 |

默认三份划分均没有重复的完整有序句对。重复的是组成句对的句子或同一图注的改写。现有解析器把 `pair_semantics=relation` 读成有序文本列，三类标签保留，初始菜单有三个逻辑回归配置和两个极随机树配置。只有两列实际句子可作输入，图注来源和其他标注均未交给模型。
