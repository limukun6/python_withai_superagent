# 根据内部反馈决定一对文本是否需要第二个编码器

同一输入同时运行两个编码器需要额外计算。有些文本即使只运行一个模型也能得到相同答案。这里检验用训练反馈决定第一个编码器以及提前给出答案的条件，观察在另一个数据集上能否执行同一规则。

使用已冻结的两种开发任务及它们均有完整初筛和第一确认折记录的两个交付组件。标题为 E5 与带措辞熟悉度的十二层 MiniLM；台词为 E5 与普通十二层 MiniLM。台词两个全量头来自各自在完全相同的 1,744 行上重训的原生运行。研究用的候选范围预先指定，决策函数只看内部预测、真实标签和同组信息。

1. 在初筛折中选择单模型正确数较高者先运行。平局按候选 ID 字典序。初筛考察固定的置信度阈值 0、0.1、0.2、0.3、0.4 和 1。第一模型胜方概率与 0.5 的距离达到阈值时直接给出答案，其余才调用第二个编码器并等权投票。阈值 1 表示全量双模型。选择初筛正确数至少与全量双模型持平、同时跳过最多第二模型计算的阈值。同样多时取较高阈值。
2. 在第一确认折中剔除初筛评过的所有关联标题组，用余下的行核对这一个阈值。若正确数至少与全量双模型持平，且至少 10% 的行能提前判断，则采用该阈值；否则执行全量双模型。确认仅用于接受或退回该选择。样本共享文本关系仅来自匿名训练包；台词外层按整部影片留出。
3. 先同时冻结两个任务的决策，再对开发留出执行。记录第一组件实际处理的行数、本地 token，第二组件实际收到的子集，以及与全量双模型和单模型的配对正确数；同一批数据另跑全量作对照。所有留出预测保存后才评分。两个开发留出（1,693 对标题、450 对台词）以往已用于其他研究。课程 940 行和正式测试均不参与。新增监督拟合 0，模型 API 0。
4. 若两个任务的路由均能在留出实际跳过至少 10% 的第二模型调用，且两者的正确率损失均不超过 0.5 个百分点，再推进预设目录以外的复验。实际输入 token 受同批重复文本及前缀影响，故按编码器计数器报告。这里只测真实使用量，墙钟不作为判据。
