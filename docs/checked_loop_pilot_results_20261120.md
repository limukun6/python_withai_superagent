# 原始历史与检查记忆的完整循环对照

2026-11-20。本轮优先检验跨任务可复用的失败反馈能力。使用同一个决策接口和提示模板，在类别表格、成对文本两个发布任务上完成六条自主搜索路径。新增 66 次分类器拟合、12 次真实 Flash 调用，运行 1825.75 秒，约 30 分 26 秒。课程费用折算为 0.086265 元，学校账户实际扣费待核对。

## 瓶颈、结构与证据

| 瓶颈 | 本轮结构 | 实验及目前证据 |
|---|---|---|
| 配置事实集中于文本，其他类型缺少可靠说明 | 根据实际注册训练函数补充分类器事实，覆盖现有类别表格、数值表格、普通文本和成对文本的 expanded 目录 | 49 个候选均获得分类器说明。两个真实任务的 12 次提案通过配置声明核验。数值表格和普通文本目前只检查事实覆盖 |
| 假说失败后，后续决策可能忽视结果 | CheckedHistoryPolicy 通过共同 DecisionPolicy 接口，提供原始历史或额外的执行器检查与假说记忆 | 两个真实任务均出现第三步假说未通过、第四步重新决策的完整过程，第四步能够引用前次失败并改变方案 |
| 结构化反馈可能增加开销却没有效果 | 三组采用同一菜单、相同搜索与复核预算，对比原始历史与检查记忆 | 表格准确率持平，文本检查组比原始历史组高 1.6579 个百分点。检查组相对原始组在本轮两个任务都更快，但只有单次运行 |
| 无效调用后可能被随机恢复掩盖 | 决策策略可声明 stop_on_error，请求或提案错误立即停止本批 | 本轮 12 次请求全部成功，无随机恢复，失败停止分支尚未由本轮真实请求触发 |

相关 38 项测试通过，包括新增的原始输入屏蔽派生检查、数值表格分类器事实检查，以及原有假说与架构契约测试。

## 对照设计

两个任务均使用新的开发外层种子 43911，保留既有预留分区。搜索种子为 707。菜单采用 expanded，共享首个实验，后续三步自主决策。每条路径为四次搜索、前三名各追加两次复核、一次全量重训，共 11 次拟合。训练单次超时 90 秒，每路径总时限 1200 秒。

三组分别为本地 interleaved_routes、Flash 原始历史、Flash 检查记忆。两组 Flash 均读取任务契约、候选事实、原始配置和测量、错误分组及历史提案。它们使用相同输出格式和模型，每步一次请求。检查记忆组额外读取执行器计算的假说检查和重建记忆。原始组屏蔽 hypothesis_check、paired_error_comparison、explanation_audit 及 memory，后台仍计算相同检查用于评估。

同一状态下，两种上下文经程序核对，仅 checks 和 memory 字段不同。任务内三组首步预测逐项一致。表格先运行原始组，文本先运行检查组，部分平衡运行顺序。所有候选冻结后才评分相应外层数据。

调用使用 DeepSeek-V4.1-Flash，流式传输，实际 requests 超时 60 秒，失败停止且无自动重试。调用与费用集中记录在批次根目录，训练子目录的 llm_calls 为零，原因是自定义策略通过共同接口调用批次客户端。

| 类别表格 | 1299 | 72.2864% | 72.4403% | 72.4403% |
| 成对文本 | 1327 | 69.7061% | 68.0482% | 69.7061% |

表格中，两组 Flash 都相对本地对照净多判对 2 条。检查组相对原始组改对 37 条，同时新增 37 条错误，因此准确率持平，预测并非相同。

## 失败后实际发生了什么

**表格原始历史组。** 第三步深度 6、正则项 10 的 CatBoost 将内部总分从 71.6346% 提高至 73.6538%，高缺失组却从 78.1818% 降至 76.3636%。高缺失组仅有 55 条样本，下降相当于少判对一条。第四步试深度 8、正则项 10，仍声明希望改善高缺失组。最终复核选中该第四步模型。

**表格检查记忆组。** 第三步改试深度 4、正则项 10，内部总分从 71.6346% 提高至 72.5962%，同样出现高缺失组退步。第四步理由明确报告目标组从 78.1818% 降到 76.3636%，下一条假说缩小到整体准确率，并试深度 6、正则项 10。它撤回了目标组改善的承诺，原失败记录继续保留。该行为表明它读到并回应了失败，目标组修复仍待研究。

**文本检查记忆组。** 第二步 word_char_C0.3 的内部准确率为 65.9454%。第三步降低 C 至 0.1 后降至 65.0047%，联合假说未通过。第四步明确引用这次下降，恢复此前较好的 C=0.3，并增加统计特征，最终选中 word_char_stats_C0.3。

**文本原始历史组。** 第二步先选 word_char_C0.1，第三步再降至 0.05 后成绩下降。第四步也明确引用下降，恢复自己的较好 C=0.1，再增加统计特征，最终选中 word_char_stats_C0.1。因此原始历史组也能自行回应失败。两组参数路径从第二步已出现分叉，文本最终收益无法单独归因于第三步之后的失败检查。

## 已验证能力与尚缺证据

本轮验证了统一接口、候选事实、训练后检查与后续自主决策可以在两类真实任务上连成完整循环。检查组的决策出现了可核对的失败引用，并在文本任务取得优于原始组的结果。

检查与记忆作为一组输入共同变化，尚未分离它们各自的贡献。每个任务只有一个新开发划分，每个条件只运行一次，结果仍可能受样本划分、候选空间和模型响应变化影响。本轮没有验证数值表格和普通单文本的性能迁移，也没有证明稳定超过本地策略。

后续应先冻结当前控制器和输出契约，在真实数值表格与普通单文本任务上验证同一入口。若要单独检验失败检查的决策作用，可在共同的已失败历史上比较两种上下文的下一步选择，再训练评估分歧动作。完整轨迹结果与同历史决策对照应分别报告。
