# Task2 的第三个模型，Agent 什么时候愿意用？

在统一入口从头运行五次，Agent 每次都试了一个第三模型，五次都交付原有的 MiniLM-L12（带词频熟悉度特征）和 E5-small。五折共答对 **4,733/6,608（71.63%）**，与同轮双模型逐行一致。本轮训练内实验没有通过晋级条件。课程指定验证仍引用统一冻结版的 Task2 **689/940（73.30%）** 和 Task1 **1,532/2,030（75.47%）**。本批只使用课程原包的训练 CSV 和说明。[冻结版指定验证](UNIFIED_AGENT_20261124_zh.md) · [本轮逐折与汇总](../research/crossfit_challenger_1124/result.json)

## 从头运行的结果

每个外层训练包只给两列匿名文本和一个结果列。将共享任一标题的样本归到同一组。Agent 从每折约 5,300 行训练数据中划出一块提名区、两块交叉反馈区。它按照双模型留下的误差，从 MiniLM-L6、BGE、MPNet 和 RoBERTa 的冻结表示中提名一个挑战者。两个反馈区轮流训练和预测，Agent 根据两份折外结果决定是否接纳挑战者，并在该折全部训练行上重训所选分类头。历史保留的 1,693 行未进入本轮五折的拟合或评分。五个新进程从原始无标签文本生成的 6,608 行预测全部与冻结决策一致。[预先登记的规则](batches/crossfit_challenger_plan_20261124_zh.md) · [分区指纹](../research/crossfit_challenger_1124/protocol.json)

|---|---:|---:|---:|---:|
| 原双模型 | 4,733 | 71.63% | 0／0 | 0 |

## 为什么继续研究 MPNet

单独复用旧批已经训练好的六个分类头，比较两种提名办法。第一种看候选表示能否解释双模型的错题；第二种看每个候选在训练反馈中以三分之一权重加入后，实际多答对几题。二者使用同一份资料和相同的确认条件。第二轮调换学习组与外层评价组，保留相同的确认组和分类头。旧批基础分类头的训练构成与本轮冷启动不同，下表各列都与本列的双模型配对。两轮覆盖同一批 6,608 行，属于开发回放。[首次回放登记](batches/challenger_nomination_replay_plan_20261124_zh.md) · [轮换登记](batches/challenger_nomination_rotation_plan_20261124_zh.md)

| 旧预测上的做法 | 第一轮相对 4,722 题 | 调换后相对 4,754 题 |
|---|---:|---:|
| 按误差方向提名，经确认后采用 | +7 | +15 |
| 按实际改对和改错提名，经确认后采用 | +9 | +14 |
| 固定让 MPNet 占三分之一 | **+55**，五折均正 | **+19**，三折正、两折负 |
| 相同固定比例使用 BGE | +8 | −9 |
| 相同固定比例使用 RoBERTa | +13 | +18 |
| 相同固定比例使用 MiniLM-L6 | −9 | −32 |

固定 MPNet 第一轮改对 191 题、改错 136 题，按标题组重抽样的差值区间为 **+0.30 至 +1.41 个百分点**。调换后改对 187 题、改错 168 题，区间为 **−0.26 至 +0.88 个百分点**。它是看过四个候选后辨认出的固定对照，有选择偏差。真正交由 Agent 提名、确认的两条路线，两轮区间均跨零。MPNet 值得保留在候选中。当前反馈仍不足以让 Agent 在冷启动时稳定发现这个机会。[第一次全部结果](../research/crossfit_challenger_1124/replay/result.json) · [轮换全部结果](../research/challenger_nomination_rotation_1124/result.json)

## 统一入口与费用

这条可选策略由人定义两个参考成员、四种候选表示、一份拟合预算和批准规则。Agent 在运行中读取明确的左右偏好任务契约、检查本机权重、根据训练反馈提名和拒绝候选。该实验使用已经在本机的固定公开权重。它检验了本地选择与交付；开放网络发现新架构、自动选择 GPU 及这些能力的任务间迁移仍需另测。

六份匿名工程包各换一次包名，并增加三次资源与目录变更。在首次拟合前，数值表、混合表、单文本、图像、对称文本分别进入通用调度，目录有 5、5、16、8、8 种方法；偏好文本进入六成员策略。数值任务保留 ROC AUC 和正类 0，两份三分类输入保留 macro-F1。缺少 BGE 时保留五种候选，缺少必要的 E5 权重时可进入通用调度。15 次检查未训练分类器。另有一份真正从头训练的匿名偏好小任务，162 行训练、18 行原始输入导出，两次独立预测逐字节一致。[路由检查](../research/crossfit_challenger_1124/dispatch.json) · [匿名完整运行](../research/crossfit_challenger_1124/smoke/smoke.json)

五折每折自主拟合 8 次分类头，含最后两个重训；为公平比较，各在决定封存后补拟合 1 次第三分类头。合计 40 次自主拟合、5 次对照拟合。匿名工程验收另计 8 次，共 **53 次本地分类器拟合**。五折另计 5 次残差提名、新旧选择器各 10 次连续权重拟合及旧选择器 10 次离散筛选；匿名小包另有 1 次提名、2 次权重拟合。两轮历史回放再做 20 次监督提名，复用已有分类头。五折累计自主训练 266.15 秒，五次脱离特征库的原始文本预测共 63.11 秒。模型 API 请求、计费 token、费用均为 0。上面的样本数、用量和耗时均限于本批研究。[每折原始耗时和计数](../research/crossfit_challenger_1124/result.json)

## 队友如何复核

同一版本、合规权重及 Python 3.11 测试环境下可以直接从匿名训练包运行。

```bash
python -m unified_agent train anonymous-train.zip --run-dir runs/new-task --strategy crossfit-challenger --weights /path/to/pretrained_weights
python -m unified_agent predict anonymous-features.zip --run-dir runs/new-task --output runs/new-task/predictions.csv --weights /path/to/pretrained_weights
python -m scripts.verify_crossfit_challenger verify "/path/to/Released_Task2-Headlines_CTR.zip"
```

复核命令会重建五个匿名训练包，核对行号、标题组、模型身份、每次拟合准入及预测，重新计算两套选择器、两轮历史回放和配对区间。加 `--weights /path/to/pretrained_weights` 可从原始文本重算提名向量并重跑 15 次路由检查；`--cache` 可指向已有的三种冻结特征。已逐项验收 138 项相关回归测试。复核程序按原训练的进程边界逐折清空输入向量缓存，使 MiniLM 的数值批次与实跑一致。[复算程序](../scripts/verify_crossfit_challenger.py) · [统一策略实现](../tools/challenger_training.py)

下一次优先检验**生成候选入围名单的依据**。在已有合规、同划分的折外预测时，用候选实际纠错和新增错误做初筛；没有这些证据时，在同一小块训练数据上给可用候选相同的试用机会，再只把最有希望的送去独立复核。入围要能随匿名数据改变，并记录试用成本。仍以真正交付的逐行预测作为晋级依据，按每路径最多 11 次拟合预算设计。[团队前一轮的验收优先级](AGENT_LIFECYCLE_AUDIT_20261124_zh.md)
