# BC1-05 · 用四个已冻结的真实模型验证评分

在标题偏好、数值表格两任务上选取预先登记的 Q 原目录及扩展目录共四个真实归档模型。先核对四个原始模型及其指纹，再用正式预测入口和已登记的无标签文件，在四个新进程中各重新导出一次。四份逐字节吻合归档预测后，使用 C1 的评分代码读取训练内留出，检查实际源行、标签、原始记录对应关系以及主指标。另通过正式命令行核实不完整 C1 在打开源标签前停止，缺少已有账本的训练在产生启动记录前停止。两个控制均无需真实密钥或账本。

这四个原模型共同使用 B 的已冻结数据。本验收新增拟合、付费请求和正式 C1 组均为零。复核已经公开过的开发成绩，保留任一不吻合结果。[Q 的原始回执](../../research/bq_01_portfolios/results.json)
