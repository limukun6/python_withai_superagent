# 本地自主配对实验

用户授权一次配对。现有本地动态 Agent 和启用新组件的 Agent 各最多 11 次实际监督拟合，含内部拟合和最终重训，合计最多 22 次。模型 API 上限为零。一条路径出现已开始的失败训练时保留记录，不再启动同一条路径。实验使用同一版本的正式命令入口，程序先锁定代码、输入和资源规则。

## 输入与两条路径

仅打开 Released Task2 的训练成员。沿用已有分组指纹，从 8,301 行中取 6,608 行做匿名训练包。其余 1,693 行共享标题组与训练完全分离，并作为两边统一评分的已见开发保留区。两个 Agent 都只收到训练包、二元文本偏好契约以及同样的下游预训练编码器。新实验不接收历史分类头、适配器、历史预测或外部验证标签。使用同一个种子 707、同一份 primary 分区，单路径 1,200 秒，每次训练至多 300 秒。两条路径依次执行。

对照沿用 `ab-v1`、完整共同目录与现有动态选型。实验路径在相同入口开启可选组件机制，仅在契约明确为二选一文本偏好、准确率、0/1 标签且本机具备已校验的六层和十二层 MiniLM 时使用；其他契约沿用原入口。实验同时改变候选和调度，衡量它们作为整体的效果。

## 新版怎样用反馈

1. 从零训练纯词法基线和六层 MiniLM 加词法的基础头。primary 留出按共享标题组固定拆为探索与复核两部分。搜索训练、复核输入、最终评分输入各自分开。
2. 若两个基础头在探索部分同时错至少 8 行且占比达到 5%，且可为重训留足预算，则尝试十二层 MiniLM 基础头，同时开放两头等权平均的免费组合。若此时所有已测基础头仍同时错至少 8 行、占比达到 5%，且预算允许，再训练两个分组交叉拟合的六层基础头和一个 rank-8 适配器。普通线性方案始终可选。
3. 新组件可用时，按已测组件开放全量适配、全量等权融合及仅对低把握行启用它们的候选。分派阈值来自探查行上去截距分数绝对值的第 25 百分位，仅用输入分数。用两部分合并的 primary 正确数选择已测候选。得分并列先选最终所需拟合数较少者；条件推理优先于同成本的全量推理；剩余同分按预先固定的目录顺序决定。
4. 最终仅对被选中的路线在 6,608 行上重新训练。单六层或十二层需一次，普通等权组合需两次，适配器需四次，带适配器的双编码组合需五次。拟合阶段记录每次真实分类器训练和适配器优化。编码提取是冻结的本地推理。新旧模型分别封存后再通过统一预测入口两次导出，逐行核对成功才评分。

主要结果为正确数、准确率、配对改对和改错，以及实际训练次数。按共享标题组给出差值区间。这是一轮开发对照，课程指定验证、正式测试和 H 都不在评分范围内。新方法优于本次原版即可报告观察到的提升；进入共同默认目录另需跨划分或跨任务证据。
