# 已执行模型上的限额选择实验

这次独立研究检验一个更窄的问题。在相同的、实际训练过的方法中，只能试三次时，让 Agent 看到前两次的真实表现，是否比只追求方法差异更有用？登记时匿名标题路径仍在运行，三个真实模型尚未统一封存。本实验只使用各模型在训练内初探划分上的既有逐行预测。课程指定验证、正式测试、746 对标题与 450 对电影外层评分均不参与。

标题合并本批两条路径在同一训练输入、同一初探划分、同一分类设置上真正执行过的方法。完全相同的配置重复时固定取参照组的第一份记录，列出重复预测差异。电影使用本批迁移路径实际试过的方法。配置数不足三的任务只报告不可判定。候选池本身由此前路径选出，结论只覆盖这些有观测的方法。

每个任务按共享文本连通组做四折。对初探划分中的每个组取 SHA-256(`b-varied-feedback-fold-v1/` 加组摘要) 对 4 的余数。在三个折上模拟反馈，用另一折评价最终选择，再轮换。所有备选分类器原本就没有用任何初探行拟合。选择器的冷启动统计只计算自这些分类器实际使用的训练行。两组都从空历史出发，预算相同，最多三次观察，且至少保留一个未试配置。

两边均由相同算法选择代表性首项。第一个策略依次看到已试方法的反馈行预测和准确率。第二个策略做后续探索时将所有已试分数固定为 0.5，将分歧设为零，只按方法距离探索。达到相同预算后，都在自身已试候选里选反馈行准确率最高者，平手按配置摘要决定。评价折答案仅在两个选择都封存后用于评分。报告逐折选择、跨折总正确数、改对和改错，区分反馈是否改变了所试方法和是否改变最终交付。此项采用历史模型回放，新增拟合和模型调用均为零。
