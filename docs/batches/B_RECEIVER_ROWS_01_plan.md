# 已交付模型会不会因为换了批次或排了顺序而改答案

使用两份已验收分支包的九个真实冻结模型。新包取匿名数值、优惠券、非线性标题、非线性短信、电影评论、字符组合短信；较早的十一分支包取自然花卉照片、Dry Bean 七分类和对称句对 MRPC。每份都使用接收验收时的模型指纹和原无标签查询。按固定种子 112208 选最多 97 个互不重复的行号，不按预测或标签选样本。重复首尾及若干中间行，将重复后的序列打乱，然后测试整批和 1／47／48／49 个交替分块的执行结果。固定期望是每个原始行的标签在这三种情况下与已验收 CSV 完全相同。对于原任务能力表声明支持概率的模型，检查类别次序及对应概率，允许最大绝对差 0.00002，完整记录偏差。

对声明为偏好关系的标题另外交换左右文本，检查正类概率互补（同样的容差，两边恰好平局时不强迫翻标签）；对声明为对称关系的 MRPC 检查交换后各类概率和标签均不变。数值、图像和单文本没有交换约束。通过接收分支自己的代码与独立进程运行，只读原模型、输入及已生成的标签预测。不得训练、调参、下载或查看真实目标。出现不一致按模型记录，不能放宽容差补报通过。
