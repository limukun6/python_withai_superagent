# 数值核候选进入统一入口后的自主选择

训练内初筛、两个按完整特征组划分的确认面板已经结束。核特征相对原逻辑回归分别净增 14、7、5 行。现在检验正式入口能否自主选择并交付最后的模型。选择规则和本机原 C1 动态组一致。

- 对照复用真实 C1 的 Bean L1 动态路径。逐项核对匿名训练包、默认可执行目录、707/808/909 的训练及评分行顺序、历史动作和旧结果。家庭名称仅用于核对结果。固定组 L0 只作为第一阶段方法对照。
- 新路径的唯一开关为 `--numeric-kernel`。该候选向有足够内存的纯数值表格提供带 512 个随机傅里叶特征的逻辑回归。其余方法继续可选。第一个候选、探索和复核规则、最终选型规则沿用现有调度器。保持 local、ab-v1、seed 707、实际拟合（含重训）上限 11、单次 300 秒、整条路径 1,200 秒、模型 API 0。
- 从空目录启动。先封存最终模型、实际拟合日志、动作和三份内部分区，分别核对训练、类别概率及预测行序；两个独立进程重新加载并导出 2,178 行匿名开发特征。对照也用同一份特征重新导出。全部预测先落盘，再用历史已评分的 A94 开发留出核对两边正确数、改对/改错和按完整特征组选样的配对 95% 区间。不按得分换种子、选模型或改算法。这份开发留出与校方 Task2 的 940 行及未见任务 H2 分开。
- 若新路径完成、两次导出完全一致、开发留出至少净增 8 行，则保留为下一轮可选候选。公开该路径的开发证据及逐组复算数据；最终课程版由双方另外固定。
