# 两种通用编码器和一种组合策略

本轮使用已经发布的原生十二层目录为对照。固定匿名训练包、种子 8123、三个共享标题分组、调度与选型规则。原对照在 1,693 行训练内保留区答对 1,224 行，已保存模型、逐题输出和全部训练回执。每条研究路径在这 33 项目录上增加一个候选，原有候选的配置及次序保持一致。每条上限 11 次实际监督拟合，含最后重训。最多两条新增路径，共 22 次，生成式模型 API 为零。

E5-small-v2 使用作者规定的双边 query 前缀、掩码平均池化与归一化；BGE-small-en-v1.5 使用未加检索指令的标题、首词元池化与归一化。两者均为英语通用特征提取器；分类头沿用相同词法、风格和逻辑回归配置。两种候选均按任务语义和已核验的本地资产进入目录。任务名称不参与路由。各重训一次即计一次，不直接复用另一种编码器的下游权重。[E5 发布者的使用说明](https://huggingface.co/intfloat/e5-small-v2) · [BGE 发布者的使用说明](https://huggingface.co/BAAI/bge-small-en-v1.5)

先对匿名训练输入中确定性抽取的 512 条不同标题做无标签探针。按标题内容哈希取样，检验参考实现、单位范数、交换方向、完备的资产清单与缺少资产时的目录。分别计算 BGE 对 E5 和普通十二层的前十近邻重合比例。两项均低于 0.80，才为 BGE 新开一条自主路径；E5 成功通过技术验收即可运行。此门槛只用于排除近乎重复的计算。比较近邻不读取任何标题输赢。

所有获准路径均由标准入口完成；各模型先冻结，统一用两次独立进程预测对齐行序后才评分。输出每次实测方法、是否自主选择新方法、同分区候选表现、保留区准确率、改对和改错、5,000 次共享标题组配对重采样区间、实际拟合与 API 用量。以既有普通十二层的原始预测为对照，同时报告旧研究方案 1,231 对的参照数字。仅当新编码器由 Agent 选为交付模型，并在保留区达到 1,235 对且优于原生对照时，核验一个原样模型在课程指定验证的成绩。两条都满足时，采用开发保留区正确数较多者，同分选 E5。正式测试与 H 不参与。

另检验一种结构性方案。对同一训练及评估分区内实际已训练的普通十二层和新编码器，逐行等权平均两者的类别概率。只做离线诊断，绝不为提供组合补训缺少的模型。组合若在至少两个匹配分区超过两个单模型，并且合并行次数比更好的单模型至少多 0.20 个百分点，则列入下一阶段拟议候选；各分区重复出现的行不视为独立总体。课程正式结果只取 Agent 自主封存并导出的模型。
