# 第二轮：把重复画像与有限情境作为推荐问题

首轮 OOF 画像均值在三个普通划分的平均变化约为 −0.39 个百分点。在整组新画像上从 70.65% 降到 63.45%。为了区别“均值特征不好用”和“重复结构没有价值”，改用两种直接学习画像与情境关系的算法。

* 基线仍是生产的字段交叉树。路线 T 保留该树，通过无标签发现的字段把画像、情境以及画像与单个情境字段的组合作为类别，交给 CatBoost 自身做有序类别统计。
* 路线 K 用核岭回归同时学习画像相似度、情境相似度及二者交互。对完全相同的画像或情境另加权。字段权重由拟合侧的类别与标签互信息决定。核、正则强度和 0.5 分类阈值固定。另报基线与 K 的固定等权分数融合，仅作误差互补诊断。
* 只读原包的两个 train 成员。用种子 18643 的五折按确切特征行分组，依次取前 3 个互不重合的评价折。其训练集互有重叠，此题此前已做过开发，不把这些行称为新数据。每折 3 次拟合，合计 9 次，API 0。预计 CPU 2–10 分钟。先保存折指纹和源代码指纹。每一法按折记录改对、改错和正确数。
* 晋级对象仅 T、K 两个单模型。相对于同折基线，平均提升至少 1 个百分点，且至少两折上升；两者均过线时取平均提升较大者。均未过线就不打开指定验证，保留生产基线。过线则再用新的统一入口批次验证可选、执行、重载和指定验证一次评分。三折均值与达到 80% 分开报告。
