# 调度器能否从内部反馈发现有用的组合

现有 Agent 比较单个方法时两次都选普通十二层。为检验它是否遗漏“单模型略逊、与领先模型配合却更好”的情况，在已完成的 E5、BGE 两条历史上做一次只看当时信息的调度回放。研发者已看过本批开发成绩，本项评估策略可执行性，不提供独立泛化估计。

回放取同一匿名训练任务的前四次实际探索。主分区先选准确率最高者为当前领先模型；对其它每个已测候选，在相同行上等权平均它与领先模型的类别概率。达到至少 0.2 个百分点改善才可用剩余额度申请成对复核；选择改善最大的搭档，同分保留原探索顺序。没有候选达到门槛就保留单模型。请求复核后才向策略提供第一次复核的已测结果；两个分区均超过各自两个单模型，且合并行次比更好的单模型至少高 0.2 个百分点，才选择组合。先为最终一或两个成员的重训留够拟合额度。输入只有候选 ID、行序、实测标签与概率、预算；数据集名称、编码器名称和外层成绩均不参与决策。

若选中的状态缺少同分区实测，登记为无法回放。BGE 的额外复核明确标记为后续实测反事实。冻结动作后，再检查是否已有对应整集模型和保留区预测。报告回放请求的拟合数、历史复用数与本轮新增真实拟合数。与原生产入口的真实自主结果分别标明。此次回放新增拟合和模型 API 请求均为 0。
