# 让 SuperAgent 在开跑时读题

第一版在正式 `solve` 入口增加了 `--task-analysis flash`。四道公开分类开发题各跑两次，共 1,252 个外部留出样本。DeepSeek 四次都引用了题面证据，复述了指定指标，并提出了可以查证的疑点。两组最终预测逐行相同。本次没有观察到提分，因此继续把开题分析作为可选能力。[逐题结果](../research/task_opening_1126/results.json)

## 一道新题怎么跑

1. Agent 读取任务说明、输入结构和训练数据，从第一份内部划分的拟合部分提取类别数量、分位数，以及最多三条只保留长度、数值尺度或图像统计量的样例。发送的题面可以保留“评论会换话题”这样的上下文。原始评论、图片和预测用的数据留在本地。
2. 第一轮训练开始前，Agent 可向校园 DeepSeek-V4.1-Flash 请求一次开题分析。大模型要说明预测目标、引用具体证据、提出一个能实际检查的猜想，并说明什么观察会推翻它。Agent 同时照常试模型，先保存一个能直接预测的完整模型。如果遇到需要模型协助识别的输入格式，格式识别和开题分析共用这一次请求。
3. 回复及时到达时，Agent 每做完一次原有实验就用已有的逐行预测更新判断。涉及分组或时间的题目可以核查划分。怀疑某类样本更难时，两份互不重叠的训练内部留出数据都须显示该组错误率至少高出 5 个百分点，每边至少有 5 个样本。
4. 若证据支持猜想，Agent 从已经试过的方法中找出能救回这些样本的候选，再核查另一份划分。替换完整模型需要候选在两份数据的题目指定指标上都领先，平均至少提高 0.3 个百分点。针对某组样本选出的候选还须在第二份数据上净救回该组样本。否则保留原模型。请求失败或猜想被证伪也能继续交付。

目前通用检查覆盖类别、评论长度、数值尺度和缺失情况、图像强度和对比度、实体或时间划分。大模型会自主选择检查，也可以放弃提议。可执行的检查类型由代码提供。每次的判断和实测结果会写入本题的经验记录。这四次各自从头开始，后续任务自动读取历史经验尚待验证。

## 同预算实测

两组均从相同训练包冷启动，最多 16 次真实拟合（含重训）、600 秒。原有调度可用最多 10 次拟合先交付，双方都可在剩余额度里验证一次额外候选。本地组使用原有选择规则，开题组可以根据经证实的疑点改变候选。固定了训练和评分规则之后才发请求，八份最终预测和对应的原模型预测全部封存后再开留出标签。各组实际原路线的训练动作、内部划分和原模型预测一致。[预登记](../research/task_opening_1126/protocol.json) · [开跑前补充](../research/task_opening_1126/intake_amendment.json) · [复核记录](../research/task_opening_1126/verification.json)

| 开发任务 | 训练／留出 | 评分指标 | 本地组 | 开题组 | 开题组核实了什么 |
|---|---:|---|---:|---:|---|
| 蛙鸣声学特征分类，整段录音留出 | 1,188／412 | 平衡准确率 | 84.81% | 84.81% | 三份内部划分，训练与验证间重叠录音均为 0 |
| 用评论识别推广内容，整条新视频留出 | 760／240 | 宏平均 F1 | 92.68% | 92.68% | 不超过 5 词的短评论，两份内部留出分别全对 46／46 和 44／44 |
| 手写数字识别 | 900／300 | 准确率 | 97.33% | 97.33% | 低对比度组的错误率相对其他样本分别为 −3.69 和 +3.22 个百分点 |
| 由无线信号强度预测房间 | 900／300 | 宏平均 F1 | 97.67% | 97.67% | 最少见类别的错误率相对其他样本分别为 −1.98 和 −2.99 个百分点 |

两个训练过程之间出现了可核查的区别。评论题的回复在第三轮训练时已经到达，Agent 连续记下 7 次更新，第五轮已有第二份划分的证据。其余三题在回复到达前就已交付完整原模型，最后仍核查了建议。四次均未改变额外实验的候选。录音题的本地候选在第一份内部划分提高 0.60 个百分点，在第二份降低 3.34 个百分点，两组均保留原模型。

评分结束后，仅用原模型在两份训练内部留出上的逐行预测，把当时所有可选的“哪组样本更难”检查重新算了一遍。四题共 14 项，没有一项在两份划分上都达到 5 个百分点。这也解释了为什么即便换一种提问顺序，本轮也很难触发新路线。评论题的说明提到话题变化，第一版能读到这句话，可实际执行的检查仍限于字数和类别。验证按主题或来源变化提出、执行检查，是比单纯增加调用次数更直接的下一步。[训练内复查](../research/task_opening_1126/training_inventory.json)

四项任务均取自公开真实数据，并封装成这次研究使用的输入格式。蛙鸣按录音隔离，去掉属、种和科等会泄露答案的字段。评论只给模型文本，新视频的评论专供外部评分。手写数字没有书写人编号，采用按类别抽样的外部留出，无线信号任务亦按类别抽样。结果只反映这些开发任务，课程 Task1、Task2 和封存任务均未参与。[蛙鸣数据](https://archive.ics.uci.edu/dataset/406/anuran+calls+mfccs) · [评论数据](https://archive.ics.uci.edu/dataset/380/youtube+spam+collection) · [手写数字](https://archive.ics.uci.edu/dataset/178/semeion+handwritten+digit) · [无线室内定位](https://archive.ics.uci.edu/dataset/422/wireless+indoor+localization)

## 费用与交付

配对实验共 78 次真实拟合，两组逐题均为 12、12、8、7 次。另有开跑前的本地演练 39 次、接口不可用的入口验收 8 次，均为零模型调用。正式四次调用共输入 2,804、输出 4,873 token。按更新后的空闲价，输入每百万 ¥1、输出每百万 ¥4，共 **¥0.022296**。单题最高 ¥0.009940，课程每项评估任务的模型用量上限为 ¥20。本次均有校园接口返回的用量，已在 B 侧账本结算，待与团队账本合并。学校账户实际扣款未提供。单次接口耗时 24.6 至 30.8 秒。两组共用机器且与其他检查并行，整次耗时不宜用作速度对比。[计费口径](deepseek_pricing.md) · [用量及每题耗时](../research/task_opening_1126/results.json)

在项目环境中，沿用团队已配置的校园密钥文件 `SUPERAGENT_PLANNER_KEY_FILE`、用量账本 `SUPERAGENT_PLANNER_LEDGER` 和同题累计编号 `SUPERAGENT_TASK_BUDGET_ID`，可从统一入口运行。以下路径仅作示例，`run-dir` 指向新的运行目录。

```sh
python -m unified_agent solve task.zip --task-analysis flash --fit-limit 16 --time-limit 600 \
  --run-dir runs/new-task --prediction-input features.zip --output deliveries/predictions.csv
```

使用 `--task-analysis local` 可在相同的训练与复核规则下做零 API 对照。运行目录下的 `agent/opening_brief.json` 可查看模型实际收到的题面，`task_opening.json` 记录建议、核查和换模决定，`opening_updates.json` 在有训练中更新时生成，`opening_lesson.json` 保存实测经验，`opening_incumbent.json` 指向随时可恢复的完整原模型。
