# 连续数值分类的两个候选与 Dry Bean 内部对照

C1 原目录对 Dry Bean 提供 3 个逻辑回归强度和 2 个极端随机树模型。本次在同一训练池检验两种不同的分类依据：某条记录在各类别的数值分布中有多常见，以及与它距离最近的训练记录属于哪些类别。已知原 C1 的开发留出成绩，筛选只使用原先登记的训练内划分。

- 候选一用中位数填补缺失值，每个特征仅用当前拟合折的最多 256 个经验分位点映射为正态边际，然后用类别协方差的二次判别分析，固定 0.10 的正则强度。候选二用同样的中位数填补并在拟合折做标准化，使用 11 个欧氏近邻、距离倒数投票。每次构建带标签的邻居索引计一次拟合。两种方法均输出原始类别顺序可核对的概率分布。
- 从原生 C1 固定组复用已选出的 `numeric_tabular_logistic_C1.0` 在 707、808、909 的真实模型。原始训练包模型拟合池为 8,710 行、16 列。先复现对照逐行预测和数据指纹；新候选每折只接收同一拟合分区中的特征与标签。
- 初筛只在 707 试两个挑战者。若较优者至少多答对 4 行，才在后两折各重新拟合该候选；初筛平局时优先二次判别。确认 808 只计 707 未评过的完整特征组，确认 909 只计 707、808 均未评过的完整特征组。两组均不退步且合计至少多答对 8 行才有资格另行验证外层。报告各类召回的变化和按完整记录组的配对区间。训练折仍使用原本分配到该折的全部拟合行。
- 最多 4 次本地分类器拟合，模型 API 0 次。既有 2,178 行开发留出和课程指定验证不在本次运行中。相同数据和同一真实标签空间下的匹配实验独立于已交付的 C1 六组。
