# B1-07 · 真实标题偏好的固定与动态预算

B1-05 的标题路径用了九次探索、零次复核。为检验这种预算分配的后果，本批在同一真实开发任务上预登记另两个外层种子 45102、45103。只读取课程训练 CSV，按共享标题连通分量分组。两个资源条件都可使用相同的已校验本地 MiniLM。内部种子为 707、808、909，使用同一机器、源码、可执行候选、候选顺序、起点、探索排序、最终晋级规则和模型出口。每条路径独立启动。

- F 沿用总计划：探索 4 个不同配置，在主划分按分数及候选 ID 排序取前三。两份预登记复核划分依次对这三位各执行一次。合规候选不足时取实际可用数量，少于两位就停止复核。一轮剩余复核不能全部容纳时保留重训额度并停止。
- S 沿用 B1-05 的动态规则，用已经返回的真实反馈决定是否复核或继续探索。预算上限两组相同，实际消耗允许不同。四条路径均最多 11 次监督训练含重训，合计最多 44 次，墙钟 1200 秒，每次训练最多 300 秒，新增 API 上限 0。失败保留，不自动重试。
- 第一划分先 F 后 S，第二划分先 S 后 F。与 B1-05 的已知分数单列。全批封存模型后才读取各自的外层标签。报告准确率、逐行新对与新错、预算去向与耗时，并记录跨划分外层交集。若两边交付完全相同则如实报告。

A 正式命令在本基线上只暴露动态调度。研究启动器在每个独立进程开始时显式选择 B 的调度策略，随后调用相同的 A 命令处理函数。两组都保留 A 的状态、动作检查、真实训练计数、反馈、停止、选型、重训和导出。策略记录另行保存。生产默认入口仍选用动态组。
