# B1-06 · 真实对称任务的候选方法对照

在看到 MRPC 模型分数之前登记本批。MRPC 开发数据取 GLUE 发布的固定训练分片 `a3f3ab759b9d7018046ce361f115ef38276d2e1e`，文件 SHA-256 为 `61fd41301e0e244b0420c4350a170c8e7cf64740335fc875a4af2d79af0df0af`，共 3,668 对新闻句子。标签表示两句话是否语义等价。这个语料用于开发，另行封存的 PAWS 继续保留到 H1。只读 MRPC 训练分片。[Microsoft 数据说明](https://www.microsoft.com/en-us/download/details.aspx?id=52398) · [GLUE 固定版本](https://huggingface.co/datasets/nyu-mll/glue/tree/a3f3ab759b9d7018046ce361f115ef38276d2e1e/mrpc)

在相同源码、目录顺序、调度、首个候选、分组与执行预算下比较两种本地资源条件。词法组提供 B1-05 的三个交换不变候选。扩展组额外开放一个本机校验过的通用 MiniLM 候选，结合字符/词法与对称的句向量特征。是否尝试、复核、选中它均由 Agent 决定。两组使用同一个正式 `superagent run` 入口。用可选方法带来的整条路径差异评估这项资源配置。

按共享原句连通分量，使用预先指定的两个外层种子 45101、45102，内部仍为 707、808、909。每个外层两组逐项核对任务包、源行序和实际划分指纹，其他可执行候选必须完全相同。第一划分先词法后扩展，第二划分顺序相反。每路径最多 11 次实际监督训练，含重训。每路径墙钟 1200 秒，每次训练最多 300 秒。四条路径合计最多 44 次，真实 API 上限 0。预先冻结完整协议，全程离线。未经人工选模的四个模型均封存后才评分。失败保留，不换种子。

主指标为训练集外层留出 accuracy，记录每个划分的正确数、逐行新增正确/新增错误、候选与重训数、耗时、两目录重载一致性及正反序概率最大差。两个划分来自同一语料，另报实际留出交集。检验真正的对称能力要求每一行、每一类概率都完全相等。可选编码器的性能收益允许为正、零或负。

运行方式为 `python -m scripts.run_b1_06_mrpc --training-parquet MRPC_TRAIN --weights LOCAL_MINILM --output NEW_DIR`。提交只包含方法、复跑步骤、摘要和实训记录，不分发新闻文本。
