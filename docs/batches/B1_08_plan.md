# B1-08 · 在数值表格、单文本和类别表格上核对预算调度

B1-07 完成四任务预算研究中的标题任务。本批预先登记另外三个任务和六个比较。依次运行 Dry Bean、SMS、Released Task1。每个任务从自己的原始训练数据划出外层 45102、45103。内部仍为 707、808、909，用共同分组器隔离相同输入。每份外层先按相同谱系生成训练包、行号、公共目录和依赖指纹，再启动真实入口。每任务独立落盘，任一路失败保留账本和原始状态。

冻结生产代码、完整扩展候选目录与 B1-07 调度规则，使用同一 CPU 和已核验本地 MiniLM。每任务均按 45102 固定、45102 动态、45103 动态、45103 固定的次序。固定组探索 4 项，对前三名各复核两次。动态组根据实际返回的逐行预测与主指标决定下一步。每路径最多 11 次监督训练，含最后重训，每路径 1200 秒、单次训练 300 秒。三任务总上限 132 次，加上标题计划上限 44 次，合计与 B1 的 176 次一致。新增 API 上限 0。

四个模型都冻结后统一评分。Dry Bean、Task1 使用准确率；SMS 使用 macro-F1，另列准确率和逐行新对/新错。每条路径记录从首轮到最终赢家的动作、晋级、实际训练、运行时间、两次跨进程预测字节核对。报告同任务两个外层的重叠行数。预先固定的六个比较全部报告，共享样本的划分不当作独立样本。课程验证集、正式测试和封存的迁移任务不参加。

每一任务先运行 `python -m scripts.run_b1_08_other_tasks --prepare-only`。训练时传入相应 `--reference`，首个训练动作前比对两个协议的源码、环境、任务、候选与实际行号。相同控制器、拟合守卫、停止/重训与预测沿用 A 正式命令，B 的独立启动进程只选择固定或动态分配。零训练预检和最终模型分别使用新目录。
