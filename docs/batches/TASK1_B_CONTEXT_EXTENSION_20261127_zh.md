## 同一方法多训练几次，有时比再换一个模型更有效

在原有 8,117 行训练内五折上，保留每折 Agent 已经选出的成员。有随机性的成员用两个额外种子在原来的全部数据上重训，冻结的表格模型沿用原预测。先在成员内部平均，再保持原来成员之间的权重。五折依次多答对 **5、4、7、7、3 道**，合计从 **6,159（75.88%）** 提到 **6,185（76.20%）**。一共改对 109 道、改错 83 道。按完全相同的特征行分组，净增 0.32 个百分点的 95% 配对区间为 0.00 至 0.64 点。

这组 6,185 是事先列入的“始终平均”对照。原来的严格规则要求三个内折都提供较强的准确率收益，五次都选择了保留原模型，实际仍答对 6,159 道。为衡量这两种行为，研究共增加 56 次分类器拟合。[历史回放规则](../../research/task1_feedback_extension_1127/full_training_seed_replication.json)

新的可选策略使用同一正式入口。Agent 按常规流程选模并保存可用模型，再从已经选中的成员里找出适合重训的模型。它只用训练侧的留出数据，检查换种子后有多少预测真的改变、题目要求的指标和概率误差有没有明显变坏，以及还剩多少时间和训练机会。符合条件才投入两次全量重训。可用 `--fit-limit 64 --feedback-reflection seed-replication` 启动这条路线。新划分上的被试程序固定在 `f214f8b`。[自主入口的确认规则](../../research/task1_feedback_extension_1127/seed_policy_qualification.json)

## 让历史选择对当前预测产生正向或负向修正

算法从训练数据中发现重复出现的属性组合，再学习哪些历史情境有参考价值，以及历史反应应当怎样改变当前判断。它估计某个情境的一般接受率时，先去掉该画像的全部记录。给一条训练样本构造历史时，也会排除与这条样本完全相同的记录。这里的画像由输入属性推断，原包没有提供可核实的个人身份。

在 808 行上，程序为较强的双模型选出一半份额的有符号修正，答对 616 道，原来是 609 道。随后两批分别从 620 提到 623，从 604 提到 606。保持公式和权重，移到五个常规 Agent 各自选出的模型，折外校准只复用它们已有的三份内部评分。五折一共 **6,173 / 8,117（76.05%）**，比常规版多 14 道。再给三种子版本加入同样的修正，答对 **6,190（76.26%）**，比它单独使用多 5 道，两组净差的 95% 区间均包含零。课程交付仍按该方法自己的晋级规则决定。[开发规则](../../research/task1_feedback_extension_1127/cross_context_transfer.json) · [五折规则](../../research/task1_feedback_extension_1127/cross_context_outer.json)

TabDPT 也已试过真正的逐行检索。编码器能从 4,061 条拟合数据中为每一条查询选最相近的 128 或 512 条参照。2,432 个查询分别耗时 83 和 228 秒。程序在提名题上选了 25% 的 512 邻居方案，后续两批分别少对 5 道和多对 4 道。原顺序的精确检索和 GPU 模型分开进程运行，修复了本机两个数值库同时加载时的停滞。[检索方案](../../research/task1_feedback_extension_1127/tabdpt_retrieval.json) · [运行记录](../../research/task1_feedback_extension_1127/tabdpt_retrieval_runtime.json)

## 用预训练表格模型做特征提取

早期表示的试验用 809 条训练数据作为固定的带标签参照。余下 3,252 条拟合数据与 2,432 条开发题都以查询身份交给冻结模型，提取同一层的 512 维行向量。交换同伴样本和顺序后，抽查的行向量最大逐维差约 0.000011。给同样的线性分类器加入这些向量，三批分别多答对 6、15、12 道。与强组合投票时，程序在 808 行上选中了占四分之一的增强树，随后两批均少答对 3 道。

晚期表示的试验改为读取最后分类层之前的 1,024 维向量。这时模型已经看过其他带标签的训练例子。四折轮换参照集，每个训练样本及其完整特征重复组都从为它生成向量的参照中排除。使用训练标签在 32 维子空间里调整分类头，开发提名选中八分之一的投票权。两个后续面板分别多答对 1 道和 2 道，合计约 +0.18 点，低于该项预登记的晋级门槛。两项实验均在课程训练集内部完成。[行向量规则](../../research/task1_feedback_extension_1127/frozen_row_embeddings.json) · [分类头适配规则](../../research/task1_feedback_extension_1127/adapt_foundation_readout.json) · [发布者模型架构](https://github.com/soda-inria/tabicl)

在每个成员仍然只额外训练两次的条件下，也试了让两次训练对不同样本分配互补权重。每条样本的总权重固定为二，所有样本都保留。五折共 14 次新的全量拟合，得到 **6,179 / 8,117**，比常规单种子多 20 道，比同成本的均匀样本权重三种子少 6 道。[同成本对照](../../research/task1_feedback_extension_1127/paired_training_weights.json)

## 把另外两折也跑完

## 接入与交付

```sh
python -m unified_agent solve TRAINING.zip --prediction-input FEATURES.zip --fit-limit 32 --run-dir RUN --output predictions.csv

```

## 把 Task2 的编码器和反馈方法移到表格

E5-small-v2 和 BGE-small-en-v1.5 复用了 Task2 的本机权重。两个编码器各搭配分类树和线性分类头，共训练 4 个候选。参照组合在 808 行提名阶段答对 609 道，BGE 树占四分之一时答对 614 道。随后两批各少答对 2 道。用题目文档里确认的字段名去匹配行内类别，是另一种使用 BGE 的方式。程序自行识别出 5 个互相对应的字段，调换列顺序后对应关系一致。换成无意义的编号表头时，程序放弃匹配。全局树和 5 个局部分类器的组合在两批分别少 1 道、多 1 道。[训练与确认记录](../../research/task1_feedback_extension_1127/method_transfer_results.json)
