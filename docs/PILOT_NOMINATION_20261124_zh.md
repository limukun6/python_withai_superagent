# 第三个模型该不该加入，先让 Agent 实际试一轮

上一版按参考模型的错误来猜谁能帮忙，五折都退回了原双模型。这一版让每个可用候选在同一批训练题上试用，再用两批不同的标题组提名、复核。同样的 6,608 道训练内留出题上，按改对数提名多答对 27 题，按概率改善的稳定性提名多答对 32 题。课程指定验证的最近实测仍是 Task1 **1,532/2,030（75.47%）**、Task2 **689/940（73.30%）**。[上一版逐折结果](CROSSFIT_CHALLENGER_20261124_zh.md) · [统一版指定验证](UNIFIED_AGENT_20261124_zh.md)

## 谁作了哪些决定

研发人员规定可用的模型实现、每条路径上限、提名方式和通过复核的条件。启动后，统一入口读取匿名任务契约并核对本机权重。针对两列文本、左侧为正类、以准确率计分的偏好任务，Agent 试用两个参考模型 MiniLM-L12 和 E5-small，以及当前可用的 MiniLM-L6、BGE-small、MPNet 和 RoBERTa。对于其他任务契约或不够独立的训练组，入口走原来的通用路径。这里实测的是**从已安装的候选里自主提名、复核、放弃或采用**。未加入自由下载或任意生成模型代码的能力。[候选准入](../scripts/unified_encoder_portfolio.py) · [决策实现](../tools/pilot_challenger.py)

每个外层折都把共享标题的行留在同一组。余下的组分三份。第一份拟合试用分类头；第二份上，Agent 比较每个挑战者等权加入两个参考模型后改对多少题、对正确答案的概率是否更准；第三份单独复核被提名者。最终选择确定后，在该折的全部训练行上重训两个或三个分类头。报告中的实际交付分数来自新进程，它只收到模型及无标签文本包。[首轮登记](batches/pilot_nomination_plan_20261124_zh.md) · [匿名验收与逐行凭证](../research/pilot_nomination_1124/)

## 第一套五折

| 实际交付 | 答对 / 6,608 | 准确率 | 比双模型改对 / 改错 | 五折分别净增 |
|---|---:|---:|---:|---|
| 同折重训的双模型 | 4,733 | 71.63% | 0 / 0 | 0，0，0，0，0 |
| 优先选净改对最多的候选 | 4,760 | 72.03% | 102 / 75 | 0，+8，+12，+7，0 |
| 优先选概率改善较稳定的候选 | 4,765 | 72.11% | 140 / 108 | 0，+8，+12，+7，+5 |

主检验预先选的是第一种提名方式。它在三折提分，另外两折持平，未达到至少四折提分的门槛。概率提名预先列为辅助对照，比双模型多对 32 题，按标题组配对重抽样的 95% 区间为 **+0.015 至 +0.971 个百分点**。两种提名器直接对比，后者改对 38 题、改错 33 题，区间为 **−0.165 至 +0.347 个百分点**。值得复验的是第三成员能带来的增益，现有差值不足以判定两种提名器的优劣。[汇总与分组区间](../research/pilot_nomination_1124/result.json)

两种策略在第一折都提名了 MPNet。它在复核区只多对两题，门槛为三题，所以 Agent 自己退回双模型。第五折两种提名器出现在最终交付上的唯一差异。按净改对数选出的 RoBERTa 在复核区少对三题。按概率改善选出的 MPNet 在复核区多对十五题，最终在外层多对五题。将首选强制加入、取消拒绝权的事后对照，五折分别多对 38 和 37 题。这些对照使用了实际 Agent 未批准的模型，不能用作它的交付成绩。[第五折两个决策](../research/pilot_nomination_1124/fold_4/)

另一个容易忽略的差别是训练量。两个参考模型只用试用区拟合时答对 4,585 题，整折重训后答对 4,733 题。固定每折被提名的第三个成员，其相对同期参考模型的净收益，按改对数提名从 +67 变为 +38，按概率提名从 +74 变为 +37。小样本上的优势会随重训缩小，最终验收应覆盖真正交付的模型。[试用头与重训头的逐行结果](../research/pilot_nomination_1124/result.json)

## 让首选没过关的 Agent 再试备选

这次把同一块复核数据按标题组平分。首选必须先在第一半得到正向反馈，才可进入第二半。开备选的一组可以在首选未获支持时，把事前已选定的第二名送进第二半。两组使用同一批准条件。[备选实验登记](batches/pilot_backup_plan_20261124_zh.md)

| 实际交付 | 答对 / 6,608 | 准确率 | 相对同折双模型净增 |
|---|---:|---:|---:|
| 两阶段复核，关闭备选 | 4,745 | 71.81% | +12 |
| 两阶段复核，允许备选 | 4,750 | 71.88% | +17 |

开关直接比较，允许备选改对 65 题也改错 60 题，净增 5 题，95% 组配对区间为 **−0.256 至 +0.419 个百分点**。第一折真的改用 BGE，评价净变化为零。第五折真的改用 MPNet，多对五题。第二折首选通过第一半，第二半只多对一题，未过门槛。两种分半路径都低于首次用完整复核区的 4,760 和 4,765 题。可单独归因于开关的是 4,750 与 4,745 之间的差值。该扩展复用了可核对身份的头，另拟合一个 BGE 分类头，十份新进程原始文本预测均已复核。[逐折选择、拟合账本和逐行对照](../research/pilot_backup_1124/result.json)

## 换一次分组并把分类头从零训练

在打开新外层评分前固定概率提名规则。重新分配同一批 4,874 个标题组，每折均从空分类头缓存启动，单独训练、单独导出两个参考成员和实际选择的模型。双模型 **4,740/6,608（71.73%）**，Agent **4,744/6,608（71.79%）**。Agent 改对 131 题、改错 127 题，净增 4 题。五折依次为 **+7、−7、−2、0、+6**，95% 组配对区间为 **−0.421 至 +0.505 个百分点**。此次主检验未通过晋级标准，依登记未启动外部回复偏好任务。两次划分共用同一批开发题，不能把分母加倍。[预先登记的方案](batches/pilot_brier_replication_plan_20261124_zh.md) · [全部冷启动证据](../research/pilot_brier_replication_1124/result.json)

五折都提名 MPNet，四折批准。第三折的训练复核多对 34 题，交付在外层少对 2 题。第四折复核多对 19 题，但提名区少对 2 题，Agent 按规则保留双模型。依原始行号对齐，两套划分都被第三个成员救回的只有 30 题，两次都被改错的有 19 题。实际交付标签在两套划分间有 621 处变化，双模型本身也有 593 处变化。瓶颈已经从能否找到 MPNet 转向训练反馈能否预告重训模型在下一批题上的收益。[同题配对与划分敏感性](../research/pilot_brier_replication_1124/partition_sensitivity.json)

## 哪些题该交给第三个模型

在已批准第三成员的路径上，允许 Agent 从训练反馈提名“一致”或“分歧”这类题继续由双模型单独回答，并在独立标题组复核。一共十条路径，八条曾批准第三模型，也都完成了这次离散选择。没有一条在提名区找到同时满足改对数和概率改善的类别，十份最终逐行预测与原交付完全一致。这里的逐题实验复用已训练分类头；八次决策另行计数。[事前方案](batches/pilot_consensus_veto_plan_20261124_zh.md) · [逐行数据与两套结果](../research/pilot_consensus_veto_1124/result.json)

| 两个参考模型的意见 | 第一套五折，第三成员改对 / 改错 | 第二套五折，第三成员改对 / 改错 |
|---|---:|---:|
| 一致 | 45 / 26，净增 19 | 36 / 30，净增 6 |
| 分歧 | 95 / 82，净增 13 | 95 / 97，净减 2 |

因此，把两模型一致的题全部锁死会损失实际能救回的题。光看两模型是否分歧，也不足以判断下一次交给第三个成员是否划算。

## 多给两个参考模型一些训练题，再决定是否接纳第三成员

还有一种解释是，试用阶段的老模型没有充分训练，第三个模型容易显得有用。在两套实验已批准 MPNet 的八条路径上，把两个参考分类头的训练量从单独的试用区扩大到试用区加提名区，保留原复核区。八条路径上的参考模型确实都在复核区答对了更多题，每条多 **10 至 33 题**。再把完全相同的第三个模型与新参考比较，八条仍全部通过原门槛。比如重新分组的第三折，复核多对的题数从 +34 降到 +14，仍然通过；该折外层已知少对 2 题。两套划分的最终预测都逐行没变。这次额外拟合的 16 个分类头有可核对的训练组和账本，尚无理由给默认策略增加这两次拟合。[事前条件](batches/reference_scale_plan_20261124_zh.md) · [两组逐折对照](../research/reference_scale_1124/result.json)

## 近似标题是否让成绩显得更好

课程训练 CSV 没有文章编号。原来的共享标题分组只能保证完全匹配的规范化标题不跨折。事先固定近似匹配条件后，11,505 个不同原文标题中发现 166 对跨原组的近似标题，连接了 140 对原组；连通合并后剩 4,737 组。第一套五折有 266 行的至少一个标题与当折训练侧直接近似，第二套有 249 行。只看扩大后的整组均留在外层的行，第一套净增 **31/6,303**，第二套净增 **11/6,320**。近似样本不能单独解释 +32 与 +4 之间的差距。这个标准衡量措辞相似，无法单凭它识别文章身份。[定义及审查方案](batches/pilot_title_overlap_plan_20261124_zh.md) · [逐行分组与结果](../research/pilot_title_overlap_1124/result.json)

后续本地 benchmark 已接入 `--search-grouping near_text --confirmation-grouping near_text`。生产划分器逐行复现独立审查器得到的 4,737 个组。五个预定随机种子的训练与评价之间均有零个近似连通组重叠。在 240 行匿名构造任务上，普通 benchmark 完成了搜索和三次分组评价，首次数值复用，三个真实分类器拟合均从子进程计数。这是独立的分组工程验收。[划分规则与验收设计](batches/near_text_grouping_plan_20261124_zh.md) · [真实入口与五次分组记录](../research/near_text_grouping_1124/)

## 本地拟合与调用

首轮五折新增 26 次实际下游分类器拟合，其中 2 次用于决策封存后的强制对照；首轮匿名验收另有 8 次。备选实验新增 1 次，重新分组的五条全冷路径分别为 9、9、9、8、9 次，合计 44 次。以上共 79 次实际拟合，单条独立 Agent 路径从零启动最多 9 次。新冷启动只共用固定编码器的输入表示。严格分组的匿名 benchmark 另做 3 次，扩大参考训练量的实验做了 16 次，共 **98 次实际拟合**。后者每条完整路径从零启动最多 11 次。逐题决策、相似度审查、五次开发划分和额外匿名复核均未新增分类器拟合。模型 API **0 次、0 个计费 token、¥0**。

第三个模型也有本地推理耗时。在重新分组、实际采用 MPNet 的四折中，每折 1,293 至 1,338 行，双模型新进程从原始文本预测的中位耗时约 **12.5 秒**，三模型约 **29.4 秒**。这些是这台机器整批导出的墙钟观测，包含进程启动和权重加载。[逐折训练与原始导出的秒数](../research/pilot_brier_replication_1124/result.json)

## 少数类任务的入口修复

原入口会检查旧提名方法使用过的一小块数据是否同时有两个类别。这一版的 Agent 已经把该小块并入更大的反馈区，旧检查会误拒可运行任务。用 1,800 个构造任务检查后，按实际三区条件可运行的有 1,313 个。旧版误拒 304 个，修复后误拒 0 个，额外误放 0 个。两次真实入口路由从回退改为走试用策略，五个课程开发折的行指纹全部一致。这些是可用性结果，没有分类准确率含义。[修复前后记录](../research/pilot_eligibility_1124/)
