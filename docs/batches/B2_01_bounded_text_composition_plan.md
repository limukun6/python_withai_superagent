# B2 条件实验，分清扩大方法目录与按反馈组合方法的作用

B1 对已试方法的行级分析发现，对两份标题内层数据分别有 167 和 184 个错误，所有已测方法都答错。普通投票又曾推翻更多本来正确的标题。B 的首次参数选择试验在两份标题与两份优惠券留出均未改变最终预测。根据共同计划第 5 节，现有证据足以做一次有上限的组合实验。

在同一 A31/B 接入版本、同一训练器及已核验的本地权重上，各跑单篇 SMS 和有方向的标题偏好任务（标题固定选已有 45102，本轮只用这一份）。两任务均使用事先登记的训练内留出与 707/808/909 三个优化分区。三组分别使用原目录和原调度、扩展目录和原调度、相同扩展目录和按反馈组合的本地调度。每条路径最多 11 次实际监督拟合，含重训，1,200 秒总时限、单次上限 300 秒。六条共至多 66 次真实拟合，零模型 API。标题三组按原目录、扩展、反馈顺序，短信顺序反过来。六份模型全部冻结后才评外层成绩，交付物各做两次独立进程预测。

组合空间直接使用项目已有的文本 recipe 工厂和参数校验。每项都使用一个逻辑回归分类器，词或字符分析器、仅潜在语义或词法加潜在语义、C 为 0.3 或 1.0，共八个不同配置，SVD 最多 64 维。同一组合法组合从开始就在两个扩展组的可信目录内。单篇和偏好文本各自按输入契约生成，偏好保持两侧差值与翻转标签的含义。对称或一般关系任务沿用原目录。原基准、原强方法都保留，候选每次实际训练照常占用名额。

反馈组只在原调度准备探索一个 recipe 且至少有两份经过行级证据验证的 primary 观测时介入。用已实测的单一词／字符方法的主分选择分析器：都试过选分高的，只试过一个则提议另一个，都未试则先词。若最佳模型的训练主分减搜索主分超过 0.15，提议只用潜在语义，否则提议保留词法的混合表征。C 在允许的两档中取与最佳已测配置标称值对数距离最近的一档，缺省为 0.3。按这些值现场调用已有工厂验证组合。目标已试过或不可负担时，在同一可行列表内优先保留分析器、再保留表征、再保留 C。同分沿用共同目录次序。原调度仍独立负责是否探索、复核谁、何时停止与最终重训。每条提议都记录依据的真实试验与预算，下游得分不回流到规则。

分别报告扩展减原目录、反馈减同扩展目录两个差值，以及实际尝试、被挡回的提议、行级得失、拟合数和交付。SMS 主指标为 macro-F1，标题为准确率。尝试效果差和未被选中都保留。这个实验检验受约束的文本组合能力，课程正式验证、测试及 H 均未参与。
