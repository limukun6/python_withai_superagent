# BV-02 · 视觉模型搬迁后可复现 200 条预测

新目录中的视觉模型使用复制的官方权重，200 行预测文件与 BV-01 冻结时逐字节一致。删除权重路径或更改权重文件的一个字节时，新进程均在导出预测前返回明确的资源错误。原像素 SVM 在没有视觉权重的环境中同样复现其全部 200 行预测。四种情形均验证了冻结时采用的真实训练输入与候选目录。

对图像输入还收紧了资格检查，缺少或格式不完整的解码说明会使视觉编码器不进入候选目录，其余图像路线仍可使用。两条已经跑过的照片路径，在这次修订后的合法候选及排列均与实验时完全相同。修订后全套 416 项回归测试通过。此批没有新增训练、成绩或模型 API 请求。
