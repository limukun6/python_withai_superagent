# SA2：公告驱动提交契约与实际预测导出

基线SA1 40be241。先落计划，再实现和运行。用LLM提案中的OutputRecipe描述CSV编码/分隔符/表头、原ID或声明顺序编号、标签映射、指定类别概率；支持按样例提交的ID顺序重排。程序只搬运模型预测和真实输入ID，不让LLM填预测值。旧默认导出不变。

接入：semantic-task-v2可携带output与引用，v1仍兼容；编译时校验输出schema与训练类域，冻结进task.spec。predict在正式模型/已验证trial上导出并重新读回校验，partial prior沿同一输出recipe且保留partial身份。准确率任务若提交概率，候选需具备概率接口；不修改评分目标或B排序，只按输出能力做准入过滤并记录。

验收：非默认中文/英文列名、非ASCII编码BOM、前导零和乱序ID、样例模板重排、字符串标签映射、非默认正类概率、类别概率列序、重复/缺失/未知ID、概率缺失或非法、坏模板、输出被篡改、无output时旧默认不变。用无fit的确定性模型夹具走真实create_predictions及独立CLI predict，不假称真实训练或真实LLM理解成功。

本批输出范围CSV（含分隔符/编码/无表头），不支持任意代码或所有输出容器；非record输入的原ID提取、正常native快路的主动LLM解释及工具循环留后续批次，不能把SA2包装成全任务完成。
