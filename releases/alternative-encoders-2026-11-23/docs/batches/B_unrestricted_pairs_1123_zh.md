# 不强制包含领跑单模型的六个组合

此前三个开局都从四个候选中选首轮第一，再考察与第一名形成的三个组合。现在对同一四个真实候选枚举六个无序二元组合，使用已冻结模型，最多重算推理且不新增训练。三个开局为种子 8123 的 E5、BGE 菜单和种子 18643 的 E5 菜单。研发者已见三者原先的候选排名和开发成绩。

初筛候选必须比四个单模型中的最强者至少高 0.2 个百分点。若多个组合答对数相同，以较弱成员自身的正确数、再以较强成员自身的正确数打破并列，最后才用固定的探索顺序。若最优组合不含领跑者，要求同一次复核中已有两个成员以及领跑单模型的实际观测。缺失则登记候选与缺口；本批不补训。如果数据齐全，两分区的组合均须超过各自领跑单模型及两成员中的最高成绩，合计增益至少 0.2 个百分点。首轮决定和证据来源冻结后才对应已有保留区预测；遇缺少整集组合工件仅报告内部分区结果。分别报告扩大搜索范围和改变并列规则的作用。
