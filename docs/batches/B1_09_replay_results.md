# B1-09 · 观察结果是否真的改变下一步

重放四个任务的十六次完整路径。170 个已经执行的动作，包括停止，均在原始状态上逐字段重现。随后对每个任务的两次动态路径做一次双向检验。先对齐从开局开始完全相同的动作，在第一次分歧处固定任务契约、待选菜单、剩余训练名额和各自当时的时钟，交换来自两个真实划分的成套历史与已核验的训练内逐行预测。各自的行、标签和分组始终随对应的观测一起使用。
