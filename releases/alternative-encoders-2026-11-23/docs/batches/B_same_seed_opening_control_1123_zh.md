# 同种子四次探索对照

使用种子 40531、相同训练包、联合候选、同一 10 次拟合上限。原调度的前四项探索与新调度共用完全相同的实现。先从标准入口保存的第四个结果重放原调度每一条后续动作，将新调度产生的第五次探索完全遮蔽。被要求确认的原有检查点必须能对应相同候选参数、数据指纹、行号和真实逐行概率。缺少的确认分开补测，最多 2 次拟合，并保留物理记录。冻结原调度决策后，复用同一完整训练包已训练、配置相同的完整模型；如果无法核实权重来源，记录具体缺口。

核对重放所得四次探索、后续确认和完整重训所对应的拟合数，同本批真正新增拟合数分别记录。用相同导出入口与标签顺序比较两组，计算按标题组的配对区间。该控制属于旧调度的真实检查点回放；新调度属于从零运行的正式入口。课程指定验证、正式测试和模型 API 均不在对照范围内。
