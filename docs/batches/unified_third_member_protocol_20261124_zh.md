# 两个编码器都答错时，已有的第三种表示能否补位

起点为原始包共同入口已冻结的两个成员。在其 1,693 行训练留出里，319 行两个成员都答错。已知这项汇总，继续使用该留出做研发对照。正式测试与指定验证均不参与本实验。

从原生运行已完成的 primary 划分枚举除已交付二者之外的全部候选。只用同一划分的训练外概率，比较三成员等权平均相对双成员的正确数增量。选增量最大者，同分时依次比较它单独答对的双成员共同错题数及较早的试验序号。有相同独立确认记录则额外计算确认增量。先冻结候选、重新计算所需的已训练文件指纹，再预测训练内留出。

验收做两个配对对照。第一组的三个成员全部采用在相同 primary 训练行上拟合的旧权重。第二组采用已交付的完整双模型加现有第三模型，用于衡量直接接入的实际影响。记录第三模型单独能解决的共同错误，以及等权融合实际改对、改错的题数。按共享标题组重抽样 2,000 次，种子 28113。申请一轮完整重训需要 primary、独立确认各有正增量，同时两个留出对照均净增至少五题且配对区间下界大于零。未通过时保留交付模型。本批新增拟合与模型 API 上限均为零。
