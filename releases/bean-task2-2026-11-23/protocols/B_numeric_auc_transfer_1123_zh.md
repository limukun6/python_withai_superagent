# 新核候选在另一份真实数值表格上的选择

用本机 scikit-learn 自带的 Wisconsin Diagnostic Breast Cancer 分类数据做公开开发对照。这份数据有 569 行、30 个数值特征、两个类别；课程未见任务沿原登记封存。这次把任务指标设为 ROC AUC，检查 Agent 能否在不同类别数、样本规模和评分方式下选择方法并正确交付类别概率。

- 同特征行分组，以原分组分层器和种子 11323 划一次开发留出。两条路径使用同一份匿名训练包、同种子 707、同动态调度、模型 API 0、每路径最多 11 次真实拟合（含重训），单次 300 秒、每路径 1,200 秒。先跑默认目录，再跑只增加 `--numeric-kernel` 的目录。每条路径根据自己的训练反馈决定是否探索、复核、采用候选。
- 两个全量重训模型先封存。每个模型由两个独立进程导出带类别列的概率；核对每行概率归一化及列顺序，然后一次性比较留出集 AUC、准确率、正确数与两两排序差。以数据集原始类别 1 为正类。区间对正、负类分别抽取整行，使用同一批重抽样比较两种预测。此单次开发对照不承担课程 H2 迁移评价，也不单独触发默认策略变更。
