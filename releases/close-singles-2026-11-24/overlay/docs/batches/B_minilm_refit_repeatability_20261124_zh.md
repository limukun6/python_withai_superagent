# 固定特征后检查六层 MiniLM 分类头能否复现

两条从头运行的动作和七次实验逐行概率完全一致。互换已冻结的逻辑回归分类头后，两处交付预测差异都跟随六层 MiniLM 的分类头。仅测重训稳定性，沿用原 7,364 行训练子包与 937 行无标签特征包。留出答案不进入本试验。

两个独立进程用相同的词表、缩放、预训练权重和分类器参数分别生成训练矩阵。每个进程在自己的同一份矩阵上拟合两次，一次使用原求解容差 0.0001，一次使用 0.000001。其他参数、数据顺序和线程设置相同。校验训练矩阵摘要、迭代次数、系数差异和两次独立重训后输出的概率与类别。每种容差用相同 E5 对照组成原等权投票。每一处比较都以拟合前确定的参数执行。

保留每个进程两次拟合的计数，合计最多四次，模型 API 为零。两次同设置能否复现、收紧容差能否减少差异、以及精度更高的分类头是否提高任务准确率是三个不同问题。这回只验证前两项。若同设置已经一致，把结果记录为在受控条件下复现，以前两题差异的更底层原因继续保留为未确证。无论输出如何，本次都不修改公共默认值。
