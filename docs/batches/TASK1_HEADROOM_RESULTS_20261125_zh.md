## 5 能说什么、不能说什么

**能说**
1. 在三个训练内划分上，交互路线 3/3 为正，均值 +0.514pp，满足预登记的晋级条件。
2. 更强正则的路线无效（1/3 为正，均值 −0.08pp），**换容量不是方向**。
3. 21%–23% 的评价行是三个候选的共同错题，这是当前方法族的结构性上限。

**不能说**
1. **不能说 Task1 一定提分**：+0.514pp 只是训练内开发差，且刚好过线；指定验证未评分，外层收益未知。
2. **不能说是 Agent 选的**：本轮是三个候选的**固定对照**，不是 Agent 自主选型的结果（那是第三批）。
3. **不能说三个划分独立**：它们共用同一批行，只是分组种子不同，方向一致不代表可重复性。
4. **不能把 0.755 当交付成绩**：这是内部评价集，不是 2,030 行的指定验证。
