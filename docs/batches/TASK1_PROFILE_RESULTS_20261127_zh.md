# Task1 画像与情境研究的阶段结果

2026-11-27。本分支从 f0f3593 出发，用户明确要求重新探索 TaskA/Task1，目标为 80% 准确率。当前可复核的统一入口结果是 **1549/2030，76.31%**。此前历史自主入口为 1533/2030，净增 16 题、0.79 个百分点；达到 80% 需要 1624 题，还差 75 题。历史对比涉及不同提交和选模路径，方法配对证据另见下表。

## 瓶颈和对应结构

21 列类别特征中，模型从拟合侧列值自动找到 12 列反复共同出现的属性组合。完整训练集有 567 种组合、173 种情境。算法不使用列名、任务名或这些列的位置作路由。相同属性组合可能对应不同人，只能称重复画像。

原来的少量字段交叉会拆散这些重复关系。新增候选把完整画像、完整情境，以及画像与单个情境列的组合变为类别 token，由 CatBoost 自身的类别统计与树学习预测。候选只有在主训练折内检出重复结构、二分类、资源和任务限制允许时开放。原调度器继续比较全部合法候选、读内部反馈、复核和选模。模型没有预先指定为赢家。

## Agent 实际做了什么

统一入口在主训练折发现该结构。先探索深度 8 的原始类别树，然后试新增情境候选，并试运行时生成的梯度树、旧字段交叉、浅树和逻辑回归。对情境候选做两次新训练划分复核后，最终重训该候选。物理观察器的 10 次分类器调用与入口账目相同。训练只打开原包 C_train、y_train、Readme，指定验证只有特征提供给预测入口。模型和 2030 行预测全部封存、另起进程得到相同文件后，才单次读取 y_val 评分。

## 证据边界

本轮沿用已开发过的训练数据。本轮种子 707 的实际留出是 1621 行，和旧版本历史 1622 行不同，各批保留真实索引指纹。不能把两版内部得分直接作同划分配对。第二轮同一五折的评价行互不重合，拟合行互有重叠。

指定验证已经在项目历史中反复评分，本次 76.31% 仍属于开发验证。正式 test 在本轮封存，最终准确率待冻结后评价。新方法只在这一份真实类别表格题上证实，跨任务迁移和新画像收益待验证。画像均值在冷启动明显退化，神经模型与核模型的负结果支持限制它们的晋级范围。

课程允许自由选择分类算法，同时要求统一 Agent 自主决策、限制语言模型及记录费用，并将指定 test 用于最终评价。80% 是研发目标，当前实测尚未达到。
