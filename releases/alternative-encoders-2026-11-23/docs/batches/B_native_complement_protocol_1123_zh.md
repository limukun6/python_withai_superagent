# 新划分上的自主组合选择

既有同一训练内保留区的最高组合为十二层 MiniLM 与 E5 等权平均，1,234/1,693。旧菜单里两条标准路径都选十二层单模型。为验证组合能否由统一入口在反馈驱动下自行产生，冻结一条新的本地路径，最多 8 次实际拟合（含最终重训），模型 API 0 次。已有研究共 23 次新增拟合，此批独立登记。

仍用同一匿名训练包（6,608 行），提供与前轮 E5 相同的 34 项公共候选，明确该菜单由开发者选择。改用尚未在该实验使用的内部分区种子 18643。候选、搭档及最终部署形式不得由名称、任务身份、过往保留区成绩决定。新策略依原调度探索四项，预留两次重训。初筛领先者逐一与其他已测候选等权平均，优于领先者至少 0.2 个百分点才请求成对复核。以完整同一分区的概率及逐行结果决定是否晋级。两个分区均胜过各自较好的单模型且合并行次增益至少 0.2 个百分点时才交付组合；否则保留初筛领先者。最终全量重训选中的一或两个成员。所有试验、复核、预算与导出由标准入口执行。

组合仅在具备足够预算、有方向的二元文本偏好、准确率、可核验概率且有至少四个可执行的单次拟合候选时启用。其它合同继续使用原动态调度。偏好概率按同一种规范次序计算，再还原左右位置。每条概率须核对候选、真实标签、行序、分区、类别列和内容摘要。此为针对候选择优机制的前瞻新种子实验，1,693 行开发保留区已多次使用；完整结果无论好坏均报告。本批不进行课程指定验证、正式测试或 H。冻结最终产物后重复导出，核验原个人分支完整重训对照及预算。
