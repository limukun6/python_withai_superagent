# 从内部反馈学习两个预测的权重

沿用上一次临界停止研究封存的两个模型。问题是弱模型在部分题上有帮助，但是否该给它一半表决权。只允许拟合一个介于 0 和 1 之间的数，表示给既有单模型的权重。其余权重给之前已经选出的搭档。算法不接收任务名、标题词表、课程验证或正式测试。

两组固定训练内题目为 A、B。先在 A 学权重，在 B 评分，再在 B 学权重，在 A 评分。基础模型都在另 4,971 对上拟合，A、B、基础训练区之间均没有共同标题组。权重通过最小化真实标签的对数损失得到，每个标题组等权，加 0.005 乘以权重偏离 0.5 的平方。按已有规范做反向一致的概率与平局处理。

主要对照是两条原路线，即实际交付的单模型和原有等权投票。分别报告准确率与对数损失。只有在两个对面板都至少追平其中较高正确数，且合计比逐面板较高正确数至少多 8 题，才开下一轮独立确认。两次检验共用已见开发池，互换不能当作两个独立任务。预算为 2 次使用标签的标量拟合、基础分类器新增拟合 0 次、模型 API 0 次。保留正负结果。
