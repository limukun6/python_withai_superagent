# 在另外两组标题上复核单编码器排序

目前首轮 1,693 道题 MiniLM-L12 比 E5 多答对 23 道；另两组共 1,637 道题反而 E5 多答对 18 道。直接比较原配置的这两个单模型，检验第二种排序能否跨分区重复。

只用 8,301 对匿名训练数据。之前三块评估区的所有连通标题组均没有资格进入本轮评分。对剩下的组用盐 `b-fresh-singles-20261124-v1/` 与组键做 SHA-256，对 8 取余，余数 0、1 分别是两个新评估区。课程训练池中其余的行共同用于从头拟合两个模型，各一次。每个标题组完整落在同一区。两组模型均在打分前封存，评分只看单模型；不试融合、不改超参数。

E5 只有在两个新评估区都多答对题，合计净增至少 0.5 个百分点，且按连通组配对重抽样 5,000 次的 95% 区间下端大于 0，才有依据把它送入新调度策略的验证。无论结果高低都报告改对改错数量与区间。预算为两个实际分类器拟合，零模型 API。评估区相对本轮前述三块互斥，仍属于反复使用过的课程开发训练池。课程验证和正式测试均不读取。
