# BC1-04 · 对照将发给规划模型的事实

比较付费反馈之前，先确认 B 公共目录写的分类器与实际交付的分类器一致。在已登记的四任务、两分区、固定与动态共 16 条路径上，重放 A12 的本地动作，打开内部搜索及复核的 154 个实际模型，读取拟合对象的类与算法族，与对应能力记录及 worker 历史对照。无法识别、明确冲突、完全一致分别计数。真正的未知或冲突照实报告。

在本版另外三条真实本地路径（BA12 的 MRPC，BV-03 的两条手写数字路径）上，复用每步原始选项、预算、历史及划分。在不改变已有选择和观测的情况下，模拟前三个非首轮探索的调用位置，用 A12 自身的上下文生成器构造 raw 和 checked 两份输入。核对共同字段、候选及顺序，逐条检验分数核验是否有证据，记录实际序列化的输入字节。字节不换算成 token 或费用。动作、检查字段与模型真实决策效果分别报告。

此批只用训练内证据。新增拟合、外层成绩访问、HTTP 及模型 API 均为零。不会凭离线构造的提示推断 Flash 能提高成绩。先登记程序与协议，再读取真实模型和比较快照。
