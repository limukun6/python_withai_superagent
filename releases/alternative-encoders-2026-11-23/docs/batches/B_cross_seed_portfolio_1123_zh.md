# 换一批标题，调度选择能否复现

旧回放显示，换一组标题后，得分最高的单模型会变，最常被选中的原搭档也只出现在约三至四成重复抽样中。两个旧种子 8123 和 18643 已经各自实训过相同的四种候选，开局完整，先复用这八个现有检查点。

每次只用一个种子的开局划分及其预测做选择。在同一开局上按共享标题组有放回抽取 5,000 次，每次用原规则选单模型或两模型组合。每次给入选方案一票，两个成员各分半票。保留总票最多的三个成员，按所得票数归一化加权，票数相同按原目录试验顺序。对照为在整份开局按原规则选出的单模型或等权组合，另列固定十二层的表现。本实验只评价开局决策，各调度器的后续确认步骤在真实运行时仍需另测。

先冻结两个方向的选择、权重和预测，再统一评分。测试一侧使用该侧原训练折拟合的检查点，去掉所有与决策一侧评估标题组重叠的行。两个方向最后计分的组互不重叠。每个方向列原规则、固定十二层和新规则的改对改错，并给出分组重抽样的配对区间。两个方向相对原规则均净增，且合并至少高 0.2 个百分点，才具备开展新种子真实调度对照的理由。不按结果重新调票数、模型数或门槛。

跨种子回放中，接收侧某些评分行曾用于决策侧检查点的训练。另设一项隔离更严格的检查。各取两个开局互不重叠的那部分标题组，分别用组编号和固定盐值的 SHA256 排序，奇偶交替分为两半。在同一个原训练检查点上，先用甲半评估来选择，在乙半打分，然后反向再做一次。甲乙两半都没有进入该检查点的训练，全部评分组各算一次。两种回放分别汇报；只有它们各自在两个种子方向都净增、合并都达到约定门槛，才晋级。

此前两个划分的总体表现已知，这是一项训练集内的跨划分回放。只读取匿名训练包、内折检查点和预测，新增拟合 0 次，模型 API 0 次。
