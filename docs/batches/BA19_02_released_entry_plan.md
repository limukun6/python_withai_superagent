# A19 两个 Released 入口及 B 的共同任务预算核对

只用课程原包的训练成员和任务说明，与 A 已归档的预检、B 已登记的训练内输入逐项核对。以 A 的训练成员清单建立只含训练数据与 README 的副本。核对原包哈希、声明来源、训练样本、候选次序及共同指标，并实际用正式本地入口尝试开始原包的两条命令。测试护栏在第一次试图打开任何非训练成员时按文件名中止，先于读取内容和启动 worker。用相同护栏检查只含训练的副本，验证可顺利到达正式分区阶段，在训练前返回。这样可以区分预检读取的数据与真正启动时读取的数据。记录 A 和 B 的时间、数据和目录差异。固定本地权重开启与隐藏两种条件，只比较候选资格，不拟合模型。

A19 已共同登记标题预算标识 task2、大豆标识 dry_bean。让 B 的十二组准备和运行都明确冻结这两个标识和 full 目录；验收错误或互换的标识能在读账本前被拒绝。在旧版已封存回执上保持原来的校验入口。重新生成准备清单，所有检查 0 次监督拟合、0 次模型调用、0 次评分。作为整合检查，不计入正式 C1。
