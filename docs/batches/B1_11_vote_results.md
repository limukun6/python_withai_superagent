# B1-11 · 三个模型投票的实测结果

八条开发路径先各自锁定前三名，另一进程随后评估全部 16 份训练内复核。每条样本听第一名的判断，只有另外两名意见一致时才采用它们的预测。这条规则在四个任务上都没有达到预登记的后续验证门槛。

| 任务及主指标 | 第一个开发划分的两次复核 | 第二个开发划分的两次复核 |
|---|---:|---:|
| Task1，准确率 | +0.23，−0.23 | +0.15，+0.23 |
| Task2，准确率 | −4.65，−2.27 | −1.97，−4.05 |
| Dry Bean，准确率 | −0.06，+0.35 | +0.06，−0.06 |
| SMS，macro-F1 | −12.79，−15.51 | −16.99，−18.54 |

每项为投票相对首轮第一名的主分变化，单位为百分点。Task2 的第一名是 MiniLM 加词法特征，另两名均为词法方法。以第一个复核区块为例，在 1,376 对标题中投票挽回 92 对，同时把原来答对的 156 对改错。剔除首轮探索评估中出现过的标题组后，该区块仍下降 4.78 个百分点，其余三个标题区块也均为负。

SMS 的固定路径前三名中，两位挑战者在四份复核中均未纠正第一名的任何错例，却分别引入了 25、31、34、40 个新错。这里检验的是固定路径在前四个尝试中实际筛出的三名。动态搜索第五次才找到的词字符 C=3 没有进入这场投票。两项结果合在一起，支持在这些短信开发样本上保留动态探索。

覆盖率只说明曾有别的方法答对。给不同模型相同票权会允许相近路线共同推翻较好的模型。此轮保留现有单模型交付，未启动新融合方法训练。八组名单对应的固定路径各有 11 次实际拟合。重放只读既有预测，新增拟合与模型 API 均为零。三个成员若都全量重训，原固定流程需要 13 次，超过每路径 11 次的约定。两次复核有样本重叠，这些开发结果不足以断定所有融合方案的表现。
