# 标题改写片段对照

前两项冻结模型试验中，两个十二层模型有 1,643 对共同错误。下一项检验换一种看输入的方式能否纠正其中一部分。这里采用一个适用于有方向文本对的规则。模型仍使用已冻结的十二层 MiniLM 以及原分类头，新增监督训练、模型 API 均为零。

以空白分词并忽略大小写，对标题做词序对齐。保留每个发生变化的片段及左右各两个词，上下文不连续时用省略号连接。双方都至少保留三个词、合计至少能删去四个原词时才启用额外视图。相同标题、文字本身过短及无法裁短的行沿用原输入。对齐先用标题文本建立确定顺序，再恢复调用方的左右次序。替换只影响十二层语义特征，将完整标题与改写片段的语义分数等权平均，词法和风格仍使用整条标题。

在同一批 6,608 行和两套分组五折上检查全部折外预测。以每个模型自己的原预测作对照，逐行核对十个对照输出。预先要求两个种子分别有正增益，且两者平均净提升至少 0.20 个百分点。另记录触发率、改对和改错及对两种子共同错误的覆盖，只用于解释。通过后才对以前用过的 1,693 行训练内保留区评分。该结果须严格超过完整十二层原模型并达到至少 1,235 对，才评一次课程指定验证。课程正式测试和 H1/H2 均不参与。
