# 允许同一个 Agent 自主比较不同模型

共同基线固定为 `9eb9b5a71f9ddce912550a28a17c12654dcd53a9`。本批是 B 的本地研发。训练入口读取匿名分类契约、匿名特征与训练标签。运行中没有人工指定模型、实验次序或最终赢家。研发者提供通用可执行方法、选择算法与资源上限。模型 API 为零，不使用课程指定验证、正式测试或 H2 外层。

在现有词、字符、冻结 MiniLM-L6/L12、E5 与词频候选以外，新目录开放线性 SVM、原生 Bernoulli 朴素贝叶斯、带监督词权重的逻辑回归、风格统计 CatBoost 和一个新表示。新表示用训练文本的冻结十二层 MiniLM 估计无标签话题方向，学习同一种写法在不同话题下与偏好的关联。只按输入语义、可用依赖、权重与预算开放方法。词表、主成分、分类器均限当前 worker 的训练行；每个候选只拟合一个监督分类器。两组共享原目录中的全部可执行配置；扩展组额外看见同一套新增通用方法。

两条正式对照和电影迁移均使用同一个自主本地规划器。它在所有合法未试候选中按方法属性、训练数据量、已观测分数和已测模型的逐行分歧估算收益与探索价值；首步也由程序评分。平手按配置内容摘要稳定决定。两组均从自身目录自主选第一步，继续使用共同的成对复核、晋级、停止和重训逻辑。每次模型选择保留全部备选分数、反馈来源与预算，可用原始状态逐动作重放；另检查改变候选呈现顺序、屏蔽历史表现或调换已观测反馈是否影响选择。反事实只作为机制检查。

先做一个独立合成匿名输入的完整自主冒烟，每路径最多 6 次拟合。之后同份未见标题组上做两条完整自主路径，两组的唯一区别是可用方法目录，参照组带全部原有方法，扩展组还能试上述新增方法，两组的规划器、划分和预算相同，固定种子 51803，各含重训最多 11 次拟合。另在既有电影台词训练包上用同一套程序与目录跑一个自主迁移路径，最多 11 次。所有真实路径和模型先统一封存，再在独立进程对无标签特征各导出两次，最后评分。初批上限 39 次真实监督拟合，0 次规划模型调用。数据读取、预测或签名检查失败时保留原始记录，已完成的拟合不重做。

标题在原 8,301 对训练数据中按共享标题的连通组另留一块。排除已登记的 1,693、1,637、1,223、937 行开发面板、完整标题运行第一次复核的全部组，及 6,608 行子包中两个历史开局与 814／777 行面板。剩余连通组按固定摘要 `b-varied-models-20261124/v1/` 划分，取余 3 为 0 或 1 的组作本轮留出。与上述命名面板和本轮训练均不交叉。更早的开发无法据此称为从未使用。电影台词用原登记训练中的内部反馈，同原研究单独按电影与连通组隔离的 450 对计分；该 450 对是已使用过的迁移开发基准。

报告两组实际尝试的估计器与表示、复核/停止依据、留出正确数、逐题得失、按组重抽样 5,000 次的配对 95% 区间，及真实拟合、调用、费用。标题净增至少 0.5 个百分点且区间下端大于零，才支持把扩展目录晋级为默认目录。电影单路径只支持考察迁移行为与交付，不能估计相对提升。即使某个新模型未被选中，也不在启动后调整次序来让它出场。
