# BP-01 · 两机划分不同的零训练排查

A-10 与 BQ-01 的 Dry Bean、SMS 使用相同种子，记录的包和实际划分却不同。本批使用同一台 Mac 上已有的两个 Python 环境，对相同的两个公开训练文件做盲于模型分数的排查。环境一使用 scikit-learn 1.7.2，环境二使用 1.9.0，A 留存的 Windows 环境使用 1.9.1。仅打开原包的清单与训练成员。

1. 检查两个 ZIP 的中央目录，只在内存里切换创建系统字节，计算摘要，和队友记录的 Windows 整包 SHA-256 比较。两边相符才能将整包差异归到该元数据。
2. 两环境分别按 A/B 已公布的外部种子 45101 及内部 707、808、909 自行划分。比较原始外层行号、三份内层行号与标签的摘要，分别对照 A-10 和 BQ-01。两个环境中有多个库版本不同，不拆分单个库版本的因果贡献。
3. 向两环境输入 BQ-01 已归档的确切行号。检查各划分训练/留出完整互斥、类别齐全、无重复输入跨界，并按实际输入顺序计算训练内容与标签的逻辑摘要。在同一组源行上比较跨环境的一致性。此项只检验数据，相同输入不保证不同软件环境训练出同一模型。

允许新增训练、模型预测、外层模型评分和模型 API 均为零。全程不改动已完成实验或 A 的入口。本批结果用于决定最终协作时要共同传哪些文件。
