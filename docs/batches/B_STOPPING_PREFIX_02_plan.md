# 配对复核后，哪些证据仍值得追下去

B-STOPPING-PREFIX-01 中要求「连续领先且与任意对手复核过」仍错过两个后来胜出的短信模型。对同一批已用作设计的 22 条轨迹评估两层额外条件，并把相同规则用于未参与本次规则设计的 6 条公开情感分类历史路径。公开评论路径来自商品、电影、餐馆轮流整域留出的原菜单与扩展菜单。它们的原始结果以前已经公开，不作为盲测。各批和各来源分开报告。

1. 沿用上一批的连续领先及配对要求。如果另一个已测候选的首轮主分超过在位模型至少 0.002，且两者尚未在任何共同复核划分相遇，就推迟停止。0.002 沿用原调度器的晋级常数。这测试「被复核过的对手」是否就是眼前真正值得检查的对手。
2. 在上述条件上，若仍有合法、可负担、从未在首轮尝试的方法路线，则继续。以原目录的路线字段为准，保留最终重训名额，按现有调度器开局后三轮的同等口径，同时预留一次探索和一次确认。目录配置参数不同但路线相同，按同一条路线计算。这里只评估这类可见行动对停手的提醒。

上述条件只能推迟一个假设的提前停止决定。原 Agent 自己结束时一律结束。所有路径使用原版调度源码与真实历史，复现原动作、逐行证据、预算和最终赢家。先锁定选择，再匹配历史完整重训的交付物。在不同版本确实训练过的模型不跨版本借用。缺少可比完整模型时报告缺测，不用内部搜索分冒充外部成绩。各规则统计提前数、预计节省数、错过赢家数、可比成绩。把仍然错过的情况按当时能看到的证据列明。零新增训练、零模型预测、零模型 API，不开放课程指定验证、测试或 H。
