# 同源样本会改变调度器对反馈的判断吗

使用 BA19-01 有序关系两条路径及 BA19-03 两个 Released 任务各两条路径，只看训练内逐行预测、任务、真实动作与当时剩余预算。先逐个复现原决策并核对事件中状态指纹。运行器不得打开任何外层预测、留出标签或得分。数据输入仅从已签名的优化训练包、实际训练内分区及其来源组登记取得。

旧调度对准确率以两个方法的不同预测行数开平方除以行数来近似波动。有两种可能的误差来源。多分类中两个不同预测可以同时错误，同源的多条样本也可能一起成功或失败。为每一对候选计算每行是否改对，按真实来源组把各行的配对正确数差汇总。对组内「正确数差减去整体平均差乘以组大小」的平方求和，乘以组数除以组数减一，再开平方并除以总行数，得到组相关的一阶标准误。沿用现有最小差值 0.002 和晋级规则。此阈值只用来决定是否值得复核。

优惠券按重复特征组，标题按共享任一标题的连通组，有序关系按 BR-01 的完整原句来源组。分别报告唯一候选配对的阈值差异、原轨迹上动作差异、最早分歧及其前所有动作是否一致。分歧后的状态仍是旧调度实际经历的历史，不能当作新调度自主运行。只做离线诊断，零训练、模型调用、预测和新成绩；不足以选新的部署调度。本批不占双方 D4 的可选方法或正式矩阵。所有实际动作相同的方向不追加种子。
