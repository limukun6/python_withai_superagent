# 共享标题加权的两组额外确认

首轮 E5 加权在两种子上分别多答对 10 和 14 对，其中 285 对出现在两轮评估中。首轮的预设门槛已满足。下面的确认集在新模型训练前一次性固定。

1. 只读取原 6,608 条匿名标题训练包。找回两个首轮评估中出现的全部标题组。余下组以固定盐 `title-weight-confirm-1123-v1` 加公开分组哈希后取 SHA-256，大端整数模 5 等于 0、1 的组分别进入确认 A、B。在 A 或 B 中出现的所有标题都从两种新模型的训练中排除。A、B 互斥，也与首轮两份评估组互斥。
2. 两个新分类头使用完全相同的训练行、交换增强与正则强度。一套 E5 特征提取器仅在本次训练行上拟合。一个分类头使用普通行权重，另一个使用已登记的组大小负二分之一次方权重。每个分类头实际只拟合一次，然后分别在 A、B 上预测；记录输入、输出、训练工件和真实拟合回执。
3. 报告两个确认区各自的改对、改错和差值。它们互不重叠，同时报告按标题组重采样的合并差值。两个区都未退步且合计至少多对 8 对，才把新方法交给正式调度做一次从头选择；未通过则保留试验记录。该门槛不能证明统计显著性。
4. 本批最多 2 次本地监督拟合、模型 API 0 次。两个模型的预测文件都冻结后再评分。1,693 行开发保留区和 940 行课程验证集均不用于本次比较。
