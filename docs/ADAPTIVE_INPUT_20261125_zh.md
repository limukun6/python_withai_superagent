# 陌生分类任务的文件接入验收

统一入口先读取任务包中的训练声明和文件结构。原有读取方式无法建立契约时，程序按内容识别记录、数据库表、工作表或图片目录，核对训练划分和预测目标，再交给实验规划器。预测进程从模型旁的任务契约恢复字段、顺序和读法。适用范围是课程的表格、文本和图像分类。

新验收覆盖嵌套 JSON、逐行 JSON、UTF-16 分隔文本、SQLite、Excel 工作表、Arrow IPC、普通 XML 记录、ARFF 和定宽文本，以及 gzip、TAR、ZIP 和目录封装。图片目录可读取单帧 PNG、JPEG、BMP、TIFF、WebP 和 GIF，保留旧 PNG/JPEG 模型的解码契约。混合文件必须先认清每行或每张表的划分。混合文件的容器字节可能包含多个划分，只有选定的训练行进入特征分析和模型训练。

明确的机器声明和常见格式可以在本地处理。有自然语言格式公告时，合规的 Flash 可以解释字段名、字符位置或任务目标与字段字典的对应关系。程序核对引用、字段范围、整行宽度、实际训练标签和后续预测接口。格式解释和实验规划共享同一个模型客户端与每任务调用额度。没有可验证的标签、划分、解密密钥或支持的解码规则时，系统记录原因。能验证类别与预测行的情况允许输出标明身份的训练类先验。

四组最终离线冷启动均完成训练、出预测和跨进程逐字节复现，每组 3 次实际拟合。另用学校 DeepSeek-V4.1-Flash 真实解释了一份无表头定宽合成数据公告，随后完成 2 次拟合并复现预测。真实调用 1 次，输入 189、输出 160 token，按项目冻结的空闲时段输入 ¥1/百万、输出 ¥4/百万计 ¥0.000829。个人暂记账本等待团队合并。前后三批格式实验合计 23 次实际拟合，正式测试集保持封存。

两份 Released Task 的训练输入逐行对齐此前封存的最终训练数据，旧模型对指定验证特征再次预测，2,030 行与 940 行分别逐字节一致。此项复核没有重新选模或评分。格式阶段的全仓 734 项测试通过。脱敏实测记录见 research/adaptive_formats_1125/verification.json。
