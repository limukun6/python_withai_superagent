# A27 词法方法与 B 已有方法在同一真实开发划分上的自主对照

A 的 202a250 保留四个共享训练词表的 TF-IDF 方法。B 原有三个固定哈希词法方法及一个可选的本地冻结 MiniLM，特征权重、词典与模型参数不同。整合时先保留 A 候选的正式次序，再附加 B 已有次序。两边方法必须在训练前向调度可见，交换输入须保持标签与概率。不得按数据集名称选择，不更改调度晋级阈值。

先运行两边方法和组合边界的回归，并用完整回归检查偏好、关系、图像和已有调用。真实开发比较使用 MRPC 的原训练分片、以前冻结的外层种子 45101、同一训练包、三个开发分区 707/808/909、外层 746 条及保留的倒序包。分别从 A 原始公开源码和本地合并后的源码，通过它们自己的正式运行入口运行 full/local/ab-v1，实际每路径最多11次训练含重训、1,200秒、单次300秒。共同代码变更包括 B 既有通用调度优化与目录，结论限于两套实际运行栈；记录调度文件摘要以及在这个任务实际可见的方法与完整动作。发布者训练优化数据外的真值只在两个模型均封存后访问。分别在三个新进程核对原目录、迁移目录与交换输入，并在各版本中核对概率；比较正确数、macro-F1、改对与改错和物理训练费用。如果一个模型在两次运行中胜出也保留结果。所有训练仅开发用途，模型API零，不读取H或课程测试。
