# 用同一路径已经训练过的挑战者复核低信心行

上一批按既有最终模型的概率定位难题。本次对原四条已冻结的代表参数路径运行一个预先固定的预测规则。对每条路径，从它自己实测的 primary 历史中，在与最终模型表示路线不同、能输出概率并有行级证据的候选中，按已归档主分降序、同分按原试验顺序，选择第一位挑战者。它保留当时的内层试验模型，不重训、不跨路径借模型。四条路径先共同冻结挑选的候选、权重指纹和输入身份，再比较留出预测。优化集不包含留出标签。

部署规则固定为：最终模型的信心低于 0.60、挑战者信心至少 0.80、两者类别不同时才改用挑战者标签，其余行都保留最终模型。为检验推断时的选择本身，分别报告原模型、挑战者单用与规则输出的所有行，给出真实改对、改错、分数与实际需要交给挑战者计算的行数。不能据此更换阈值。没有另一种合法路线时原样交付。研究代码用同一条路径的现有训练产物，新增监督或无监督训练均为零，额外成本是预测；原模型原路径拟合数仍单独标明。四份开发留出曾经用于前期诊断，因此这属于开发验证，正式验证、正式测试和 H 均不参与。
