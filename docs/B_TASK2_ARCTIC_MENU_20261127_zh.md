# 给统一入口多一个 Arctic 编码器后，Agent 怎样选

在原有资源目录旁新增 Snowflake Arctic Embed S 的公开权重，固定发布版本和文件指纹。Agent 会识别发布者声明的池化配置，开发者可以用同一接口提供其他兼容的句子编码器。运行时由 Agent 决定是否训练、采用或融合该资源。[发布者模型说明](https://huggingface.co/Snowflake/snowflake-arctic-embed-s) · [本次下载凭据](../research/paired_encoder_search_1127/arctic_publisher_receipt.json)

从 8,301 条课程训练题新划出 6,631 条供两组从头学习，另外 1,670 条单独评分，组间不共享标题。两组的程序、数据和预算相同，只改变资源目录。每组最多 22 次拟合、1,800 秒。新编码器的 11,546 段训练文本向量提前一次性算好，耗时约 156 秒。

| 资源目录 | 首轮可行动作 | 实际拟合 | Agent 最终选择 | 训练内留出 |
| --- | ---: | ---: | --- | ---: |
| 原目录 | 71 | 18 | MPNet 与 GTE-base 等权 | 1,222/1,670 |
| 多一个 Arctic | 72 | 18 | MPNet 与 GTE-base 等权 | 1,222/1,670 |

Arctic 在第二组首轮已可用，后续没有被提名训练。两组的 1,670 行预测逐字节一致，外部进程均成功重载。该结果衡量了把新模型提供给现有调度器的作用。Arctic 单用的分数和它能补对哪些题，需要另外的受控测量。[两组评分、训练次数与决策回执](../research/paired_encoder_search_1127/arctic_menu_results.json)

第 3 步时，Arctic、MPNet、DistilRoBERTa 和 MiniLM-L3 的探索分数精确相同。按照可执行配置指纹打破平局，MPNet 获得训练机会。它返回结果后，Arctic 在下一步菜单中降到第 18 位。后续调度转去复核已经展示实力的候选。这里可以具体定位到早期探索机会的分配。[带同分候选的逐步记录](../research/paired_encoder_search_1127/arctic_menu_expanded_trace.json)

这两次运行冻结在修复本地编码器派生身份之前。它们都从 MPNet 提名案例投票，却实际试用了 MiniLM 表示。两次都保留原双模型，投票最终权重为 0。由这两组成绩无法判断正确的 MPNet 案例投票会怎样。合计实际拟合 36 次，模型 API 0 次。课程指定验证答案、正式测试与 H2 均未打开。

### 每个可发现编码器都给一次相同的训练机会

从上述 6,631 行训练数据中，按共享标题分成拟合、提名、确认、最终检查四份。只在第一份的 2,685 行上拟合，把历史三模型组合和四个通用编码器放在同样的条件下比较。程序依据第一份反馈定下是否加模型及其票权，再由第二份反馈决定是否保留，最后才看第三份。下面的“原组合”指在这 2,685 行上重新训练的三个成员。受控实验总共 7 次拟合、模型 API 0 次。

| 方案 | 提名，1,319 条 | 确认，1,318 条 | 最终检查，1,309 条 |
| --- | ---: | ---: | ---: |
| 原组合 | 926 | 924 | 910 |
| Arctic 单独预测 | 903 | 926 | 885 |
| 原组合 75% 加 Arctic 25% | 923 | 932 | 913 |
| 程序选定的原组合 50% 加 MPNet 50% | **931** | **941** | **917** |

有无 Arctic，程序都提名并确认了 MPNet。最后检查相对原组合改对 64 条、改错 57 条。这支持再用较大训练量验证这次自选的组合。它尚未进入正式提交。[提名和配对数量](../research/paired_encoder_search_1127/resource_audition_nomination.json) · [完整结果和四个单模型](../research/paired_encoder_search_1127/resource_audition_results.json)

把程序选出的成员和 50% 比例锁住，提高每次拟合的数据量至约 6,600 条。在两次按共享标题分组的五折实验中，每次都覆盖 8,301 条训练题。第一组从 6,104 提高到 6,127，净增 23 条（+0.28 个百分点）；第二组从 6,069 提高到 6,139，净增 70 条（+0.84 个百分点）。两组各有四折提高。按组重采样的 95% 区间分别是 −0.35 至 +0.88 和 +0.22 至 +1.47 个百分点。这批复用之前的 30 份成员拟合，仅新增 10 次，未读取课程验证答案。达到预登记的下一阶段门槛，可以测试普通 Agent 能否自行发现值得补回的成员。当前可提交模型仍为独立复现的 710/940。[大样本对照与逐折结果](../research/paired_encoder_search_1127/audition_scale_results.json)
