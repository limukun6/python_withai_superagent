# 用题目本身能看到的特征定位开发错题

第一批发现了少量相同输入的矛盾标签，以及标题图里仅两个比较三角。本次只使用相同的训练源和四份原有开发预测。此前四份总分已知，此次仅用特征固定分层和每行所属组，落盘组的行序指纹，再读取原预测、使用标签计算分项。按两份划分分别报告，不用这些分项调参、改路由或筛掉难例。所有分组均完整保留，即使一组样本很少或为零。

* 对优惠券，在各自的优化行中记录原有 21 个字段各自出现过的值及 210 个字段对出现过的组合。按留出行有无新单字段值，以及没有见过的字段对数为 0、1、2 至 5、至少 6 划分。记录各组行数、对错与准确率。这是无标签的输入覆盖统计，不拟合模型。
* 对标题，用 Unicode 单词分词和大小写统一计算两个标题之间的单词编辑距离，标点和排版不计。按距离 0、1、2 至 4、至少 5 分组。另按原始比较图的连通块是否只有一场比较，对每个开发留出分别计数和计分。用原分组器采用的大小写和空白规范化核对留出两端的标题在优化输入出现 0、1 或 2 个。关闭严格分组时才可能见到已有标题，这里只核查实际分区。
* 对完整标题训练源及每份留出，核对所有长度的有向循环。先按原始标题把相反方向的胜负相抵，统计剩余图的有向强连通分量、无向连通分量、只有一条边的分量和最大分量。若图无环，说明存在能满足这些已观测比较的排序，不输出排序或预测，也不外推到未试的标题。若有环则报告含环的分量与其中的边数。

分项仅采用先前锁定的优惠券代表配置和两个标题原冻结赢家，原 CSV 继续做逐行指纹与总分核对。比较图稀疏、分母很小或两个划分方向不同的现象都将明示。新增训练、模型推理、API 和课程费用均为零。
