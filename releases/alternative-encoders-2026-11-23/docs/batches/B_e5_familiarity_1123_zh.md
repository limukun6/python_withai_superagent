# 在相同内折上检验 E5 和词频特征是否互补

历史固定组合中，E5 加普通十二层在多次使用的 1,693 对开发保留区为 1,234 对。带新特征的十二层单模型为 1,232 对。两者都已冻结，单独成绩接近不足以说明其错误可以相互纠正。

沿用 29111 的两个内折。每折原十二层和带特征的十二层均已实际拟合，只新增一次同配置 E5 头，合计最多 2 次物理拟合，模型 API 0 次。比较相同 E5 与两种十二层的等权概率组合，不搜索权重。首折计全部标题组，确认折另剔除与首折评分组重叠的行，再分别报告总数。任何方案的当折评分标题均未用于相应模型训练。

进入开发保留区需同时满足以下准入条件：相对于 E5 加原十二层，在首折、整个确认折、剔除重叠后的确认折都净增；去除重复评分组的汇总增益至少 0.2 个百分点；新组合的汇总正确数超过 E5 和新特征两个单模型各自的成绩。未达到即结束该项，保留区继续封存，原组合可继续使用。如果达到，两个完整组件均可从同 6,608 行训练的已保存模型复用，独立进程导出两次，核对模型、权重依赖、行序后才打开训练内保留区的评分。结果属于研发人员登记的一种组合比较。正式入口自主选择的另批结果单独交付。课程指定验证和正式测试仍不在本批范围内。
