# 把文件名与真正的评价目标分开测试

使用 B2-01 已完成的两任务、六条真实历史，不增加训练。先把两份优化训练包各自改用一个匿名文件名和一个暗示其他任务的文件名，归档字节不变，重新从项目输入入口解析。对 61 个原始状态分别用两种重建的任务契约、目录及真实预算再次调度，比较动作全部六个字段，核对任务名称是否进入当前本地策略的决策。

在另一个对照中保持样本、划分、模型和历史上的选择不变，只交换明确声明的主指标：标题由准确率改为 macro-F1，短信用相反方向。对每个真实 worker，使用保存的训练侧准确率、macro-F1 计算相应训练主分；对搜索／确认侧从已签名的真实行级预测及可信标签重算两个指标。为新目标绑定独立评价载荷指纹。用同一套简化历史先复现原目标 61 个完整动作，再做同状态的指标替换，核对能力目录是否变化，分别报告下一步动作或试验候选的变化、第一处分歧，以及在相同已观察证据下最终推荐的模型。不生成分歧后的虚构历史，不重训或评新目标的最终成绩。全程不读外层标签、课程正式验证、测试或 H，零模型 API。
