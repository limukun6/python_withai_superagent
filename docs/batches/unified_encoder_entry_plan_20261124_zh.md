# 三编码器可选入口的匿名冷启动验收

在打开三种编码器新五折的外层成绩以前登记。用同一个只有训练成员的匿名标题包再冷启动一次，逐行预测由实际交付模型导出。训练侧不导入此前任何候选预测或标签清单。沿用统一版按共享标题组自动保留审核区的规则。剩余标题按组的固定哈希排序分十桶，六桶训练分类头，两桶学习候选与权重，两桶确认最终选择。六个分类头均从头拟合，四种选择仍与五折相同，每路径 6 次基础拟合、2 次连续权重拟合、2 次离散选择，模型 API 0 次。本路径只用课程训练集，课程指定验证与正式测试均不评分。缓存仅存固定编码器逐输入计算的向量。

在培训部分和模型都封存后，比对独立进程的最终预测，同一次冷启动的原双模型和 Agent 在预留审核行上做配对核对。基础模型所见样本数与历史全量双模型不同。这个面板参与过历史研发，作为端到端验收来解释。冻结基线继续独立交付。
