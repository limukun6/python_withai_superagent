# 搜索反馈与复核开销的配对实验

按[阶段协议](current_stage_10h_zh.md)在两个发布任务的训练数据中比较三个配置。B 使用真实搜索分数和三名复核候选。F 只替换传给搜索器的分数，仍用实测成绩入围及选模，与 B 均用 11 次拟合。K 保持 B 的搜索，用两名复核候选，实际执行 9 次拟合。每个种子的各臂复用相同的外层行索引。模型冻结后才评估外层预测。

## 开发阶段

| 任务 | 外层种子 | 行数 | 正确数 B / F / K | 耗时 B / F / K（秒） | K 相对 B 的节时 |
|---|---:|---:|---:|---:|---:|
| 表格 | 43111 | 1,299 | 965 / 966 / 965 | 98.7 / 64.1 / 102.2 | −3.5% |
| 表格 | 43117 | 1,299 | 932 / 932 / 932 | 106.2 / 63.4 / 93.2 | +12.2% |
| 文本 | 43111 | 1,328 | 886 / 886 / 886 | 40.2 / 40.1 / 36.5 | +9.1% |
| 文本 | 43117 | 1,327 | 878 / 878 / 878 | 41.7 / 40.8 / 39.1 | +6.4% |

12/12 条运行有效，累计 124 次拟合、766.0 秒、0 次模型 API 调用。B 和 K 的前四项候选和实测分数全部相同。K 在 4/4 配对中保持逐行预测，3/4 更快，四对节时中位数 **7.8%**，低于协议要求的 **20%**，因此 K 结束于开发阶段。

每次少验证的候选都是表格的 `extra_trees_leaf2` 或文本的 `char_C1.0`。这些拟合在本轮较便宜，少两次拟合的效果随被移除候选及机器时延而变。表格种子 43111 的 K 在前三个较慢的搜索候选上总耗时比 B 长，抵消了复核阶段的节省。实际节时按每个任务、种子内的配对墙钟计算。

真实分数使 4/4 配对在第 3 步更换搜索动作。表格 43111 改变了最终赢家及 85 条预测，B 相对 F 改正 42 条、新增 43 条错误，净减少 1 条。其余三对逐行预测相同。根据协议继续跑 B/F 的三个锁定复验种子。

12/12 条运行有效，累计 132 次拟合、701.3 秒。表格每次在第三步分歧，B 试深度 8 的 CatBoost，F 试一个逻辑回归配置。表格前两个复验种子最终选择不同深度，分别有 79、82 条外层预测不同。表格第三个复验种子和三条文本复验最后都选回同一赢家，逐行结果一致。表格平均差为 **+0.026 个百分点**，文本为 **0**，准确率未达到事前规定的平均改善和复验胜场门槛。

本轮合计 **24/24 条有效轨迹、256 次实际拟合、约 24 分 27 秒、0 次模型 API 调用**。使用记录逐行复算正确数、改正数和新增错误，并核对冻结行索引和所有模型、预测文件哈希。两个阶段均只读任务包的训练数据来训练和比较。

## 可写入报告的结论

本地 Agent 在第三步会根据前两次实验报告的分数切换搜索动作。开发和锁定复验共 10/10 对出现该分歧。该差异在复验 2/6 对改变最终赢家，表格一胜一负，文本均同选。读取分数的收益取决于它会把搜索导向何处，以及新候选能否通过独立划分复核。在本轮表格任务上，真实分数导向较慢的深树候选，五个配对的实际墙钟都高于屏蔽组。相同拟合次数能够控制尝试数，墙钟还取决于各次尝试的成本。

复核前两名比复核前三名少两次拟合，但本轮开发实测的中位节时为 7.8%，低于预设门槛。保留现行 4/3 作为统一配置。这里的比较覆盖两个固定任务的训练内重划分和特定本地策略。它提供了反馈会改变搜索路径的直接证据，准确率效益在这些配对下没有达到采用标准。新任务与整合版真实 Flash 的表现仍待验证。

现有发布模型、任务包和发布运行时的指纹均通过核对。用课程验证特征在新进程运行 `superagent predict`，表格仍为 1,527/2,030，文本仍为 654/940。文本预测输入交换了两列在 CSV 中的位置，列名与内容的对应关系保持一致，结果逐行复现。后续正式测试使用课程指定输入与评估时点。

本轮又从统一 CLI 训练、复核、重训并重载匿名数值和 RGB 多分类包，分别输出 15 条预测。图像包只提供训练集和无标签预测输入。行序负对照与篡改模型哈希检测均通过。10 项定向测试覆盖分数屏蔽、时间耗尽时的部分结果、列识别和 CLI 运行状态。产物位于本轮结果目录的 `delivery_checks`。待收尾的交付物包括整合版 `report.pdf`、最终提交包与队友独立审阅。
