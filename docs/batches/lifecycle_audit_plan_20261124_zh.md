# 从任务说明到交付的审查与实验登记

共同代码起点为 `bcea2789`。历史课程验证仍属于当时冻结的程序；本批只使用训练内部或受控匿名数据。A 拥有任务契约、执行和导出，B 拥有候选与调度；跨这条边界的改动放在单独研究分支供复核。

## 目标与证据边界

1. 用同一匿名数值 CSV 和相同 README 先运行原版，再运行修复版。固定 620 行、8 维、二分类、类别权重 0.86/0.14、随机种子 1124（scikit-learn make_classification），前 460 行训练，余下 160 行留给预测冻结后的工程核对。README 明确指定 macro-F1。另以显式 manifest、相矛盾的目标、否定、未给目标、多分类和其他格式检验读入。成功条件是任务、所有已完成试验、选型记录均使用声明的指标，两次独立无标签预测相同。合成任务的准确率不用于判优。两个版本各最多 10 次实际分类器拟合，模型 API 0 次。
2. 对原版 Task1、Task2，按原运行中的逐行索引，量出首轮和实际执行过的复核之间共用了多少评价行和多少组。分别列出实际执行与最终选型实际采用的分区。在单次分区内部继续检验训练与评价没有重组。通过条件是今后产生的最终记录能区分“使用另一个分区”和“该分区的评价组与前面互不重叠”。这项工作不能推出旧验证成绩受污染。
3. 对已封存的 Task2 两套五折逐题概率，检验“先提名一个，再单独批准”的规则。六个分类头及各个候选策略均复用旧学习区的结果。逐折把原确认区按标题组 SHA256（固定前缀 lifecycle-confirm-v1/）排序后交替平分。第一半只用于提名，从单模型、等权双模型、固定融合、逐题融合中选学习区净收益为正、且提名区准确率收益减一个按组标准误为正的最高者；同分依次比较 Brier 收益和规则原顺序。第二半只审核该提名，准确率收益减一个按组标准误严格为正才采用，否则保留双模型。比较原双模型、原决策、提名直接采用、新决策。封存十个决定及其预测后再汇总外层真值。报告改对、改错、按标题组的配对区间和每折差；两个角色轮换复用相同题目，分别报告。每轮至少四折正收益、总净增至少五题且配对 95% 区间下限大于零才进入新的独立匿名验证；本批不替换交付。基础模型与融合权重新增拟合均为 0，记录十次提名与审核。
4. 审查各环节的源代码、已有真实运行及交付物，覆盖任务语义、数据划分、候选可达性、规划与执行、反馈、停止与重训、跨进程预测、资源与课程提交。明确属于默认入口、可选研究入口、历史测量或未来验收。未见正式任务、指定验证和正式测试均不参与本批。
