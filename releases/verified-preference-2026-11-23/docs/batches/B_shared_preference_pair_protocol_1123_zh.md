# 标准入口下十二层与改写特征的新配对

两边均使用同一版本的正式 `superagent run`、本地 ab-v1 动态调度、匿名训练包、随机种子 8123、共享标题划分和停止规则。取已封存的 6,608 行作训练，1,693 行留作开发评估。两边都有词法、六层、十二层、原非线性等候选。研究组在相同位置之后额外开放 `minilm_l12_with_edit_context`。只用函数适配任务契约和训练反馈决定是否探索或复核，候选未入选时也保留完整记录。

新候选只训练一个逻辑回归头。原十二层的全部词法、风格和整句语义特征保留，另提供 384 个特征，表示改写片段的语义差减去原句的语义差。无法抽出局部改写的标题对新增块为零。这个权重块由训练数据学习。两边在预算、其余候选和最终选型上使用相同执行代码。每边 11 次实际监督拟合封顶，含最终重训；本轮两边合计最多 22 次，模型 API 为零。各次拟合由实际分类器调用与执行器账本交叉核对。

两边均封存最终模型后，各自用两个独立进程通过正式预测入口导出相同保留区的逐行预测，核对行序和文件校验值后一起打开标签。报告各自正确数、改对和改错、按共享标题组配对重采样的区间，以及实际选型和资源。研究组没选新方法时，同样导出由 Agent 选定的模型。开发观察不用于声称已知准确率上限。研究组若在保留区超过对照且达到 1,235/1,693，才单独核验一次课程指定验证。正式测试及两份未见迁移任务不参与。
