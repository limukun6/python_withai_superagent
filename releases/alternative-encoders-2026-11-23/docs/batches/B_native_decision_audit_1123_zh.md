# 调度是否跟随逐行证据的验收

在新种子的真实匿名路径运行期间，登记 0 拟合、0 模型调用的决策验收。取实际第四次探索后的决策状态，从已冻结训练分区恢复行号和标签，检查重放的下一动作是否与真实日志一致。将四个已测候选统一改为匿名编号，更新其内部身份引用但保留全部数值，行动必须随 ID 一一映射。

分别注入两种明确标记的人造反馈，只检查调度机制。第一种让四个候选给出完全相同的概率与预测，调度应停止并保留一个模型。第二种使首个模型与第二个候选的错误互补，第二个候选单独更弱，但两者平均明确改善，调度应申请匹配复核。概率的摘要或对应行序被破坏时，机制应拒绝状态。所有修改只在内存中进行，原运行证据、训练、部署产物和成绩保持原样。
