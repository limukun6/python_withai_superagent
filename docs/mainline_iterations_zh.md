# 七次搜索的分类主线能走多远

本轮比较一套固定计算预算下，分类 agent 怎样使用最后两个试验名额。开放的能力由开发者编写，程序根据输入和前面试验的逐行预测自行选择候选，完成训练、复核和选模。各轮之间由开发者提出新假设。运行中没有人指定下一步，程序使用本地规划器和已下载的模型权重。

## 成绩怎样读

Task1 从随作业发布的训练数据中划出 6,494 行作为开发池，另外 1,623 行保留。Task2 的开发池有 6,608 行。每一套五折划分中，每行只做一次外层验证。Task1 的相同输入放在同一组，Task2 中通过任一共用标题相连的样本放在同一组。换随机种子会重分同一批样本，因此跨种子的正确数不能相加当作新的独立样本。

每组先做相同的五次搜索，再使用两个额外名额。原领先候选保证入围。入围三名在三个训练内划分上复核，优胜者用该折全部拟合行重训。七次搜索、六次额外复核和一次重训合计 14 次下游分类器拟合。我们逐折检查前五次搜索的预测完全相同，在所有比较组冻结后打开外层答案。正式验证和测试成员均未打开。每次试验上限 480 秒，整组上限 1,600 秒。候选的树数、特征计算量与实际用时可以不同。

更换主线的事前门槛是合计准确率比每个对照高至少 0.2 个百分点，且五折至少赢三折。在已探索的划分达标后，还须在重新分组的训练数据上复验。所有研究分支的分数用于开发决策。课程最终报告使用的正式成绩须从同一最终提交版本重新产生。

## 哪个环节还有空间

我们把第一套五折中原策略的三名入围者都在完整拟合行上重训，额外使用 10 次拟合。即使事后知道每折答案，并能挑中该折最好的完整模型，总共只能答对 4,810 行，比原策略多 9 行。这项诊断限定了原入围名单里进一步选模的空间。所有事后看答案的数字只用来估算上限。

再把每折剩余四名也用同一批数据重训，额外使用 20 次拟合。此时完整七名候选的同口径上界为 4,812/6,494（74.10%），比实际策略多 11 行（0.17 个百分点），低于晋级所需的 13 行。这个数值恰好与另一组固定路线的实测正确数相同。两个实验的候选、逐行预测与用途各异。

三名入围者按多数票决定类别，强制使用时答对 4,764 行。改为等权平均预测概率，在两套划分上分别答对 4,771 和 4,756 行。两种方式都沿用原 14 次拟合，其中两名成员来自较小的初次拟合。另付计算量将三个成员全部重训后，第一套划分的硬投票和概率平均均答对 4,779 行。

同一个普通 CatBoost 只改变可用于拟合的分组数量，依次使用约 25%、50%、75%、100% 时答对 4,545、4,610、4,725、4,758 行。最后四分之一增加了 33 行，说明固定名单的上限和整个分类问题的上限是两个不同的问题。查重还发现，39 组完全相同的输入带有冲突标签；这些样本约束出的 6,455/6,494 上界很宽，不能用作可达到的目标。

## Task2 与自主决策

普通七次搜索答对 4,421/6,608 行（66.90%）。开放另一组候选后，程序五折都先试从零训练的小型神经网络，再试普通文本方法，最终答对 4,435 行（67.12%）。逐折相差 +8、0、0、+12、−6 行。这一变化相当于纠正 163 行并新增 149 个错误，胜利折数低于更换主线的门槛。

对 Task2 同样把七名候选全部重训，事后可选出的最优整模总共答对 4,468 行（67.62%）。这 33 行空间全部落在每折原有三名入围者内。我们还重放了一条更谨慎的换模规则。新模型须在三个训练内复核中至少赢两次，纠错净收益达到 0.2 个百分点及一个分组标准误，才取代前五次的领先者。对重复出现的行先平均，再估计不确定性。这条规则在 Task1 少答对 26 行，在 Task2 少答对 14 行。

原来的 MiniLM 能力服务于表格类别名。在这次扩展中，输入为英文为主的文本、且多种模型仍共同犯错时，程序可以试冻结的句子向量。成对偏好任务使用左右标题的向量差，单段文本使用该段自身的向量。第一种候选将它与词、字符及适用的文本统计信息结合，第二种只用句子向量。固定组尝试两者；自主组会依据第一种候选改对和改错了哪些行，决定是否继续第二种试验。运行记录单独列出训练和外层预测的编码量。[MiniLM 模型说明](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2)

在第一套标题五折上，固定和自主两组都答对 4,623/6,608 行（69.96%），比 4,435 行的旧路线多 188 行。五折分别多答对 14、77、50、33、14 行。合计纠正 657 个旧错误，同时新增 469 个错误。自主组第三折把最后的名额给了普通文字模型，其余四折试单独使用向量。两组最终都选中混合模型，逐行预测完全相同。

先把三个入围者全量重训，再补齐每折其他四个候选，混合模型在五折中每折都是七者中最好的一个。就这批七个模型而言，即便事后看答案，也无法多答对一行。把句子特征在已训练分类器中的贡献减半降至 4,552 行，翻倍得到 4,607 行。让程序在内部搜索集上用对数损失和准确率决定是否改变权重，它五折都保留原权重。这项权重试验复用了冻结的向量和分类器，新增拟合与特征前向次数均为零。

表格的另一条候选路线从训练数据估计单个类别、类别组合与标签的关系。为每行生成训练特征时，程序先连同该行的重复样本一起留出，只用其他组的标签计数。遇到稀有组合时，估计向两个单列的估计收缩。单元测试会改变一整组自己的标签，验证这组得到的训练特征丝毫不变。[交叉拟合原理](https://scikit-learn.org/stable/auto_examples/preprocessing/plot_target_encoder_cross_val.html)

## 复现与团队交接

统一入口在两项任务各跑五折，分别复现 4,801 和 4,623 个正确答案。共 70 次搜索的逐行预测、10 个最终模型的逐行外层预测，与相应的单独路线完全一致。六类匿名输入均能导出可重载的分类器，每类顺序输出 15 行。混合表在第六次搜索后用完了可行候选，程序按设计提前结束。单段和成对文本模型移到新目录后，冷启动分别处理 131 和 262 个 MiniLM 输入 token，再预测的模型计算量均为零，输出文件字节一致。[统一运行与重载记录](../research/unified_policy_results.json)

另将两个真实公开数据集的名称和字段名从 agent 的输入中省去。采用三折分组验证，同一 `auto` 配置在葡萄酒数值表（178 行、3 类）得到宏平均 F1 0.9774，答对 174 行。在手写数字灰度图像（1,797 张、10 类）答对 1,759 张，准确率 97.89%。共六次完整训练，84 次下游拟合，模型 API 请求为零。这是两个公开参考任务的运行记录，课程未发布任务仍待最终评估。[逐折记录](../research/open_transfer_results.json) · [Wine 数据](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_wine.html) · [Digits 数据](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_digits.html)

同一运行时的五折结果来自本地 `tools.frontier_study`，该入口只准打开原始包的训练成员。它以对照在前的顺序接受 `--arms`，用 `--seed` 固定外层分组，用 `--freeze` 在首次拟合前写入协议。协议记录原始包和源码的 SHA-256、依赖版本、完整行号、对照运行目录和预算。可以复用同一划分下已冻结的对照模型。历史版本仍可按对应 Git 提交和保存的协议重放。

命令行接口另有匿名包端到端测试。下列命令使用同一套决策处理数值表、类别表、混合表、图像、文本与成对文本。每种都会把模型导出、重载，再逐行检查预测格式。单段文本和成对偏好模型另移到新目录，只复制分类器、任务规范和选模记录，显式传入公开权重，再验证冷启动与缓存预测。

```sh
python -m tools.method_smoke --policy auto --minilm-weights /path/to/all-MiniLM-L6-v2 --output runs/method_smoke
python -m tools.open_transfer_probe --output runs/open_transfer --freeze
python -m tools.open_transfer_probe --output runs/open_transfer
```
