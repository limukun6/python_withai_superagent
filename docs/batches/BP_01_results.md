# BP-01 · 相同种子产生不同行号的定位

把同两份未修改的训练输入交给两套已有的 Mac Python 环境。使用 1.7.2 版 scikit-learn 的环境重现了 BQ-01 的外层和全部内层行号；使用 1.9.0 的环境重现了 A-10 在 Windows（1.9.1）记录的外层行号，以及三份内层的行号与标签指纹。两个本地环境还有其他依赖差异。本次可以确认运行环境组合会改变由种子产生的行号。

| 只换本地运行环境 | Dry Bean 外层行数 | SMS 外层行数 | 两任务三份内层行号和标签 |
|---|---:|---:|---|
| Python 3.11 / sklearn 1.7.2 | 2,174 | 825 | 六份均匹配 B |
| Python 3.14 / sklearn 1.9.0 | 2,178 | 826 | 六份均匹配 A |

两个环境改为直接读取 B 已归档的原始行号后，源训练内容以及每个外层、内层的训练和留出输入都得到完全相同的逻辑摘要。每个划分均覆盖整个父数据，训练与留出无行号及重复输入交集，类别齐全。最终比较应交换确切行号、训练内容指纹、候选与环境版本。只传随机种子会重复出现这次分歧。

将本机两个 ZIP 中央目录的三个创建系统字节改作 Windows 值，均未复现 A 的整包摘要。整包字节差异的其余来源仍未确定。这项元数据检验不改变任何原包。首次零训练检查把 A 的整份任务字典传给了单任务比较函数，两个环境都在计算比较前报错。已保留失败回执，按任务取正确记录后在新目录完成两次检查。整个排查没有训练模型或调用 API。
