# Task1 重复画像下的情境分布与偏好估计

起点 534d599，交付基线 1549/2030。本机另外出现的实验记录提示部分券种、低置信度样本更难。部分记录在 1621 行的评价折上引用了早先 1615 行折的基线，故它们只用于形成假设。

1. 对照组使用原情境组合树。第一种新方法只从拟合侧构建“画像 × 情境”计数表，估计至多八组情境分布，再给树添加组别和组别与当前情境的组合。推断组别时扣除该画像对当前情境的全部计数。新画像使用总体先验，同批待预测行之间不共享信息。
2. 第二种方法用带 L2 正则的逻辑回归估计画像、情境以及它们交互的效应。通过不同特征缩放使样本稀少的高阶组合更强地向总体收缩。额外检查现有树与该回归固定等权的概率均值。阈值均为 0.5。
3. 固定种子 112801，按完整特征行分组的分层五折。前三折配对重跑基线和两个候选，9 次分类器拟合，额外 3 次无标签分组。记录准确率、配对改对/改错、低置信度及按训练侧最相关情境字段分组的误差。数据来自既有 8117 行训练集；新种子只用于排除错误的配对比较。CPU 预计 2–5 分钟，0 API。
4. 三折平均增加至少 0.5 个百分点，至少两折上升，最差折不低于 −0.5 个百分点的方案可晋级。多方案通过时取均值最好者，平分时选拟合数少者。只复核该赢家，在后两折与基线逐行比较，至多另 4 次分类器拟合。后两折累计净增为正且五折整体提升至少 0.5 个百分点，再接入统一入口做独立进程交付。只有 Agent 实际采用了新方案并封存预测后，才读指定验证标签评分。正式 test 封存。
