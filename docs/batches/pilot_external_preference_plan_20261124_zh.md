# 晋级后的独立匿名任务

在本轮 Task2 外层评分前登记。若主策略在 Task2 五折至少四折净增、总净增至少五题且标题组配对 95% 区间下限为正，冻结该策略再运行一次独立的英文回复偏好开发任务。该任务使用 OASST1 公开的人类撰写、人工排序对话。相同父节点下的回复按 rank 排名，0 最优。固定版本为 `a2c461b87baf5f2c581c20ca75d13d4e7b21c5cb`，读取 `2023-04-12_oasst_ready.messages.jsonl.gz`。不使用团队 H、课程指定验证或正式测试。[原作者的字段及排序说明](https://huggingface.co/datasets/OpenAssistant/oasst1/blob/a2c461b87baf5f2c581c20ca75d13d4e7b21c5cb/README.md)

每棵树只取英文根提示下未删除、非合成、rank 为 0 与 1 的两条人工回复，父提示 3 至 40 个按空格切分的词，两条回复各 10 至 80 词。保留原提示与回复，匿名字段中各写同一提示、换行和相应回复。按 `pilot-external-trees-v1/` 加树 ID 的 SHA256 排序。相同规范化根提示或回复只出现于一对，排序中保留首次。最多使用 1,024 棵树，序号模 5 为 0 的树作独立留出，其余训练。左右位置由 `pilot-external-order-v1/` 加树 ID 的哈希首字节奇偶决定，较优回复在左时标签为 1。至少 200 棵训练树、50 棵外层树，两个集合都需有两类。该语义和数据范围仅在准备匿名包与评估时使用。

同一主策略从匿名训练 ZIP 独立调用统一入口。先冻结模型和逐行原始文本预测，再打开外层标签。与同次训练的两个参考头比较，列改对、改错、按树配对 95% 区间及采用的第三模型。最多 9 次实际分类器拟合，模型 API 为零。固定公开编码只作下游特征。迁移结果只对该语言、长度范围及人工偏好任务负责。
