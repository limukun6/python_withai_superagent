# BP-02 · 从行号生成两台机器可直接使用的实验输入

BP-01 复现了两套环境自己划分时产生的不同结果。本批在独立 B 分支上把已核对的行号做成可复用输入。只做 B 负责的两个 C1 类型：真实标题偏好和真实数值表格。输入只读其原始训练成员。使用 BC1-01 已登记的外层、内层行号、任务语义和指标。

使用两套本地环境分别从原始训练源生成正式入口可读的优化训练包、独立无标签外层特征包和训练内划分清单。归一化 ZIP 中不影响数据的时间、创建系统及压缩元数据。数组按原数据类型、行序和标签交付。两环境分别计算输入摘要，要求两个任务的训练包、无标签包及划分清单都字节相同；原始任务契约、逐行值、类别和全部内部行号须保持不变。

分区选择器接收事先登记的清单摘要，检查训练内容、索引覆盖、分组隔离、类域、种子、行与标签指纹后才给出索引。测试进程只替换 A 分区函数所用的行号来源，仍由 A 的原函数写出实际 worker 输入、验证摘要和可信分区。两环境为本机的 worker 文件分别计算实际摘要，另核对跨环境的逻辑样本内容。生产入口与旧研究分支均不改动。补充检查换序输入与被改动的清单会在执行前被拒绝。

这项数据实验的训练、模型预测、外层评分和 API 上限均为零。课程验证和测试集、H1、H2 均不打开。二者完成后再计算跨环境比较，失败保留在独立目录。
