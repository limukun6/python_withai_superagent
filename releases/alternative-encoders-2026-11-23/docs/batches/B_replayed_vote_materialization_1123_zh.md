# 补齐调度回放选中的 BGE 组合

新的“检查候选能否纠正领先模型错误”调度规则，在 E5、BGE 两次历史回放中均选择一个完整的双模型组合。两条回放的动作已冻结。E5 对应的整集双模型已实测 1,234/1,693。BGE 路径需要 4 次初筛、2 次成对复核及 2 次完整重训，在此前保留的工件中已具备 7 次，尚缺完整的 BGE 分类头。

据此追加一个独立的小批次。最多 1 次新拟合、0 次模型 API，使用原 6,608 行整集载荷。之前两条研究路径的 22 次实际拟合已经关闭，本次另计；若成功，跨批物理增量为 23。以两个新进程分别预测 BGE 和已冻结选择的 BGE 与 MiniLM 等权组合，在保存输入哈希、模型及所有预测后才核对开发保留区标签。报告与同训练量原十二层的逐题比较、5,000 次共享标题组配对区间，并列已有 E5 组合。该原型基于开发数据历史回放确定，成绩继续作为重复使用的开发估计。此次没有课程指定验证或正式测试安排。
