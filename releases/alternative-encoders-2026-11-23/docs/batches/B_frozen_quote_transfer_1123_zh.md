# 冻结的标题模型能否识别更容易被记住的台词？

两套模型均已在同一批 6,608 条标题数据上训练并冻结。比较 E5 + MiniLM-L12 与 E5 + 带训练语料词频特征的 MiniLM-L12，两者均为等权软投票。使用作者公开的 Cornell Movie-Quotes Corpus 中成对剧本台词。这个开发任务的标签表示被 IMDb 收录为令人印象深刻的台词。作者已按说话人、场景和长度配对。[语料说明](https://www.cs.cornell.edu/home/llee/data/) · [原论文](https://aclanthology.org/P12-1094/)

在推理前固定以下安排。

- 取作者发布的完整配对文件，双方均使用剧本中的原文。排除空白或经 Unicode 规范化、折叠空白和大小写后相同的配对。记录原始数、排除数、影片数以及与标题训练集的精确文本重合。
- 先按规范化文本排序，用影片标识、两边文本与固定盐 `quote-transfer-1123-v1` 的 SHA-256 确定谁在左侧。输入只含左右文本。单独保存行序、答案与电影分组。
- 每个模型在两个新进程中预测。核对模型和任务契约指纹、行序与预测文件指纹，再与答案对照。模型不调整，拟合 0 次，模型 API 0 次。
- 报告两者各自准确率、固定选左／选右基准、新模型独赢与独输条数。主比较用电影作为重采样单位，用 5,000 次成组 bootstrap 得出配对差和相对 50% 的区间。
- 属于新的公开开发任务。这次测量提供冻结预测器跨任务的证据。课程正式测试和组内封存任务继续保留到共同冻结后使用。
