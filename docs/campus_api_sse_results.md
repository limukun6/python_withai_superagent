# 校园 API 流式修复与验证

2026-11-18。SuperAgent 的公共实验客户端已改为 SSE，使用 10 秒连接超时和 60 秒读超时。客户端从内容增量拼接决策 JSON，从最终用量块读取输入与输出 token。响应截断时保留已知用量并拒绝决策。断流、读超时或用量缺失时停止后续付费调用。输出 token 上限及预算公式沿用原设置。

新增日志记录 HTTP 状态、收到的数据事件数、首尾数据事件的时间，便于区分等首包和响应中途断流。请求事件不保存完整请求内容。

| 验证 | 观察结果 |
| --- | --- |
| 本地测试 | 39 项通过，覆盖分段拼接、最终用量、截断与中途断流 |
| 无 API 基线（改动前、改动后各一轮） | 文本任务各完成 6 次训练，均选中 `word_char_C0.7`，重载验收通过。验证准确率均为 68.19%，验证预测文件 SHA-256 一致 |
| 同一短请求，Flash 流式与非流式 | 均返回预期 JSON，分别耗时 1.980 秒、1.944 秒。两次各记录 91 输入、34 输出 token，暂估各 ¥0.0001135 |
| 约 2,700 输入 token 的 Flash 长流式请求 | 响应读取过程中，69.05 秒处收到 `ChunkedEncodingError`，底层为 `ConnectionResetError(10054)`。最终用量未知，未补发 |

短请求通过了流式和计费校验。长请求超过了 60 秒才出错，但尚未验证超过 60 秒后完整返回；校园网、网关、服务端的重置位置仍需结合平台日志确认。此次长请求发生于新增计时日志之前，无法还原它的首尾数据事件时间。已知用量暂估总计 ¥0.000227，外加一笔未知用量。

同一时段运行的旧 Flash P0 保持原非流式代码。表格 `r` 的四次请求分别耗时 28.02、18.28、26.97、26.54 秒并通过用量与策略验收。随后表格 `f` 的第一次请求在 DNS 解析阶段报 `getaddrinfo failed (11001)`，批次按规则退出。事后的直连解析与 Python `getaddrinfo` 均得到校园地址 `10.121.10.250`，`GET /api/v2/models` 返回 200 并列出 Flash。DNS 错误与流式中途 reset 应分别排查，当前一次正常查询只代表复核当时连通。

## 对实验可比性的影响

训练、数据切分、决策规则和计费公式未改。旧批次采用非流式，新批次采用 SSE，两者的调用完成率、耗时、回退率应分开报告。正式 `r/f/o` 对照需要在同一批次冻结客户端版本和模型。
