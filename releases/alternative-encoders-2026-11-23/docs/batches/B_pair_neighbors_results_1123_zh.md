# 用其他标题的相似改动辅助 E5

新候选从每个训练标题组最多检索一条相关比较，将改动方向对齐，用最相近的 21 组投票。全程只检索当前训练折的标签，推理时没有共享标题跨折。邻居单独使用较弱，以固定 20% 概率与原 E5 混合时，四份训练内评估的正确数均小幅增加。

| 训练内范围 | 原 E5 | 单用近邻 | E5 加 20% 近邻 |
| --- | ---: | ---: | ---: |
| 首轮 18643，1,295 对 | 902 | 852 | 909（+7） |
| 首轮 40531，1,323 对 | 899 | 883 | 911（+12） |
| 互斥确认 A，814 对 | 572 | 535 | 576（+4） |
| 互斥确认 B，777 对 | 550 | 504 | 551（+1） |

两份确认与首轮评价没有共享标题组。合并后从 1,122/1,591 提升到 1,127/1,591，改对 33 对、改错 28 对，差 **+0.31 个百分点**，按标题组重采样的 95% 区间为 **−0.63 至 +1.27**。预先要求至少多对 8 对才进入主线组合试验，实测为 5 对。保留该研究结果。Task2 课程指定验证仍取原主线 689/940。[首轮登记及选择](B_pair_neighbors_1123_zh.md) · [首轮结果](../../research/b_pair_neighbors_1123/screen/results.json) · [追加确认登记](B_pair_neighbors_confirmation_1123_zh.md) · [追加确认结果](../../research/b_pair_neighbors_1123/confirm/results.json)

两次首轮及共同确认共建立 3 个使用标签的索引，均计入实际监督拟合。构建冻结 E5 方向表处理了 11,505 个训练标题、259,828 个本地编码器输入 token，此数只含该方向表。原 E5 分类头均复用。两轮新增模型 API 请求及费用均为零。[向量和计量回执](../../research/b_pair_neighbors_1123/screen/encoding.json)
