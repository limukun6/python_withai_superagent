# 在两个 Released 任务实测同类方法的首次参数选择

上一批在完整重放的 93 条真实决策中，找到 4 条路径的首个参数选择会改变。优惠券和两份标题划分都在第 3 步出现分歧。接下来检验这些变化是否走到最终交付。

**标题（B-ROUTE-02）** 使用先前登记的 45101 与 45102 两份训练内留出、逐行优化分区和完整 23 项候选菜单。A29 原策略的两个真实对照已在同源程序和依赖下运行，可复用，先核对实际训练、模型、动作、两份导出和环境身份。新策略每份划分仅运行一次，最多新增 22 次真实拟合（每路径 11，含全量重训）。两份新模型全部冻结后，才读取留出标签。对每个新模型核验两次独立进程预测，报告双方答对数、双方各自独有的正确数，以及第一个变化如何影响后面的选择。

**优惠券（B-ROUTE-03）** 使用原登记 45101 划分，再从同一经过核验的仅训练包按 45102 固定另一次分组留出。两条策略均采用 A29 同一运行框架。每个划分都实跑两条路径，45101 先原后新，45102 顺序相反。每条不超过 11 次实际拟合含重训，两份划分共至多 44 次新拟合。加上相同的全菜单、分区、种子、环境、1,200 秒总时间和 300 秒每次尝试上限。预先固定主指标准确率。四份模型全部冻结后再评分，并逐行比较两种策略各自答对了哪些样本。两次划分可能包含重叠行，各自报告，不合并为独立样本。

程序不读任务名来选参数，固定全局首个方法，Agent 依据当次训练反馈继续决定探索、复核或停止。每组仅切换 B 调度文件，保留相同的内层验证和交付规则。不论效果上升、下降或不变，均登记结果。上述研究全程本地，课程正式验证、测试和两份 H 继续封存。
