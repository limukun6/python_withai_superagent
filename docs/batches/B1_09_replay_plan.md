# B1-09 · 用真实动作分歧检验反馈是否影响下一步

使用 B1-07 的标题和 B1-08 的另外三个任务，共十六条已完成路径。固定为各任务的两个预登记划分，全部纳入。只读取当时留存的行动前状态、内部划分及执行记录。新增训练、模型预测、外层评分、模型 API 的预算均为零。

1. 在原目录的训练输入上核对文件、生产源码、候选和分区指纹，用当时的真实标签和分组重放本组的所有动作。包括停止动作，六个字段必须与正式入口实际执行的动作完全一致。
2. 同一任务内比较两个真实动态路径，从第一次探索开始对齐实际操作、候选与划分名，只取首次分歧。若从头到尾选择相同，记录无分歧。
3. 如果首次分歧之前的动作、可用候选、主指标契约与预算计数一致，分别保留两边的任务、剩余训练名额和时钟，将完整的训练内观测及其对应的可信行和分组换成另一边那一份。每一份观测必须单独通过真实分数和行指纹的生产检查，绝不跨分区乱拼标签与预测。双方向均记录下一动作。若控制项不同或任何核对失败，该任务标成不可作此比较。
4. 同时列出每个划分固定组和动态组首次在同一决策前缀采取不同动作的位置。只解释已观察的分歧。重放不会生成后续训练结果，也不估算改用另一动作后可能得到的外层成绩。

结论将区分三件事：候选由开发者预先实现，控制器可根据真实观测选择下一步，最终得分由另行冻结的实跑给出。
