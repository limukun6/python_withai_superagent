# BP-03 · 相同登记行在两套环境中产生相同的 2,174 个预测

将 BP-02 固定的 Dry Bean 行号交给正式本地动态入口，两套本地 Python 环境各自完成一次探索、一次最终重训。两边阅读了相同顺序的训练与内部评估样本，自主选到相同的 C=0.1 逻辑回归。首轮内部 1,745 行预测相同，冻结后再次用本环境的新进程分别导出 2,174 行无标签预测，两个导出文件逐字节相同。

| 检查项 | 实测结果 |
|---|---|
| 环境 | Python 3.11.15 / scikit-learn 1.7.2；Python 3.14.7 / scikit-learn 1.9.0，均为 macOS |
| 动作与候选目录 | 两次行动的全部字段相同，共同目录摘要相同 |
| 三份内部分区 | 行、标签指纹相同，各自产生的文件也与该环境此前登记的工作文件摘要相同 |
| 最终训练模型 | 两个文件的字节摘要不同，各自模型均通过本机校验 |
| 导出 | 2,174 对标签中 0 处分歧，行序一致 |
| 资源 | 每环境 2 次真实拟合，合计 4 次；0 次模型 API |

B 提供的实验入口为 `python -m tools.ab_registered_run --split-manifest FILE --split-sha256 DIGEST -- run ...`。它将已校验的行号接到 A 的分区写入函数，调用 A 的正式命令处理器。生产 CLI 的实现归 A 维护。本次只验证两个本地环境的训练与交付，未读取外层标签或计算新准确率。Windows 的同协议实跑仍需队友执行。
