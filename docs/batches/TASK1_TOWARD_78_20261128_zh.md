## 3 必须说清的一个统计学事实

指定验证是 **2,030 行**。在 p≈76.3% 处，单次评分的标准误：

```
SE = sqrt(0.763 × 0.237 / 2030) ≈ 0.94pp
```

也就是说：

- 78% 相对 76.31% 是 **+1.72pp ≈ 1.8 个标准误**；
- 一个**真实水平仍是 76.3%** 的模型，单次评分落到 ≥78% 的概率约 **3.6%**；
- 如果我们继续试 **30 个**变体、每个都在验证上评一次并保留最好的，那么**至少有一个碰到 78% 的概率约 67%**。

**换句话说：只要不停地在验证集上试，我们几乎一定会"达到 78%"——但那只是挑选噪声，不是方法变好了。** 这正是我们反复强调的"不许用验证集做选择"的边界。

**选 A，并把这段统计学写进报告。** 一个"我们试了 14 族方法、每个都在配对折上验证、没有一个超过 0.3pp，所以我们不声称提升"的结论，比一个靠挑选噪声得到的 78% 更有说服力——尤其课程明确说会抽查记录。
