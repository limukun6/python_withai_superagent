# BV-03 · 灰度手写数字会让 Agent 保留哪条路线

花卉实验表明下游编码器在一类彩色照片上可被自主选中。此次在已公开结果的灰度手写数字开发数据上，检验同一控制器有机会测试编码器时如何决定。这是 B 的可选方法资格验证。A 的图像 Q 及正式 C1/H 有独立登记。

使用 scikit-learn 自带的 1,797 张 8×8 图片。原始文件无需下载。沿用 A11 的 1,437 个训练和 360 个留出位置，核对 A 归档中的来源指纹和有序留出行指纹，三个内部划分直接采用归档的实际索引。先用接近 A 版本的 Python 3.14 环境恢复外层行号，必要时取 3.11 已安装环境核对同一摘要。只有匹配的原划分可以训练。两个环境均无法复原则保留失败，无替代种子。[数据说明](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_digits.html) · [原始项目](https://archive.ics.uci.edu/dataset/80/optical+recognition+of+handwritten+digits)

将 0 至 16 的 17 个灰度级映射到 0 至 255 的 8 位灰阶并逐像素检查可逆，在两组中都使用相同的 8×8 无损 PNG。正式解码、首候选、原有八个方法、动作规则、训练行与预算完全一致。先原目录，再让同一 Agent 额外看到已登记的冻结 MobileNetV3-Small。每组最多 11 次实际监督拟合、1,200 秒、零 API；整个小批最多 22 次。CPU 推理，模型资源已在本机。

先封存协议，再让两组分别自主探索、复核、选模、重训。全部模型封存后，统一核对新进程与目录搬迁的预测，再对事先登记的 360 行评分。报告编码器是否真的被探索、首轮得分、最终选型、逐行得失、时间及实际拟合。保留任一方向的结果；单个已见划分不能证明普遍策略收益。
