# BQ-01 · 四种真实任务的候选目录对照

同一台机器、同一外层留出和同一动态调度下，每个任务只改变启动时开放的方法。每条路径自行选择、复核、停止和重训。八个模型封存后，分别在原目录和搬迁后的目录启动新进程，两次导出的逐行预测字节均一致。训练前 88 项协议核对通过。本批以 `47fe1ec` 注册的方法、数据与协议运行，是当前开发版本的结果。

新增候选在三个适用任务都由调度器选作第二次探索。优惠券最后从普通 CatBoost 变为带类别字段组合的 CatBoost，净多答对 23 条（+1.41 个百分点）。标题从词字符和文本统计变为本地冻结 MiniLM 加词法特征，净多答对 39 对（+2.33 个百分点）。这两个差值包含开放新方法后整个搜索路径的变化。

SMS 两组最后都选了词字符线性模型，同样答对 811/825（准确率 98.30%）。扩展组试过 MiniLM，花的时间多约 18 秒。Dry Bean 在本批的内存限制下有五个可用候选，两组目录相同，动作顺序、赢家和每行预测均重现。上表用不同主指标逐任务比较。

全批共 79 次实际分类器训练，含 8 次最终重训。墙钟约 287 秒，包括分区准备、八条路径与交付核对。真实模型 API 请求 0 次，本批新增 API 费用 0 元。机器上的 403 项回归用例全部通过。第一次全库检查中，旧用例把新增的三个对称方法计入了历史方法数；保留了原有 43 个方法的位置检查，并增加了新方法及有权重时才出现的编码器顺序检查。

每个任务仅有一个目录对照划分。标题与 B1-05 使用同一批 1,672 对，其分数在本机重现。A-10 与本机的 Dry Bean、SMS 重建包、主划分行号及样本载荷指纹不同。课程官方验证集、测试集与 H1 均保持封存。团队最终矩阵待部署版本共同冻结后执行。
