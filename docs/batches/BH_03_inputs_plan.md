# BH-03 · 将 H2 已登记的训练区接入正式图片读入器

此批仅制作优化器的训练输入。沿用 BH-02 固定的两组原图、原行序、类别及各组三份共同内部分区。两次各读取 2,500 张训练地区的原图。留出地区的 1,000 张图片只核对既有登记清单的文件名，与训练名单必须互斥，不读取或解码这些留出图片。地理测试清单和图片成员均不使用。

以匿名文件路径和原类别生成 A 直接可读的 JPEG 训练包，按原要求使用 64×64 RGB。核对 A 解码后每张图与相应登记源 JPEG 的像素，对齐训练标签、位置、内部分组和行指纹。保留数据来源与署名。将三份内部分区转换为 BP-03 已经实际使用过的登记清单，并用 A 的真实分区写入函数核查最后生成的工作文件。

此批只在固定格式上验证数据通路。模型拟合、模型特征提取、预测、模型选择、性能评分及 API 上限均为零。部署策略仍由双方在开发实验结束后冻结。
