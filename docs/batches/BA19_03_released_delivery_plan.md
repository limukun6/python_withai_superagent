# Released 两个任务在 A19 上的自主选型与预测交付

使用 BA19-02 已核验、只含原训练数据和 README 的两份课程训练包。按 BQ-01 已发布的外层行号与三个训练内分区重新取样，每个原生训练输入保留原始字段、顺序、标签语义和 README。优惠券保留原值和数值型缺失，标题保留两列的原始身份。训练内留出另制仅特征文件。任何课程发布的验证和测试成员均不进入处理。

A19 对带 README 声明的老版标题包能够选择合法方法。实际从其训练集取 31 对制作无标签 CSV，交给相同的读取接口时触发 input_format 缺失。保留 A19 原版并在独立候选分支提出兼容修复，核对源码、任务说明、旧格式和带正式 manifest 格式的读取行为。提交给 A 评审。任务语义和正式 manifest 的校验保持一致。用真正重训后的模型在新进程完成最终验收。

两任务各做 baseline/full 一次。用同一版本正式 AB 动态入口、按能力开放的方法、已固定本地 MiniLM、老师原 README 和已有内部分区的行号。每路径 11 次物理训练含重训，1,200 秒，每次 300 秒。本批总计最多 44 次，0 模型请求。顺序为优惠券 baseline、full，标题 full、baseline。两组均独立决定探索、复核、停止和最终重训。固定行号和种子，出现路径失败原样保存，不按成绩补跑。

四个模型都封存后，对每个原路径及搬迁目录各用一个新进程导出，用训练内留出的标签计算准确率、每组的新增正确和错误数、用时、训练次数及实际选中者。将本批独立写为接入和复现实验，只与同一任务同一留出内的模型比较。既有 BQ-01 曾在优惠券读入后统一转为文本，旧分数只作历史参照。正式 C1 保持等待共同冻结。H2 两份登记保留。
