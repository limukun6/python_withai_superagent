# 相似的标题改动，能否帮助判断哪一边更容易被点击？

保留 E5 原分类头。新候选检索当前训练折中的成对比较：先用冻结 E5 分别表示两段文字，再对两侧的向量差做单位化。若两个比较的向量差方向相反，则反转邻居赢家的方向。设定完成后才读取新预测成绩。

- 按两个方向向量的余弦绝对值排序，每个共享标题连通组至多取一项，共取前 21 组。同分保持训练行顺序。用余弦的平方作为邻居投票权重；零方向或零总权重时给 0.5。单独计量近邻候选，并将其概率以固定 20% 权重加入原 E5 的概率。权重和邻居数均只取一个值。
- 首轮沿用已核验的种子 18643、40531 真实 E5 首轮训练划分和原预测。冻结编码器按标题独立计算，允许复用同一标题向量；索引候选只接收对应折的训练标签和训练组。按监督拟合收费口径，每建立一个使用标签的近邻索引计 1 次实际拟合。每折只建一个索引，模型 API 0 次。
- 先验收两边互换时概率互补、无训练标题跨折、旧 E5 回执的预测／行号／标签哈希一致，包含共享标题的多个训练比较最多投一票。分别报告单独近邻与 80:20 组合的正确数、改对和改错、分组区间。
- 组合在两个首轮都未退步且至少一轮净增 5 对，才进入此前登记的两个互斥确认区。两个确认区共用一个训练集和固定索引，可复用普通 E5 的既有拟合。若不通过则保存负结果。此次不打开课程 940 行、正式测试或 1,693 行研究保留区。
