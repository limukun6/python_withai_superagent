# 把单次推理的偏好概率修正接入冻结交付

在独立 B 实验分支上，把 B-TEXT-KERNEL-08 已验证的输入排序与方向映射做成可序列化的偏好输出适配器。只接收已签名、已拟合的二分类偏好模型，要求任务契约显式说明左右含义。保留原分类器、特征和拟合记录，将原指纹及新的输出规则写入独立目录；普通 A 入口和原模型都保持原状。已训练模型在每次非空批次只做一次概率计算。相同文本各 0.5；对严格相等的不同文本概率，用固定字符串顺序作稳定的标签平局处理，交换后结果反向。

用两个已登记的真实标题模型分别通过项目原生 predict 接口、在原导出和搬迁后的新进程执行。对全部既有无标签行验证原向标签、反向标签、双向概率、相同标题、行序和分批。原始模型与新交付物的校验值都保留。另以无需训练的定值预测器检查精确平局及 Unicode 文本。零新增训练，只执行明确无拟合的检查，原成绩不重命名为新自主训练结果。
