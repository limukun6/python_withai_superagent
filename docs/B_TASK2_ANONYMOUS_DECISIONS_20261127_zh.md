# 普通入口的自主选模与换名复核

当前可交付版本从 Task2 课程原包启动，训练阶段读入任务说明和 8,301 条训练记录，首轮有 68 个可选动作。Agent 独立进行了 9 次探索，保留最后 1 次训练在全量训练集上重训 GTE-base。发布验证集 **700/940（74.47%）**。在新目录离线重载后的 940 行预测与上一交付逐行相同，本次评分直接复用原来封存的成绩。运行和验收均使用本地计算，付费模型 API 请求 0，费用 ¥0。[评分与完整试验顺序](../research/paired_encoder_search_1127/anonymous_score.json) · [可移植交付凭据](../research/paired_encoder_search_1127/anonymous_portable.json)

## 模型怎样决定

开发者提供可调用的软件、公开预训练权重、计算预算及通用决策规则。运行时，Agent 从本机已有工具和任务契约生成可尝试的方法，部分分类器及参数按数据生成。首轮依据数据规模、特征性质等作出初选。有训练结果后，候选相似性、实测成绩、尚待解释的错误和剩余重训次数会改变下一步。下列普通命令只传入运行所需的文件。[启动参数](../research/paired_encoder_search_1127/anonymous_launch.json)

~~~sh
python -m unified_agent solve <任务包> --weights-dir <通用模型目录> --run-dir <新运行目录> --prediction-input <无标签特征包> --output <预测CSV>
~~~

在前一版中，预期收益完全相同的候选会按显示名称的哈希值排序。Task2 第 3 步有两个候选平手，第 6 步有六个。在冻结反馈上仅替换显示名称，两处都可触发改选。当前版本按实际执行配置处理平局；执行配置相同且已有测量时，也利用同一行序上的预测来区分。新一轮第 6 步自行探索了随机森林，最后仍选择 GTE-base。开发者可拓展工具目录；这个接口支持已实现的模型或运行时可组合的分类器。[旧版平局与新版逐步记录](../research/paired_encoder_search_1127/anonymous_decisions.json)

## 两个能把“按证据做决定”说清楚的试验

| 验收场景 | 真实行为 | 三套匿名名称并倒排目录 |
| --- | --- | --- |
| Task2，普通训练预算 | 9 次探索、停止，全量重训；真实训练共 10 次 | 10 步 × 3，选中的方法、动作和训练划分 30/30 一致 |
| 已公开的十分类图像开发任务，训练上限 16 次 | 8 次探索、4 次确认、停止，最终重训极端随机树；真实训练共 13 次 | 13 步 × 3，选中的方法、动作和训练划分 39/39 一致 |

将 Task2 最后两名领先者的**真实训练反馈互换**，保留候选、预算及配置，选中的方法由 GTE-base 换成 GTE-small。这是对决定的干预，正式成绩取自未作干预的真实运行。图像任务中，Agent 在两份训练划分上的 440 个验证位置选出极端随机树，答对 369 个（83.86%）。它另外预测并独立重放了 350 行无标签图像输入，外部图像成绩未评估。上述范围覆盖这两个任务的本地自主流程。课程正式测试和 H2 保持封存。[图像确认与重放](../research/paired_encoder_search_1127/anonymous_image.json)

Task2 使用相同核心工具、较大训练预算时，运行可以依据多个分组的证据选择融合。上一交付的普通大预算组实际训练 25 次，最终选 GTE-base 与 GTE-small 等权融合，发布验证集 693/940。预算差异与候选目录差异均保留在历史对照中。[原始五组对照](B_TASK2_AUTONOMOUS_DELIVERY_20261127_zh.md)

## 扩大预算后的普通入口

在相同的通用资源目录、原始训练包和预测输入上，把上限改为 28 次拟合及 3,600 秒。模型、组合、调度模式均由 Agent 自己决定。它用 25 次拟合完成 15 次探索、8 次确认、一次停止和最终双模型重训。两个确认划分各复查四个候选，最终留下 GTE-small 与 GTE-base 等权融合。24 步分别换三套匿名标识并逆序展示，72 次均选择相同的动作、成员和划分。加上前述普通预算和图像运行，三次完整轨迹合计 141 次。

独立进程重载后，940 条预测逐条与先前扩大预算的交付相同，复用其已封存的 693/940（73.72%）。普通预算交付继续为 700/940（74.47%）。本次模型 API 为 0，课程验证标签无需重新打开。
