# 统一基线之后的标题分歧对照

原始包的两个基线模型冻结并重新验分后，才启动此实验。待测规则固定一次。双模型在一题上的类别相同则采用该判断；两者相反时，比较各自置信度在其训练内确认预测中的百分位，选百分位较高者。每个模型的置信度为正类概率到 0.5 的距离；经验分位取并列区间中点，百分位完全相同则保留原等权预测。第一个共同的独立确认划分用于估计分布，全程不按标签学习新参数。若原生执行器未选两个成员，此检验记为不适用。

在原始包入口自动保留的 1,693 对标题上先冻结两份输出，再按原始训练答案比较。登记双方分歧数、改对数、改错数、净变化和按共享标题连通分量计算的 2,000 次配对重抽样 95% 区间，种子 28113。门槛沿用净增至少 5 题且区间下界大于零；通过时另开自主端到端验证。这个实验共用已研究过的训练留出，仅作开发。新增模型拟合和模型 API 调用均为零。

## 错误分布

同一份冻结输出同时统计两成员一致却答错的题数，以及两成员分歧且原等权预测答错的题数。前者的改进需要至少一个成员改变预测，这个统计不影响上面的晋级判断。
