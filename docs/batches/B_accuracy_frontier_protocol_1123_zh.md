# Task2 同目录调度与冻结模型改进协议

输入限于上轮已冻结的匿名任务记录和 Released Task2 的 train.csv。本轮不新增监督拟合，不调用模型 API。开发阶段和保留区阶段分别封存逐行预测，再读取相应标签。已有项目成员见过开发保留区的历史成绩，本轮仍按开发研究报告。

## 同一目录

只开放两版都能比较的三个单模型，即词法、六层 MiniLM 和十二层 MiniLM。统一使用上轮组件路径这三个模型在相同 1,372 行的逐行预测及其源文件校验值。原版使用仓库的 ab_scheduler.next_action 与 selection_evidence，按需提交每个动作的证据。新版使用原组件路径的共有错误门槛、探查与复核分组、预算及总正确数选模规则。用运行记录核对这些规则在原八候选实验的选择。原调度如果索取没有对应训练划分的复核记录，记为无法完成回放。各侧只接触已请求的候选反馈。两侧最终均选择同一旧模型时，引用其已冻结交付成绩。回放计数与实际新增拟合分别报告。

## 两项模型假设

1. 稀有词及字符片段的权重可能随措辞变化失效。对已训练的十二层线性头，使用原 TF-IDF 的 IDF 及其真实拟合标题数还原各词和字符片段的文档频数 df，乘以 df/(df+4)。4 为原最低词频 2 的两倍。风格、语义分量及截距按原公式计算。每个分区均以同一模型的原预测作配对对照。
2. 两次不同共有标题分组下得到的十二层模型可能有互补错误。按原始样本行号对齐，每行只使用两个在训练时均未见过该标题组的模型，将其点击偏好概率等权平均。与两套划分各自的整套折外预测比较。各折保留的十二层模型有完整重训及保留初筛模型两种来源，如实列出。保留区的组合取两套划分中第一个双方均保存了完整重训十二层模型的同编号折，用两个冻结模型做预测。

两套五折分区均覆盖同一批 6,608 行。假设一要求两套划分各有正增益且平均至少提高 0.20 个百分点。假设二要求等权组合比两套折外单模型中较高者提高至少 0.20 个百分点。同一训练行跨种子只算一行，配对区间按共享标题组重采样 5,000 次。两项均过门槛时，比较相对各自对照的开发增益，只核验增益较大者，完全相同时优先单头稀有词方案。不以子组结果或置信区间追加变体。

达标后才评所选方案在 1,693 行开发保留区的成绩。稀有词方案与完整开发集重训的原十二层头比较。双模型方案同时与各自的单模型、完整开发集重训的十二层模型比较。只有严格超过上述对应对照，且比既有最强冻结方案的 1,231 对至少多答对 4 对，才使用该原样方案核验一次 940 行课程验证。正式测试与 H1/H2 均不参与。没有过门槛的路线可分析错误重合与前景，不改权重或阈值重复试同一保留区。
