# 同一入口的六种匿名任务路由验收

用确定性的小任务检查新版可选策略从统一 train 入口能看见什么。六类为数值表（二类 ROC AUC，正类 0）、混合表（三类 macro-F1）、单文本（二类 accuracy）、图像（三类 macro-F1）、交换不改标签的对称文本、交换会翻转标签的左右偏好。每份使用两种包文件名，传入相同内容。正类、指标及成员资格须由包本身决定。对偏好包再测试缺少一个可选权重、缺少必要参考权重，以及候选遍历顺序倒置。

在真正启动第一个拟合之前截取通用执行器或偏好策略的状态。记录任务声明、实际目录、选择了哪个执行器及是否一致。分类器拟合和模型 API 的预算均为零。这批只检验入口分流。偏好小包的完整训练与跨进程预测另有独立实跑，其他五类不从此次路由检查认领精度。
