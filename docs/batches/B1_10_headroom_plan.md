# B1-10 · 把训练内候选差距按任务主指标重算

使用 B1-07/08 已经完成的四个开发任务，全部纳入。每任务使用已登记的 45102、45103 两份开发划分，两种调度的真实训练记录，以及各自 primary、confirmation_1、confirmation_2 的逐行证据。新增训练、模型预测、API 和外层评分预算均为零。只重算原来确实执行过的观测；保留每次比较覆盖了哪些候选和哪些行。

1. 核对原登记的代码、训练输入、候选、行序、真实标签、实际分区文件及预测摘要。每条成功观测都要按任务声明的主指标重新计算，并与当时的主分和 accuracy 交叉核对。固定和动态两组都试过的同一候选、同一分区，只有配置、预测与样本都一致才可合并。
2. 对每个分区给出已测候选的主指标排名、accuracy 排名、两种排名的并列第一、最好与最差的差值。报告与登记候选全集的覆盖差距。确认分区单独列，缺测不填。两个外层划分及三个内部划分的结果不混成一个样本量。
3. 逐行比较两条完整路径实际最终选择的模型在共同内部划分上的历史预测。报告答对互换数与主指标变化；短信按固定类域算 macro-F1，使用生产调度中相同的 128 次分组配对自助重采样报告差值标准差。选择时用过的数据仅作诊断。
4. 在每份 primary 的已测候选上计算逐行可修复错误和所有候选共同错误。对二分类任务，按“只要其中一个猜对就取真实类别，否则取共同错误类别”计算理想逐行选择的主指标。其余任务只报对错计数。此数需要真实标签，不作为可部署模型、泛化预测或可获得的准确率。

只在两个开发划分均出现同一已测替代候选，在至少两个共同内部划分上超过当时动态组所选方法，且共同划分平均主分差至少 0.002 时，标记可复核的选型遗漏。汇总说明是已经测到更好替代、已测方法出错高度重合，还是证据不足。不得按这次排名改动已封存的模型、候选、策略或 H 的协议。研究脚本原有的单个 accuracy 的二项标准误不再用于判断候选分差。
