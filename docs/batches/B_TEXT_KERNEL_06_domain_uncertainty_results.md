# 一整种评论来源留出后，提升有多稳

对三种来源各 1,000 条已经冻结的成对预测，按相同文本归组，抽取 4,000 次。电影来源共有 997 个文本组，macro-F1 的提升为 1.70 个百分点，95% 百分位区间为 +0.85 至 +2.66。准确率提升 1.60 个百分点，区间为 +0.80 至 +2.50。商品来源 987 组、餐馆来源 996 组，双方本来就逐行同预测，两个指标的差值和区间端点均为零。

电影来源提供了新增候选改善一项跨来源预测的证据。区间仅描述这对固定模型在该批电影样本上的抽样变动；其他领域与重新训练后的表现仍各自需要证据。复算逐项核对了源文件、行序、原预测及成绩，新增训练、模型预测和 API 均为零。[成对估计与区间](../../research/b_text_kernel_domain_uncertainty/results.json) · [六条原实验](B_TEXT_KERNEL_05_domain_transfer_results.md)
