# 加 val 训练到底值多少：两折一致 +1.33pp

2026-11-28。回答"把 val 加进训练能不能补上 2%"。实验**不使用正式 test**：从 train 里切出与 val 同规模（约 2,030 行）的假测试集，两臂评价行完全相同，唯一差别是训练集里有没有 val。**4 次物理 fit，0 API。**

## 1 设计

```
train 8,117 ──4 折分组划分（种子 907）──→ 留出折 ~2,030（假测试集）
                                         其余 ~6,087
   臂 A：其余 train 训练
   臂 B：其余 train + 全部 val (2,030) 训练
两臂都评在同一批留出行上
```

## 2 结果

| 折 | 留出行 | 臂 A（仅 train） | 臂 B（+ val） | 差值 |
|---|---:|---:|---:|---:|
| 0 | 2,033 | 0.748155 | 0.760944 | **+1.28pp** |
| 1 | 2,027 | 0.764677 | 0.778490 | **+1.38pp** |
| **均值** | | | | **+1.33pp** |

**两折都为正**，且幅度接近（1.28 / 1.38），这是本会话所有实验里唯一稳定的正效应。

## 3 和之前所有方法对比

| 方法 | 效应 | 折间一致性 |
|---|---:|---|
| **加 val（+2,030 行）** | **+1.33pp** | **2/2 一致** |
| 外部三列 | +0.29pp | 1/3 |
| ctr 复杂度 4 | +0.22pp | 1/3 |
| 种子袋装 | +0.16pp | 1/3 |
| 阈值（事后上限） | +0.58pp | 1/3 |
| 其余十五族 | ≤0 或更差 | — |

学习曲线此前的投影是 +1.2pp（区间 0.6–1.8），**实测 +1.33pp 落在区间内**，两条独立证据互相印证。

## 4 能到多少

| 版本 | 训练量 | 预期 |
|---|---:|---:|
| 当前冻结版（train only） | 8,117 | val **76.31%**（实测） |
| 加 val 版 | 10,147 | **约 77.6%**（+1.33pp） |

**换句话说：能到 77.5% 上下；离 78% 还差约 0.4pp，而这 0.4pp 落在 2,030 行评分的噪声范围内（标准误 ≈0.94pp）。**

「能不能到 78%」的准确回答是：**加 val 后 78% 变成"可能但不可保证"，而不是"不可能"。**

## 5 给队友的结论

1. **值得做**：+1.33pp 是唯一被两折同时验证的正效应，量级是其他所有方法的 4–8 倍；
2. **代价**：val 参与训练后，`76.31%` 这个数字只描述旧的 train-only 版本，交付版必须用正式 test 一次性评估（或在报告里标注"无独立验证"）；
3. **不要再在 val 上选模型**：一旦 val 进了训练，任何"val 提升"都不再是证据。

## 6 边界

- **正式 test 未被读取**：本实验只用 train 内部划分 + val 作为额外训练数据；
- val 在这里的角色是"额外训练数据"，不是评价集；
- 4 次 fit，0 API，可复算：`research/task1_val_augment_01/val_augment.json`。
