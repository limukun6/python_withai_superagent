# 将近似标题放进同一评价组

重划后概率提名只多答对 4 题。对现行划分的无标签审查又发现两套划分各有 266 和 249 个评价行与其当折训练内容近似。为后续实验增加可显式选择的文本对分组方式 `near_text`。沿用事先登记的词对 Jaccard 0.80 定义，并保留共享完整标题的连接。生产实现用低频词对优先的前缀索引，最后对候选计算精确交并比。统计脚本保留独立的全倒排实现，以便检验漏配。两列输入的任务均可选择；其他模态沿用原有的精确特征分组。

验收分三步。先在含 Unicode、全短标题、传递关系、乱序行和相似度边界的构造例上对比穷举结果。再在原 6,608 个开发行上要求每行与独立审查器具有相同的组标识，两者应得到 4,737 个组；用五个事先指定的分组分层种子 41101 至 41105 走常规划分入口，任一连接组跨训练和评价两边即验收失败。最后在匿名构造的成对文本包上跑普通 benchmark 命令，搜索与复核都选择新模式、一个本地候选、三个复核划分并复用搜索的首个结果，最多三次本地实际拟合。记录真实子进程拟合、使用的组和评价行。课程指定验证、正式测试和付费模型 API 均不启用。此变更改进后续比较的可解释性，本项不申报准确率提升。
