# 按情境难度校正历史回答

上一批把画像、情境和各种交互直接放入正则逻辑回归，三折平均比现有树低 1.50pp。历史接受率也会把两种原因混在一起：有些人常遇到人人都容易接受的券，有些人对同等难度的券更愿意接受。本批只学习扣除一般接受概率后的偏差。

固定使用三个 112801 训练内评价折。每折重跑情境树对照，并拟合一个去掉画像 token 的旧字段交叉树作为总体预测器。在拟合侧将整个画像分为三个互斥组，另训三棵交叉树，给每条拟合样本产生来自其他画像的概率。按训练侧最相关的情境字段估计“画像总体偏移 + 此画像对此类情境的额外偏移”。根据同一画像的已有回答，用带高斯先验的逻辑似然估计这两个偏移，共用固定先验标准差 0.75、1.25。新画像回到总体预测。分别测总体预测、加偏移、加偏移与原情境树的固定等权概率融合。行号、列名均不参与模型选择。

基线、全量总体树、三个画像外折预测器共每折5次监督树拟合。另报每画像一个有标签的偏移估计数，这和树拟合开销分别列出。本批开发对照不占用正式 Agent 路径，若有收益仍需核对整体计算成本才能接入。3折15次树拟合，CPU 预计 2–6 分钟，0 API。记录逐行改对/改错，情境基线哈希须与本次前批一致。

晋级限于加偏移及其融合，平均 ≥0.5pp、两折以上为正、最差 ≥−0.5pp。还要求偏移模型累计优于总体预测器，才能把改善归于历史校正。若晋级，另在后两折做一次确认；否则封存开发结果。本批仅访问训练包内 C_train、y_train。
