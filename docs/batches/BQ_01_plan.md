# BQ-01 · 四个非图像真实任务的共同候选目录

本批执行共同计划 Q 中 B 负责的四个任务。类别表格用 Released Task1 原训练特征和标签，标题偏好用 Released Task2 原训练 CSV，数值表格用 UCI Dry Bean，单文本用 UCI SMS Spam。UCI 原始数据包按仓库已登记的 SHA-256 校验，并使用同一个既有转换脚本。课程验证和测试均封存。UCI 也只从转换包的训练集再划外层。类别、数值、标题的主指标为 accuracy，SMS 用 macro-F1。[UCI Dry Bean](https://archive.ics.uci.edu/dataset/602/dry%2Bbean%2Bdataset) · [UCI SMS](https://archive.ics.uci.edu/dataset/228/sms%2Bspam%2Bcollection)

每个任务在同机同版本上做两条真实自主路径。原目录提供共同的既有可执行方法。扩展目录另外开放按契约和本机资源合法的 B 方法。共同方法必须保持顺序和元数据完全一致。数值表格若两个目录相同，仍独立跑两次作为可复现性对照。两组均使用同一个动态调度、同一首选规则和最终选型/重训、同一已校验的本地 MiniLM 环境。唯一实验开关是启动前注册的候选集合。

外层种子 45101，内部 707、808、909。相同标题分组，其他类型按共同去重规则分组。训练前登记任务包、原始训练文件、实际行号、源码、环境、能力目录的指纹。用四个不同任务成块顺序运行：优惠券先原后扩、标题先扩后原、Dry Bean 先原后扩、SMS 先扩后原。每路径最多 11 次实际监督拟合含重训，合计不超过 88 次。每路径墙钟 1200 秒、每次训练最多 300 秒，API 上限 0。失败保留，不自动重跑。

八个模型封存后统一评分。报告每个任务的主指标、训练集多数类参照、原与扩展目录的逐行预测变化、实际拟合次数、时间、强方法是否进入候选／实际尝试／最终选中，以及新进程迁移后预测是否一致。多数类类别由优化训练输入的频数决定，平票按类别顺序，不额外训练分类器。宏 F1 按整个外层重新计算。不同任务的指标分别解读。

A-10 的 Dry Bean、SMS 作为环境核对来源。本批会列出原包与内部分区是否与 A 相同，禁止用不同机器或划分的绝对成绩代替本批配对结果。已有 B1-05 的标题分数仅作历史开发记录。本批预注册的是四任务开发对照，课程正式评测和 H1 均不启动。

运行器为 `python -m scripts.run_bq_01_portfolios --help`，支持零训练预检与跨机参考协议核对。原目录与扩展目录均通过真实 A 控制循环和训练前准入计数执行。
