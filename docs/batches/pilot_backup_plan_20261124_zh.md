# 首选未过复核时，Agent 应不应该给第二个候选机会

上一批十条路径的选择已冻结。其第 5 折两个提名器分别提名了 RoBERTa 和 MPNet，在只看训练的独立确认区净变化为 −3 和 +15。此时还未打开上一批外层成绩。登记本次独立改动：允许 Agent 预先提一个备选，当首选没有得到第一块复核区支持时，转而把备选交给一块双方均未用于作决定的评价区。对照关闭备选，其余完全相同。

试用头、两个参考成员、四个候选、提名区与 `pilot-accuracy` 完全一致。在读取两块复核标签之前，根据提名区净改对、概率改善和名字排列首选，首选净改对须为正。备选在剩余候选中按概率改善减一个组标准误、净改对、名字排列，须净改对与保守概率改善同时为正。对原确认区按 `pilot-backup-check-v1/` 加标题组的哈希排序，偶数位置为第一复核、奇数为最终批准；各需两个类别、至少四个独立组。首选在第一复核净改对为正且 Brier 改善为正时送入最终批准。否则开备选的一组递交先前已登记的备选，关闭备选的一组恢复参考模型。最终批准对所有入围者使用相同条件：净改对至少 max(2, ceil(0.002 × 最终批准行数)) 且 Brier 改善为正。未达标时交付参考模型。任何时候都不能按最终批准标签另换候选。

两组均启动真正的统一训练入口，记录提名、第一复核、递交最终批准者及交付的模型。每折先复用上一批两个策略相同试用或重训身份的分类头，再按需做至多一次新的最终分类头拟合；由于首选通过时两组同选，首选未通过时只有备选组可能接纳，每折只会产生一个新选第三成员。五折额外最多五次，匿名小包额外最多一次，API 零次。每条独立策略从空缓存起最多九次分类器拟合。先作匿名完整验收。所有正式入口的预测封存后再开外层成绩，报告开关净收益、两者各自相对双模型的净收益，以及在哪些折真的转向备选。主批晋级条件保持。该后续仍用原开发总体，结果用于诊断，不把多次回放当新任务。
