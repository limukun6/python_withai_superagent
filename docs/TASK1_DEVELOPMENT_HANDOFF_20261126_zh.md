## 实际检查

- **旧版。** 复核了 `e85d8b9` 的 143 个源码文件指纹、两份封存模型及各两次独立预测。在已发生的表格训练状态上，遮掉一条真实反馈并保持可选方法不变，14 次回放中有 9 次改变下一步。在标题任务上分别遮掉三条确认记录中的一条，三次都暂停了双模型晋级，要求补齐相应依据。A 发布提交 `d936059` 的入口和算法源码与 `e85d8b9` 相同。表内旧分是本组已验证环境的记录。[旧版正式入口](https://github.com/limukun6/python_withai_superagent/blob/e85d8b9ad92bba917a92277592b46a4d06f85bb5/superagent/unified.py) · [反馈如何决定确认与交付](https://github.com/limukun6/python_withai_superagent/blob/e85d8b9ad92bba917a92277592b46a4d06f85bb5/superagent/ab_adaptive_opening.py)
- **同题换名字。** 将同一对比题的包名改成暗示另一道课程题的名字，两版读出的样本及偏好方向均相同。旧版依赖 `headline_A`、`headline_B`、`label_pairwise` 和已知说明句式。即便目标清楚，把特征改名、改用等价表述后，旧版会转成普通文本表格。给出通用清单即可恢复。新版在目标与偏好方向明确的上述变化中均识别为同一偏好任务，样本顺序、左右方向与标签一致。对于使用非常规目标列、又完全没有说明目标列名的离线探针，新版报告无法建立目标对应关系。[可对不同提交运行的输入探针](../scripts/verify_preference_input_aliases.py)
- **新版。** 对 `d501807` 原记录和 `0882148` 的新记录分别逐步回放。交换两个候选在相同训练划分上已测得的整组反馈，Task1 有 42/82 次改变下一步，Task2 有 51/120 次改变。两份任务的 20 个原动作均可复现。颠倒候选显示顺序时动作始终相同。给真实包改名、给成对字段换名并保留已声明语义后，20 次完整排序仍相同。这些交换检验的是决策会不会听证据。[本地决策规则](../superagent/experiment_policy.py) · [回放程序](../scripts/replay_anonymous_decisions.py)
- **本轮默认入口验收。** 两道题分别从空目录执行同一个 `solve` 命令，标准输入关闭。训练进程只能打开任务说明和训练成员，运行目录记录每次动作、内部得分和最终重训。两个模型均另起进程重载，全部预测封存后才对课程指定验证答案评分。每题 10 次真实拟合（含重训），本轮共 20 次，模型 API 0 次，课程费用 ¥0。正式测试集未参与。791 项回归测试通过。[登记与预算](../research/integration_autonomy_1126/protocol.json) · [验收程序](../scripts/verify_integrated_defaults.py)

## 队友从哪里开始

完整研发分支是 `codex/task-driven-planning-1125`。从该分支根目录起自己的开发分支即可运行下列命令。验证 Task1 数值的环境为 Python 3.11，精确基础依赖见 `requirements-tested.txt`。复现 Task2 的历史候选范围还需要编码器依赖和登记的本地权重。

```sh
python -m pip install -r requirements-tested.txt
python -m unified_agent solve TASK.zip --prediction-input FEATURES.zip --run-dir runs/task1-start --output runs/task1-start/predictions.csv
```

`TASK.zip` 是原始任务包，`FEATURES.zip` 仅含待预测特征。`--run-dir` 使用新目录。真实 Task1 起点是训练支持的类别字段交叉和 CatBoost，Agent 从 8,117 行训练数据中选择字段组合。要试更强的通用类别表格方法，可在 `superagent/ab_methods.py` 注册候选，让相同的调度器按训练反馈选用。开发对照先保持相同训练划分、拟合额度和可用方法，再看新候选能否在另一份训练划分上复现收益。选模和重训完成后再评分。[字段组合如何从训练数据中选出](../superagent/field_interactions.py) · [候选注册位置](../superagent/ab_methods.py)

独立开关 `--task-analysis flash` 已随本版交付。此前四项公开开发任务上的 1,252 个留出预测与本地对照逐行一致。此开关可用于研究读题和反馈，对默认 Task1 基准没有依赖。[开题分析结果](TASK_OPENING_V1_1126_zh.md)
